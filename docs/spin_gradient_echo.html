SE와 GRE는 각각 무엇을 되돌리나?

GRE는 gradient로 쌓인 위상을 반대 gradient 면적으로 모읍니다. SE의 180° pulse는 앞서 쌓인 위상을 뒤집어, 정적인 주파수 차이까지 다시 모일 수 있게 합니다. 두 과정 모두 T2로 잃은 자화 크기는 되돌리지 못합니다.

선행 지식과 이 모형의 시작점

위상은 횡자화가 xy 평면에서 가리키는 각도이며, 같은 방향의 기여가 모일수록 합성 신호가 커집니다. B03의 SE와 B04의 gradient 면적을 먼저 보면 좋습니다. 여기서는 t=0의 이상적 90° 직후를 (Mx,My)=(0,1)로 두고 초기 Mxy/M0=1로 정규화합니다.

Δf=fspin−fRF, 단위는 Hz입니다. +주파수에서 복소 위상 arg(Mx+iMy)는 감소합니다. 관찰 시간은 물리 ms이며 재생 애니메이션 없이 시점을 직접 고릅니다.

예상한 뒤 세 조건 비교하기

  1. 같은 ensemble, 두 방법. 기본값에서 SE/GRE를 번갈아 선택하고 명목 TE의 벡터와 신호를 비교하세요. 두 신호 크기가 같은데 방향은 다른 이유를 시간도식에서 찾습니다.
  2. 두 번째 gradient가 약하면? 명목 TE에서 다시 모일까요? 위상에 남은 면적과 gradient 재결맞음 기준선이 어디로 움직이는지 확인합니다.
  3. 정적 Δf 분포를 더하면? 같은 T2·gradient에서도 SE/GRE가 달라지는지 봅니다. 공통 Δf만 바꿀 때는 GRE의 위상과 크기 중 무엇이 변하는지도 예상하세요.

예제 버튼은 대표 설정과 관찰 TE를 적용합니다. SE의 gradient는 180° 전후 같은 부호, GRE는 반대 부호입니다. 각 모드의 시간도식을 함께 읽으세요.

조건과 관찰 시점

조건을 바꿔도 물리 관찰 시점을 유지하고 새 범위 밖이면 끝으로 제한합니다. TE/2의 SE는 순간 180° 직후 값입니다. GRE에는 이 RF가 없습니다. 기본 TE/T2와 g는 기전을 보기 위한 예제값입니다.

단위·정규화·가중치

위치 −2…2는 길이 단위를 정하지 않은 다섯 표본입니다. g[Hz/step]는 γ̄GΔx이며 gradient 세기 T/m 자체가 아닙니다. b는 명목 TE까지 두 절반의 면적 비율입니다. 둘째 gradient는 표시 끝 1.5TE까지 이어집니다.

각 위치에 같은 정적 Δf 분포를 적용합니다. σf>0이면 ±2σf에서 자른 9개 이산 Gaussian 가중치, 총 45개 대표 묶음입니다. σf=0이면 위치별 한 묶음입니다. σf는 분포 폭 매개변수이며 이산 분포의 실제 표준편차와 같지 않습니다.

얇은 화살표는 각 묶음의 순자화, 굵은 붉은 화살표는 가중 합입니다. 원 반지름·그래프 세로축은 초기 Mxy=1로 고정하며 자동 확대하지 않습니다.

오개념과 관찰 후 질문

“GRE가 모든 정적 주파수 차이를 되돌린다.” 반대 gradient가 보상하는 것은 그 gradient의 위치별 위상입니다. 독립적인 정적 Δf 분포는 그대로 누적됩니다. 공통 Δf 하나는 전체 위상만 돌리고, 분포는 서로 다른 위상을 만들어 합의 크기를 줄일 수 있습니다.

“180° pulse가 T2 감쇠도 복원한다.” SE가 TE에서 완전히 모여도 크기는 exp(−TE/T2)입니다. T2 envelope와 겹치는지 확인하세요.

수식·범위·다음 학습

선택 수식: 위상을 시간 순서로 더하기

τ=TE/2, m=Mx+iMy, t와 T2는 ms입니다. 각 묶음은 처음 m=i에서 시작합니다. Δf=δ, 위치 x, 첫 gradient 부호 s는 GRE에서 −1, SE에서 +1입니다.

t<τ: m=i exp(−t/T2) exp[−i2π(δ+s g x)t/1000].

τ 이후 GRE는 같은 방향으로 위상을 계속 쌓고, SE의 180°x는 m→m*로 앞의 위상을 뒤집습니다. 그 뒤 δ+b g x에서 자유 세차합니다.

GRE: m=i exp(−t/T2) exp{−i2π[δt+g x(−τ+b(t−τ))]/1000}.

SE: m=−i exp(−t/T2) exp{−i2π[δ(t−2τ)+g x(−τ+b(t−τ))]/1000}.

b=1, t=2τ에서는 gradient 항이 두 모드 모두 0이며 SE의 δ 항도 0입니다. SE가 −y, GRE가 +y인 기본 위상 차이는 180°x의 회전 규약입니다. 그림·곡선의 비교 신호는 두 성분의 magnitude입니다.

모형의 한계·출처

이상적 순간 RF, 시간에 따라 변하지 않는 δ, 공통 T2, 동일 초기 Mxy를 가정합니다. T1·TR 정상상태·RF 불완전·확산·움직임·gradient ramp·bSSFP는 제외합니다. 이산 표본의 반복 결맞음이 가능하며 임상 T2*를 fitting하지 않습니다.

면적 0은 위상 재결맞음의 기준입니다. T2 감쇠를 곱한 magnitude 곡선의 최대점과 무조건 같은 시각이라고 하지 않습니다. 신호 envelope는 C03 T2와 정적 탈위상에서 더 살펴봅니다.
