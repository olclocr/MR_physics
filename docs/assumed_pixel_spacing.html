X17 후속 · 같은 분수 pixel 좌표, 다른 단위 환산

점 위치가 정확해도 잘못된 간격으로 재면 길이가 맞을까요?

좌표가 정확하다는 것과 mm 단위의 환산이 정확하다는 것은 서로 다른 조건입니다. 같은 점 좌표를 그대로 두고 측정에 가정한 행·열 간격만 바꾸어 봅니다.

목표: 좌표/단위 환산·행/열 간격·가로/세로/대각 오차를 구별합니다.

선행 · 이번에 고정한 것과 바꾸는 것

알려진 5×5 격자는20mm 간격이고 변형은0입니다. 실제 열 간격 Δx=1mm, 행 간격 Δy=2mm, 128열×64행, FOV128×128mm입니다. x는오른쪽, y는위쪽이고 u는오른쪽, v는아래로 증가합니다.

정확한 분수 pixel 중심 좌표 u=(x+64)/1−.5, v=(64−y)/2−.5는모든 조건에서 바꾸지 않습니다. 반올림/검출오차/영상 보간은 없습니다. 측정에 가정한 간격(행,열)만(1,1)/(2,1)/(2,2)mm로바꿉니다. (2,1)이정확한 값입니다.

DICOM Pixel Spacing 순서는(행 Δy,열 Δx)입니다. 거리=√[(ΔuΔx)²+(ΔvΔy)²]이고, 두 좌표 차이를 그냥 같은 mm로 더하지 않습니다. 현재 예시는 metadata를 실제로 읽거나 고치는 기능이 아닙니다.

예측하고 비교할 세 가지

  1. 기본 세로80mm를 정확한 간격으로 환산하면?
  2. 같은 잘못된(1,1)로 가로를 재면?
  3. 열 간격만2mm로 잘못 가정하면?

환산에 가정한 간격

기본: 가정(1,1) / 중심 세로. 실제 간격은행2/열1mm로고정입니다. 모든 점의 u/v와 원래 ID는바꾸지 않습니다. 두 그림은 중심을(0,0)으로맞추고 같은 고정 mm 축척으로 표시합니다.

정확한 좌표에도 정확한 단위 환산이 필요합니다

중심 세로 선분은 Δu0/Δv−40pixel입니다. 실제 행 간격2mm이면80mm지만 행 간격1mm로가정하면40mm입니다. 점 좌표는 정확해도 환산된 길이는 틀릴 수 있습니다.

같은(1,1) 가정에서 중심 가로는 Δu80/Δv0이라80mm로맞습니다. 한 방향의 길이가 맞는다는 이유로 다른 방향이나 전체 기하도 맞다고 결론내릴 수 없습니다. 대각선에는 두 축 간격이 함께 작용합니다.

가정 간격을 바꾸면 고정 행/열 수의 환산 영상 범위도 바뀝니다. 정확한 범위128×128mm가(1,1) 가정에서는128×64mm, (2,2) 가정에서는256×128mm로환산됩니다. 실제 물체가 변형된 결과와 단위 환산만 잘못한 결과를 구별하세요.

수식 · 거리와 중심 기준 표시

L가정=√[(ΔuΔx가정)²+(ΔvΔy가정)²]입니다. 이번 실제 간격의 정답은 L참=√[(Δu×1mm)²+(Δv×2mm)²]입니다. 방향에따라 길이비가 달라지며 단순히 한 숫자로 모든 방향을 보정하지 않습니다.

두 도식은 같은 영상 중심을 원점으로 X=(u+.5−64)Δx, Y=(32−v−.5)Δy를 사용합니다. 이 원점 선택은 길이에 영향을 주지 않습니다. FOV가정=(128Δx)×(64Δy)이며 실제 환자 원점/방향을 추정한 것이 아닙니다.
