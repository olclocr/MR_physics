M04 후속 · 완벽히 분리된 두 성분의 부분 모형

지방 밀도가 같은데 echo마다 신호 분율이 달라질 수 있을까요?

T1 가중을 제거해도, 물·지방의 감쇠가 다르거나 지방 내부의 여러 peak가 상쇄되면 신호 분율은 달라집니다. 하나씩 추가해 원인을 구별해 보겠습니다.

목표: 공통 감쇠의 상쇄, 서로 다른 감쇠의 영향, 지방 내부 상쇄와 정답 모형 역산의 가정을 설명합니다.

선행 · 정답 · 교육 모형의 범위

밀도와 신호 분율, 복소수의 합, T2* 감쇠를 먼저 확인하세요. 이동 가능한 양성자 밀도는 ρW+ρF=1이며, 실제 물·지방 복소 신호가 이미 완벽히 분리되어 주어진다고 가정합니다. T1 가중·field/B1·noise·교환·실제 Dixon 분리나 fitting은 계산하지 않습니다.

물 T2*=40ms, 지방 T2*=40 또는20ms는 교육용 값입니다. 각 지방 peak의 T2*는 서로 같게 둡니다. B0는 주파수 차이만 바꾸며 T1/T2*를 바꾸지 않습니다. TE0은 수학적 기준으로 실제 즉시 획득을 뜻하지 않습니다.

공통 항은 상쇄되지만 서로 다른 항은 남습니다

공통 T2*의 단일 peak에서는 두 성분의 크기가 같은 비율로 줄어 원신호 분율이 일정합니다. 지방 감쇠가 더 빠르면 혼합 신호의 지방 분율은 줄어듭니다. 여섯 peak가 서로 다른 방향으로 회전하면 지방만의 복소 합 크기도 달라집니다. 이것은 물과 지방 사이의 OP 상쇄와 구별해야 합니다.

위상은 기존 F01과 같은 음의 회전 규약입니다. Δf(Hz)=ppm×42.57747892×B0(T), 시간은 위상 계산 시 초로 바꿉니다. 크기를 구하기 전에 각 지방 peak의 복소 신호를 합합니다. 크기를 먼저 합하면 내부 상쇄를 놓칩니다.

정답 모형 역산은 |W|를 exp(−TE/T2*W)로, |F|를 exp(−TE/T2*F)|c(TE)|로 각각 나눈 뒤 비율을 구합니다. 정답 T2*와 spectrum 및 정확한 분리 신호를 제공하므로 가능한 계산입니다. 자료에서 이 값들을 추정하는 알고리즘이 아니며, |c|가 작은 경우의 잡음 증폭도 구현하지 않았습니다.

주어진 spectrum은 Hamilton 등,2011 Table3와 Wang·Hernando·Reeder,2016 Table1에 대조했습니다. 논문의 CSE fitting이나 환자 수치·성능을 재현하지 않습니다. 실제 다중 echo에서 field·성분·감쇠를 함께 추정하는 문제는 이 페이지의 알려진 모형 역산보다 복잡합니다.
