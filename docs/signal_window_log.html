X06 후속 · 정의한 양의 scalar 신호의 균일 시간 평균

신호를 평균한 뒤 log를 취하면 변화율의 평균과 같을까요?

같은 시간창의 자료라도 신호비를 먼저 평균하는 것과 각 시각의 변화율을 먼저 구하는 것은 다른 연산입니다. 창 길이·TE·경계 시각을 바꾸어 두 결과를 비교합니다.

목표: 평균과 비선형 변환의 순서, 같은 변화율/다른 TE, 창 안의 시간 변화와 단순 평균의 한계를 구별합니다.

선행 · 신호비, 두 시간과 같은 기준 신호

단일 지수 신호 S(t)=exp[−TE·(30+ΔR(t))], 올바른 기준 S0=exp(−30 TE)에서 q(t)=S/S0=exp(−TEΔR(t))입니다. 횡진폭은 1로 정규화하고 ΔR(t)=40sin²(πt/20)s⁻¹을 0<t<20초에 직접 정의합니다. 밖에서는 ΔR=0/q=1로 이어집니다. 임상에서 측정한 곡선이나 조직값이 아닙니다.

t는 곡선의 경과시간(초), W는 평균창 길이(초), TE는 지수 감쇠 시간(ms)입니다. TE만 초로 변환해 log의 분모에 넣습니다. 창 [중심−W/2, 중심+W/2] 전체를 같은 가중치로 평균하며 범위 밖을 잘라 재정규화하지 않습니다. 이 페이지는 양의 scalar 신호의 수학적 평균이며 실제 복소 k-space/영상 획득을 모사하지 않습니다.

먼저 예상하고 비교할 세 가지

  1. 기본 12초 창을 2초로 줄이면 두 순서의 차이는?
  2. 같은 12초 창에서 TE만 60 ms로 늘리면?
  3. 순간 ΔR=0인 시작 시각에 중심을 두면 평균도 0일까요?

평균창과 변환 시간

기본: TE 30 ms / W 12초 / 중심 10초. 올바른 같은 기준 신호를 사용하며 잡음·기준 배율 오류·T1 가중 변화는 포함하지 않습니다. 긴 W와 긴 TE는 다른 조작입니다.

같은 창에서 다른 계산 순서

회색 점선: 순간 신호비 q(t) · 파랑 실선: 각 중심의 창 평균 ⟨q⟩. 옅은 영역은 선택창이며 그림 밖 부분만 잘라 표시합니다. 계산은 창 전체를 포함합니다. 시간 0–30초·신호비 0–1의 고정 축입니다.

회색 점선: 순간 ΔR · 주황 점선: 먼저 log 변환한 변화율 평균 Rmean · 파랑 실선: 신호 평균 뒤 log로 구한 Reff. 각 점은 선택 중심입니다. 시간 0–30초·변화율 0–42 s⁻¹의 고정 축입니다. 파랑이 주황보다 크지 않은지 비교하세요.

신호 평균은 변화율의 산술 평균과 다릅니다

같은 창 안에서 ΔR이 변하면 q도 변합니다. −log는 비선형이므로 평균의 바깥으로 자유롭게 옮길 수 없습니다. 이 양의 신호 모형에서는 Reff≤Rmean입니다. 더 작은 ΔR의 큰 신호가 산술 신호 평균에 더 크게 기여합니다. 이것을 실제 조직의 양이 변한 결과로 해석하지 않습니다.

Rmean은 TE와 무관하지만 Reff는 TE에 따라 달라질 수 있습니다. 순서를 바꾸지 않은 순간 ΔR은 올바른 기준이면 어떤 TE에서도 같은 값입니다. 창 안에서 ΔR이 일정하면 두 순서가 같고 W가 0으로 가는 순간 극한에서도 같습니다. 현재 UI의 W는 2/6/12초입니다.

중심 0초의 순간 ΔR은 0이지만 창 오른쪽에는 양의 ΔR이 있습니다. 왼쪽의 ΔR=0/q=1과 함께 전체 W로 나누므로 평균이 양수가 될 수 있습니다. 창을 잘라 다시 평균한 결과와 구별하세요.

수식 · Jensen 부등식과 단위

⟨f⟩=(1/W)∫[t−W/2,t+W/2] f(s)ds. Rmean=⟨−ln(q)/TE초⟩=⟨ΔR⟩, Reff=−ln⟨q⟩/TE초입니다. −ln의 볼록성에서 −ln⟨q⟩≤⟨−ln q⟩이므로 양의 TE로 나누면 Reff≤Rmean입니다. q는 양수인 무차원 비이고 변화율의 단위는 s⁻¹입니다.

이 페이지의 신호는 공통 이완 함수에서 같은 단일 지수로 계산합니다. 신호비와 ΔR을 균일 시간 구적한 뒤 같은 결과를 원표·곡선·지표에 사용합니다. 실제 복소 신호/위상·공간 부호화·시간별 k-space 결합이나 영상 재구성의 결과가 아닙니다.
