Q01 · SNR·CNR·NEX

평균하면 무엇이 더 잘 보일까요?

같은 신호를 반복 측정하면 잡음의 흔들림을 줄일 수 있습니다. 그러나 밝다는 사실만으로 두 구획이 잘 구별되는 것은 아닙니다. 신호가 없는 배경도 크기영상에서는 밝기가 0보다 커집니다.

학습 목표: σ와 SNR/CNR의 정의, 독립 반복 평균의 제곱근 관계, 복소 신호와 크기영상 잡음의 차이를 구별합니다.

선행 개념·단위·기본 모형

C01의 신호 차이와 G01의 획득/표시 격자를 연결합니다. 모든 신호와 σ는 같은 상대 단위입니다. σ는 한 번 획득한 실수·허수 각각의 잡음 표준편차입니다. 두 성분과 반복 사이의 잡음은 독립이고 평균은 0인 Gaussian입니다.

A의 참 신호는 0.60, B는 0.60−ΔS이며 위상은 0입니다. 주변 배경은 참 신호 0입니다. 고정한 64×48 격자·고정 voxel·단일 복소 채널의 두 구획 교육 모형입니다. 임상 영상이나 병변이 아닙니다.

  2. NEX만 바꾸기. 1→4→16으로 늘리면 같은 참 신호에서 흔들림이 얼마나 줄까요?

오개념·가정·다음 질문

“밝으면 두 구획이 잘 보인다” → ΔS=0이면 SNR_A가 높아도 참 CNR은 0입니다. “배경 크기영상의 SD가 곧 σ다” → 단일 채널의 무신호 크기는 Rayleigh 분포여서 실수·허수의 σ와 다릅니다. 위 표의 실수 평균과 크기 평균을 비교하세요.

선택 수식·SNR/CNR의 정의

Z̄ = S + (1/N)Σ(nR + i nI), nR,nI ~ N(0,σ²). σ평균 = σ/√N. M=|Z̄|.

SNR_A = SA/σ평균, CNR = |SA−SB|/σ평균.

여기서는 잡음을 공통 단일 성분 σ로 정의한 모형 지표입니다. 두 독립 pixel의 차이 자체의 SD는 √2σ평균이며 그 정의의 CNR과 수치가 다릅니다. 크기 ROI 평균/배경 크기 SD를 그대로 나눈 값과도 구별합니다. σ=0인 이상적 모형에서는 이 비율을 유한한 측정 지표로 제시하지 않습니다.

S=0: E[M]=σ평균√(π/2), SD[M]=σ평균√(2−π/2).

실수·허수가 Gaussian이어도 크기는 저신호에서 Rician이고 S=0이면 Rayleigh입니다. 먼저 복소 평균한 뒤 크기를 취합니다. 크기영상끼리 평균하는 것은 이 화면의 NEX와 다르며 양의 잡음 바닥을 같은 방식으로 줄이지 않습니다.

적용 범위와 출처

단일 복소 채널·공간적으로 독립인 동일 분산 잡음·동일 신호/위상·정합된 반복을 가정합니다. 움직임·위상 드리프트·생리 잡음·코일 결합·병렬/비선형 재구성·AI denoising에서는 이 단순 통계가 그대로 적용되지 않을 수 있습니다. 반복에 비례한 획득 시간 외에 실제 검사 시간 전체는 계산하지 않습니다. 같은 획득에서 표시 pixel만 늘리는 것은 NEX가 아닙니다. Q04 · R2와 g-factor에서는 같은 고정 조건에서 가속의 잡음 손실을 구별합니다. 같은 자화 밀도·코일·bandwidth·획득 시간 등의 조건을 맞춘 단순 비교에서는 획득 voxel 부피가 커지면 적분 신호가 커집니다. 실제 조건을 함께 바꾸면 잡음과 측정 시간도 달라지므로 부피 하나로 SNR을 판단하지 않습니다. 이 화면의 voxel은 고정입니다.
