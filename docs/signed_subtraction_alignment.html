X05 후속 · 알려진1차원 신호·정수pixel 이동

뺄셈 영상의 양·음 경계가 모두 조영 변화일까요?

전후 신호의 변화가 없어도 위치가 다르면 뺄셈에 양·음 경계가 생깁니다. 모형의 실제 신호 증가와 위치 오차를 분리하고 같은 ROI에서 읽은 차이를 비교합니다.

목표: signed difference·공간 정합·고정 ROI/전체 적분의 차이를 구별합니다.

선행 · 신호/좌표와 변환 정의

X05의 신호와 A02의 위치 변화에서 이어갑니다. FOV128mm의128pixel(dx1mm), 바탕구간[−40,40]mm의 신호.2a.u.와 중앙[−6,6]mm의 추가.1a.u.를 직접 정의합니다. 전영상 중앙은.3a.u.입니다. 후영상 중앙에만Δ0/.1/.3a.u.를 더하고 전체를−8/0/+8mm 이동시킵니다.

각 전후 영상의 획득 중에는 물체가 정지해 있으며 영상 사이의 위치만 다릅니다. A02의 한 영상 안에서 생기는 ghosting을 계산하는 모형이 아닙니다. 각pixel은1mm구간의 신호 평균입니다. 원영상은 비음수/같은스케일이며 ΔI=후영상−전영상은 signed값입니다. 음의 차이는 후영상이 그 좌표에서 작다는 뜻이지 원래 MR신호의 위상이나 종자화 부호가 아닙니다. 실제 농도/RF/조직값을 계산하지 않습니다.

“알려진 이동 역변환”은 정답값으로 후영상 배열을 정확히8pixel 되돌립니다. 이동 추정·분수pixel 보간/비선형변형은 없습니다. 물체는 FOV 안에 남아 이동으로 신호가 잘리지 않습니다. 범위 밖 배열값은0이며 실제 환자 정합 알고리즘이나 성능 검증이 아닙니다.

전체 보존과 국소 해석은 다릅니다

이번 물체가 FOV 안에 남는 모형에서는 이동만으로 신호의 전체 적분이 바뀌지 않습니다. 증가0이면 양·음 경계가 서로 상쇄되어 전체 signed 적분은0이지만 개별pixel과 고정ROI의 차이는0이 아닐 수 있습니다. 전체 적분이 보존된다는 이유로 국소 뺄셈이 정확하다고 결론내릴 수 없습니다.

실제 신호 증가가 있으면 이 모형의 전체 적분은12mm×Δa.u.입니다. 알고 있는 정수 이동을 되돌리면 중앙ROI의 차이도 Δ가 됩니다. 이것은 실제 환자의 움직임이 항상 정수pixel 평행이동이라는 뜻이 아닙니다.

수식 · 공간 평균·부호·정렬

Ipre(x)=.2·1_[−40,40](x)+.1·1_[−6,6](x), Ipost(x)=.2·1_[−40,40](x−d)+(.1+Δ)·1_[−6,6](x−d)입니다. Pixel값은 각1mm구간의 적분/1mm입니다. 알려진 이동 역변환에서는 후영상의 j+d/dx번째pixel을 j에 가져옵니다.

ΔIj=Ipost선택,j−Ipre,j, 전체 적분=ΣΔIj·dx, 양/음 적분은 각각 양수/음수 부분만 합합니다. 고정ROI 평균은Σ_ROIΔIj·dx/12mm입니다. 영상 단위/스케일·noise·보간/왜곡·FOV 잘림이 달라지면 같은 보존/정확복구를 보장하지 않습니다.
