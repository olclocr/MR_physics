선행 · 날짜와 버전의 의미

AI01의 denoising/누락 자료 추정/선명도 역할, AI03의 작은 구조/정량 bias를 먼저 확인하세요. 같은 제품군 안에서도 처리 단계와 설정이 다릅니다.

자료 확인일, 문서 발행일/문서 번호, 장비 software 버전은 서로 다릅니다. 이 작업에서 8개 명칭의 설치 software 버전은 모두 확인하지 못했습니다. 발행일이 없는 웹페이지를 검색엔진의 날짜나 저작권 연도로 대신하지 않습니다. 지원 조건은 읽은 문서 범위이며 국내/기관별 최신 설치 목록을 뜻하지 않습니다.

문서에 적힌 역할로 비교하기

필터는 문서의 설명을 묶은 읽기 도구입니다. 제품 성능 점수나 기능 전체의 완전한 분류가 아닙니다. 한 명칭이 여러 역할에 나올 수 있습니다.

명칭을 같은 AI 한 종류로 묶지 말고 처리의 역할을 비교하세요.

행렬·자료 일치·성능 근거는 서로 다른 질문입니다

Canon의 이 PIQE 해설은 잡음/링잉 감소의 두 AI 단계와 zero filling에 의한 행렬 확대를 구별합니다. Siemens의 이 Sharp 해설은 신경망을 이용한 복소 자료의 개선을 설명합니다. 두 제품이 같은 행렬 크기를 출력해도 같은 정보 추정이나 같은 구조 보존을 뜻하지 않습니다. A03에서 본 것처럼 zero filling만으로 새 획득 정보를 얻지는 않습니다.

Data consistency라는 설명은 획득 자료를 사용하는 방식을 가리킵니다. 그것만으로 누락된 정보·작은 구조·정량값의 정답이 입증되지는 않습니다. AI01/AI03에서 확인한 질문을 실제 제품 평가에도 별도로 적용해야 합니다.

성능 문장을 읽을 때 확인할 비교 조건

비교한 원본 방법, 실제 획득 matrix/FOV/BW/평균 횟수와 시간, 재구성 matrix, sequence/부위/코일, 처리 강도, 참조 자료와 평가 과제를 먼저 찾습니다. Noise 감소, 선명도 수치, 병변 검출, T2/PDFF bias는 서로 대체할 수 없는 지표입니다.

제조사 기술 해설은 공개된 처리 구조를 이해하는 1차 자료입니다. 그 안의 예시 영상·성능 수치·사용자 경험이 동일 과제의 독립 임상 비교가 되는 것은 아닙니다. 인용된 원전도 제품/버전·대상·과제·설계가 무엇인지 따로 읽어야 합니다. 이 페이지는 공개된 역할 설명만 대조했으며 vendor 순위나 임상 우열을 계산하지 않습니다.
