X16 후속 · 직접 정의한 가역 스칼라 응답

응답이 포화하면 선형의 ½ 규칙도 유지될까요?

초기 기울기가 같은 두 응답도 장이 커지면 현재 모멘트와 전체 응답 면적이 달라집니다. 포화하는 예시 함수와 선형 모형을 비교하여 힘과 유효 위치 에너지를 구별합니다.

목표: 초기 기울기와 큰 장의 응답·현재 모멘트와 일 적분·선형 ½ 규칙의 적용 범위를 설명합니다.

선행 · 같은 초기 기울기와 유효 에너지의 뜻

선형 μ(B)=αB에서 α=.001 A·m²/T입니다. 포화 예시는 μ(B)=μsat tanh(B/Bc)이며, 포화 모멘트 μsat=.001 A·m²와 장 척도 Bc=1 T를 각각 직접 정의합니다. B→0의 기울기만 α=μsat/Bc로 같습니다. B=1 T는 B/Bc=1이므로 작은 장 근사가 아닙니다. 이 함수/계수는 실제 재질 fitting·원자/온도·장비의 값이 아닙니다.

두 모멘트는 +z로 정렬하고 x=0의 국소 Bz(x)=B0+Gx를 가정합니다. G는 0/1 T/m, B0는 1/3 T입니다. 가역·즉시 응답의 기계적 유효 위치 에너지를 Ueff=−∫₀ᴮμ(b)db, 기준 Ueff(0 T)=0으로 정의합니다. 자기장 전체의 저장 에너지·흡수 열에너지·미시적 내부 에너지와 구별합니다.

선형 응답은 Ueff=−αB²/2=−μ(B)B/2지만, 임의의 비선형 응답에서도 마지막 등식이 성립하는 것은 아닙니다. 현재 힘은 Fx=μ(B0)G입니다. 장 의존 모멘트를 고정 dipole의 −μB에 넣고 전체 미분하는 계산도 올바른 일 적분과 다릅니다.

응답과 주어진 국소 장

기본: 포화 예시 / B0 3 T / G 1 T/m. 그림의 가로축 B는 응답을 살피는 장 값입니다. 실제 물체의 이동 경로나 3D MRI 장 분포가 아닙니다.

현재 모멘트와 0 T부터의 응답 면적

파랑: 선택 μ(B) · 옅은 면적: 0 T부터 B0까지의 양의 일 적분 −Ueff. 실제 그린 다각형은 .02 T 표본의 사다리꼴 근사이며 숫자 지표는 모형의 적분값입니다. B 0–3.2 T·모멘트 0–3.4mA·m²의 고정 축입니다.

파랑 실선: Ueff=−∫μdb · 붉은 점선: 비교용 −μ(B)B/2. 선형에서는 겹치지만 포화 예시에서는 다릅니다. 두 점은 선택 B0입니다. B 0–3.2 T·에너지 −5.4–0mJ의 고정 축입니다. 붉은 값은 비선형의 올바른 위치 에너지로 쓰지 않습니다.

½는 선형 응답의 삼각형 면적입니다

선형 μ=αB의 응답 아래 면적은 삼각형이므로 μ(B)B/2입니다. 휘어진 응답에서는 전체 곡선 아래 면적을 구해야 합니다. 현재 모멘트만으로 과거 0 T부터의 응답 전체를 삼각형으로 바꿀 수 없습니다.

포화 예시의 모멘트는 μsat에 접근하고 G가 일정하면 힘도 μsatG에 접근합니다. 선형 기준은 이 모형 범위에서 계속 증가합니다. 실제 강자성 물체의 이력/재질이나 MRI실 물체의 움직임을 이 함수로 예측하지 않습니다.

G0에서는 힘 0이어도 선택 B의 모멘트와 Ueff는 남습니다. 여기의 Ueff 기준은 0 T이고, 실제 물체를 어느 경로로 이동시켰는지 또는 안전한지를 계산한 값이 아닙니다.

수식 · 포화 예시의 일 적분과 단위

μ=μsat tanh(B/Bc), Ueff=−μsatBc ln cosh(B/Bc)입니다. dUeff/dB=−μ(B)이므로 Fx=−(dUeff/dB)G=μ(B0)G입니다. 선형은 Ueff=−αB²/2이고 초기 기울기는 μsat/Bc로 맞춥니다.

A·m²×T=J, A·m²×T/m=N입니다. μ/F/U 표시는 각각 mA·m²/mN/mJ로 SI값의 1000배입니다. B/Bc≪1에서 tanh(B/Bc)≈B/Bc입니다. 여기 Bc=1 T이므로 B=1 T에서는 B/Bc=1이며 작은 장 극한이 아닙니다. 모형의 포화는 가역 응답의 제한값이며 RF 포화 pulse나 히스테리시스를 뜻하지 않습니다.

가정과 근거

Fitzpatrick의 원문은 약한 상호작용의 spin1/2 상자성 모형에서 tanh 평균 응답과 초기 선형/포화 극한을 유도합니다. 여기 계수는 직접 정한 거시적 예시이며 원문의 원자·온도와 대응시키지 않습니다. 강자성 재질이나 실제 물체 fitting으로 쓰지 않습니다. 일 적분의 에너지 정의는 선형 응답 챕터와 같습니다.
