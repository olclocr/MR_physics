# X18 후속 · 두 풀의 서로 다른 종이완률

2026-10-19 W111 **대상 버전 통과**. 초기평형(1,.1), 물 R1w=1 s⁻¹, 교환 쌍 s→w k.5/2 s⁻¹와 w→s.1k, s의 W5 s⁻¹ 적용[0,1)초를 유지했다. 작은 풀 R1s=.5/1/2 s⁻¹·관찰1/1.2/2/4초의24조건, 기본k2/R1s.5/t1.2다. R1s는 준비/회복 전체에 적용하므로1초의 준비 상태도 달라질 수 있다. 고유 T1s는 각각2/1/.5초이며 물의 고유 T1w는 모두1초다. 이 작업은34b9105 이후 로컬 구현이다.

[Dortch 등2009 Theory](https://pmc.ncbi.nlm.nih.gov/articles/PMC2776779/)의 풀별 R1/상세 평형/결합 모드와 [Gabr 등2008 Theory2.1](https://pmc.ncbi.nlm.nih.gov/articles/PMC2398708/)의 서로 다른 T1을 포함한 affine 행렬을 실제 다시 읽었다. 모든 수치는 직접 정한 예시이고 W는 RF에서 계산하지 않은 유효 감소율이다. 실제 RF/주파수/B1→W·직접 물 포화/횡자화·MT/CEST spectrum/환자 정량을 재현하지 않는다. 외부 전문가 검토 미시행이다.

## 공통 API와 기존 범위 보존

TwoPoolTransfer.propagate/rates에 선택적인{soluteR1=1}을 추가했다. 작은 풀 회복은 R1s(.1−s), 물 회복은1−w, 평형 크기와 교환 방향은 유지한다. 기본1에서 기존 연산 순서와 반환 필드를 보존했다. 독립3×3 행렬지수/ODE 기준도 선택적인 수치 인자로 R1s를 받는다. [여덟 리터럴](W111-api-edits.json)·[입력 범위 감사](W111-api-audit.cjs)·[결과](W111-api-audit.json)는 기존1,126입력의 변경을 두 공통 파일/네 참조 항목과 선행 한 링크/한 항목으로 제한했다. 모든 변경의 역치환으로 이전 파일 SHA를 정확히 복원했다.

기존 [지속 포화 변경 전72개](W111-before-transfer-browser.json)/[후72개](W111-after-transfer-browser.json)와 [종료 전36개](W111-before-release-browser.json)/[후36개](W111-after-release-browser.json)의 전체 모델/출력/원표/SVG SHA-256은 [정확히 같다](W111-legacy-comparison.json). 각 상태에서 기존 독립 값·그래프/모든 원표 셀/키보드/예제/정답/문자 경계도 재검증했다. 기존 브라우저 파일과 스크린샷을 덮어쓰지 않았다.

[기존 지속 포화 독립 절차](W111-legacy-transfer-numerical.cjs)/[결과](W111-legacy-transfer-numerical.json)와 [기존 종료 독립 절차](W111-legacy-release-numerical.cjs)/[결과](W111-legacy-release-numerical.json)를 새 파일에서 실행했다. 원래 수치 결과 두 개와 display-reference 두 개의 바이트가 모두 정확히 같다. 확장된 API가 기본 범위의 수치/화면/정답을 바꾸지 않았다는 판정이며 실제 RF 모형 전체의 검증으로 확대하지 않는다.
