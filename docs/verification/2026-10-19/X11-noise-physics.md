# X11 후속 · 알려진 감도 정규화와 잡음 분산

2026-10-19 W110 **대상 버전 통과**. 시작 전체248개 시험 통과. T1=1000ms의 완전 회복 IR, TI400/700/1000ms와 알려진 양의 감도A.25/.5/1/2의12조건, 기본A.5/TI400이다. 기존 IRPhaseReference의 정확한30도 위상/자화를 재사용하고, 잡음 없는 참조 r1/Q=A exp(iφ)를 직접 준다. 원 신호 S=A Mz exp(iφ)+n에 실수/허수 각각σ.02의 독립 Gaussian 잡음을 더한다. A는 잡음 없는 신호에만 곱하고 원 잡음 수준은 고정하는 예시다. 전자 gain 조절의 모든 실제 결과를 뜻하지 않는다.

Q01의 SnrAveraging.createBank(2000,1,0x5831314e)와 stats를 변경 없이 재사용한다. AI03도 같은 xorshift32/Box–Muller 계열의 공통 경로를 쓰며 새 난수 모듈을 만들지 않는다. 모든 조건에 같은2000쌍을 재사용하므로12조건을 독립된12회 표본 추출로 해석하지 않는다. 위상만 제거한 C의 실수부 기대값=A Mz/SDσ, 정규화 N의 실수부 기대값=Mz/SDσ/A다. 표본 평균/표본SD는 전체2000값으로 구하고n−1분산을 쓴다.

관찰은 감도를 낮출 때 기대 평균/SD 구별, 큰 감도에서 좁아지는 정규화 잡음, TI700의 null 근처 평균과 여전히 남는 잡음이다. 두 문제는 정규화 평균/분산과 기대값/유한 표본 평균을 구별한다. 지표/64bin histogram/감도별SD 도표/전체2000행 원표는 같은 결과를 사용한다. histogram 오차 창[−.25,.25), bin폭1/128, 세로 count0–800을 고정하고 아래/위 범위 밖 수를 표시한다. SD 그림은A0–2.1/SD0–.09로 고정하고 표시 범위 위반을 검증한다.

사전 기준: 독립 BigInt xorshift32와 Box–Muller의4000표준정규 값·회복 RK4/정확한30도 계수·2×2 복소 나눗셈·두 번 통계/구간 탐색 histogram·결정론적 복소 벡터를1e−10로 대조한다. 이론 평균/분산/공통 표본의 A비례를 검산한다. 표본 평균은 기대값의4.5표준오차 이내, 표본SD는 기대SD 대비8% 이내로 고정한다. histogram 안팎 총합2000과 두 그림의 고정 축/원표·키보드/정답을 실제1920/390에서 확인한다.

[Kellman 등2002](https://pmc.ncbi.nlm.nih.gov/articles/PMC2041905/) SNR Measurement의 복소 성분 Gaussian 잡음과 위상 민감 실수 분포/정규화 범위를 실제 다시 읽었다. 이번에는 정확한 위상/감도와 잡음 없는 참조를 고정한다. 실제 coil map 추정/참조 잡음·PSIR 획득/환자 SNR/임상 판정은 제외하며 외부 전문가 검토 미시행이다.



## 독립 수치/통계와 내용 판정

[절차](X11-noise-numerical.cjs)·[결과](X11-noise-numerical.json)는12조건/24,000조건별 표본과2,000고유 복소 잡음쌍을 대조했다. 독립 BigInt 정수 경로의4,000정규 값 차이0, 회복 ODE1.499e−15, 복소 값3.109e−15, 오차 값2.221e−16, 두 번 통계4.663e−15, 기대값2.998e−15로 사전1e−10 이내다. histogram의 모든 bin/안팎 count 차이0, 총합2,000이다. 표본 평균 최대 차이는.342602표준오차로 사전4.5 이내, SD 상대차이.00552908은 사전.08 이내다. 고정 seed를 바꾸거나 표본을 재중심화/재척도화하지 않았다.

[Node 시험](https://github.com/olclocr/MR_physics/blob/main/tests/ir-normalization-noise.test.cjs)은 복소 결정론적8벡터, 허용되지 않은 입력, 정확한 이진 bin 경계/창 양 끝, 전체 표본/이론 분산/비례 관계도 확인했다. 실수 잡음 분산은σ², 정규화 뒤σ²/A²이며 복소 두 성분 파워와 구별했다. 기대 평균과 유한 표본 평균/표준오차도 설명/문제와 대조했다. 이 표본 통계로 모든 실제 잡음 모형이 적합하다고 확대하지 않는다.

기본 TI400/A.5의 Mz−.34064009207127866, 정규화 표본 평균−.34094652442258394, 이론SD.04/표본SD.04022116286654587, 위상만 보정한 표본SD.020110581433272934다. A.25의 정규화 표본SD.08044232573309179/창 밖1개, A2에서는.010055290716636477/창 밖0개다. TI700의 이상적 Mz는+.00682939241718106이며 A.5의 잡음 SD는 그대로다. 통계는 창 밖 표본을 포함하고 유한 반복의 평균값을 새 영상값으로 해석하지 않는다.
