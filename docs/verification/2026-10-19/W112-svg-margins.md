# W112 · 두 IR 페이지의 SVG 문자 여백

2026-10-19. **지정된 SVG 문자 위치 수정/내용과 계산 보존 검증 통과.** W107의 경계 검사에서 발견한 문제를 같은 배치의 W102/W106에 적용했다. 변경 전126개 실제 상태 중 모바일63개에서 복소 평면의 아래 제목과 회복 곡선의 위 제목 bounding box가 viewBox를 벗어났다. W102 위 제목은 y=−7.60545부터 시작했고 아래 제목은641.9011까지 나갔다. 전체 페이지 가로 넘침 검사만으로 잡지 못한 내부 SVG 여백 문제다.

복소 평면의 ‘실수 Re’ baseline635→628, 회복 곡선의 상단 단위 제목20→35를 각 페이지에서 수정했다. 글자/단위/축척/곡선/모형/입력값/문제 의미는 유지했다. [네 리터럴](W112-copy-edits.json)·[정확한 역치환 절차](W112-edit-audit.cjs)·[결과](W112-edit-audit.json)는1,085입력 중1,083개의 바이트 불변과 두 HTML의 정확한 이전 SHA 복원을 확인했다. 수식/과학적 계산 변경이 아니므로 이 수정만을 복제하는 Node 시험을 추가하지 않았다.

[변경 전 위상90상태](W112-before-phase-browser.json)·[전 강도36상태](W112-before-intensity-browser.json), [변경 후 위상90상태](W112-after-phase-browser.json)·[후 강도36상태](W112-after-intensity-browser.json)와 [비교](W112-browser-comparison.json)는 같은1920/390·45/18조건에서 전체 모델/출력/원표 SHA-256의 정확한 동일성을 확인했다. 지정한 두 제목 위치만 되돌린 전체 SVG 지문도 정확히 같다. 수정 후126개 상태의 모든 SVG 문자 경계는 viewBox 안에 있고 글자 최소11px 이상이다. 기존 독립 수치 기준/모든 원표 셀·곡선·벡터/선택점·키보드/초기화/예제/정오답도 새 파일에서 재실행했다. 기존 날짜의 브라우저 증거/스크린샷은 덮어쓰지 않았다.

[수정 후 모바일 복소 평면](W112-after-phase-base-390.png)·[위상 참조 곡선/지표](W112-after-phase-base-recovery-390.png)·[강도 정규화 모바일 비교](W112-after-intensity-reference-recovery-390.png)·[데스크톱](W112-after-intensity-base-1920.png)을 직접 읽었다. 두 제목이 내부 여백에 들어가며 나머지 지표와 범례도 유지된다.

처음에는 이전 날짜 보고서를 먼저 생성해 아직 없는 새 W112 HTML 링크 때문에 생성이 중단됐다. 그 뒤 통합 탐색도 준비되지 않은 inventory를 읽어 실패했다. 새 날짜의 일곱 보고서를 먼저 생성하고 이전 날짜의 한 보고서를 생성한 뒤, 전체246개 시험과450개 실제 통합 상태를 다시 실행해 통과했다. 중단된 첫 시도를 통과로 포함하지 않는다.

이 작업은 표시 여백의 수정이다. W102/W106의 회복/복소 연산/감도 정규화 물리 판정을 새 과학 모형 검토로 확대하지 않는다. [대상15개 입력](W112-versions.json)·[전체246개 시험](W112-tests.txt)·[통합 기록](checkpoint-W112-navigation.md)에 최종 범위를 고정한다. 실제 PSIR/임상·외부 전문가 검토 미시행이다. 다음W108의 포화 종료/회복 개발을 재개한다.
