# X13 기본 · metHb 상태표와 시간 해석의 한계 (W62)

2026-10-17. **원전 초록의 세 metHb 조건/정성 근거 읽기 범위 대상 버전 통과.** 새 정량 혈종 모형이나 환자 날짜/진단 성능의 검증이 아니다. 외부 전문가 검토 미시행. 구현·전체 시험·화면과 내용 검토는 따로 기록한다.

## 범위와 독립 주장 검토

비희석 세포내·비희석 free·희석 free metHb와 T1W-SE/T2W-SE/GRE근거밖의9상태다. 원전의 high-field spin-echo에 한정한 질적 고/등/저 경향이며 정량 T1/T2(ms)·농도(mM)·공통 영상 창의 숫자를 만들지 않는다. 비희석 free 상태의 T2W 등/약저는 저자 제안을 포함한다는 수준을 선택 화면과 비교표에 함께 표시한다.

[주장별 원전 대조](X13-source-review.md)에 H01–H06의 정확한 주장·구획/농도/가중 조건·근거 위치·제안/관찰과 추론을 독립 대조했다. 원전의 세 가지 상태가 같은 T1W 경향을 보일 수 있다는 관계에서 유일한 상태/날짜 역산이 아니라는 교육적 추론을 명시했다. 이것을 다른 원인의 T1고 진단 분류기나 임상 시간 추정 성능으로 확대하지 않는다.

Gomori 등1987 AJNR/1988 AJR의 [저자 초록](https://pubmed.ncbi.nlm.nih.gov/3257117/)은 검색 도구가 반환한 전체 초록을 읽었다. 직접 PubMed는 HHS 화면, AJNR PDF/AJR은403, PMC는captcha여서 본문을 읽었다고 기록하지 않는다. [Gomori 등1985 출판사 초록](https://pubs.rsna.org/doi/10.1148/radiology.157.1.4034983)은 직접 열어20혈종·1.5T·T1W/T2W SE와 넓은 시간/공간 경향을 확인했다. 두 출처의 범위를 합쳐 정량 날짜 모델을 만들지 않는다.

## 도식·표·정답의 판정

[학습 페이지](../../hemorrhage_state_reading.html), [로컬 정성 자료](../../assets/hemorrhage-state-reading.js). 세포막 안/밖과 조밀/희석의 개념 도식은 점 수·간격·색이 실제 농도/적혈구 수·신호 강도의 비율이 아니라고 명시한다. 고/저의 숫자 밝기나 합성 임상 사진을 생성하지 않았다. 표는 원전의 SE 열을 유지하고, GRE를 선택하면 모든 상태의 선택 결과가 “이 표에서 예측하지 않음”으로 바뀐다.

T1W 고 경향의 다대일 관계, 비희석/희석 free 구별, 저자의 제안을 일반 법칙으로 바꾸지 않음, SE/GRE 조건과 날짜 역산의 한계를 본문·도식·표·예시/두 퀴즈에 적용했다. “세포외이면 항상T2고”와 “T1고이면 하나의 날짜”라는 오답이 왜 범위를 벗어나는지 피드백으로 설명한다. 기초 가중/물질 상태·질적 신호/이완시간을 구별했다.

새 과학 계산이 없어서 독립 수치 적분이나 구현을 그대로 복사한 단위 시험은 추가하지 않았다. 이 내용 판정의 근거는 H01–H06 원전 대조이며 기존 전체 Node 시험을 새 내용 검토의 대체물로 삼지 않았다.
