# X05 기본 · 농도와 T1/T2*의 GRE 신호 경쟁 (W58)

2026-10-17. **직접 정의한 선형 이완률과 이상적 spoiled GRE의 대상 버전 통과.** 실제 약제·투여량·환자 프로토콜/안전 처방의 검증이 아니다. 외부 전문가 검토 미시행. 전체 시험·탐색 결과는 별도 기록한다.

## 범위와 사전 기준

농도 C0/.25/.5/1/2/4mM, TE2/8/16ms, flip5/15/30°의 54조건이다. TR20ms, M0/PD1, 정확한 순간 RF·완전한 횡 spoiling, 각 농도에서 독립적인 정상상태, 잡음0이다. 농도 축을 bolus 주입 후 시간 축으로 읽지 않는다. R1=1+4C, R2*=25+20C(s⁻¹)를 직접 정의하며 두 기울기의 단위는 s⁻¹mM⁻¹다. T1/T2*(ms)=1000/R(s⁻¹)이다. 유효 r2*=20은 실제 T2 실험의 r2를 가져온 값이 아니다.

C06의 RF 직전 정상상태 종자화를 그대로 재사용한다. 공통 모형에 고정된 TE2ms/T2*40ms 감쇠를 제거한 RF 직후 진폭에 이번 TE/R2* 감쇠를 한 번 적용한다. 비교선은 같은 R1에서 농도에 따른 R2* 증가항만0인 가상 참조다. 실제 다른 약제 곡선이 아니다. 곡선의 161점은 C0…4mM의 0.025mM 간격이며, 신호 축0…0.5와 공통 M0=1을 고정한다. C0 기준도 선택한 TE/flip과 같게 둔다.

독립 기준은 기존 C06의 Rodrigues 회전·종이완 RK4·횡 reset·고정점 반복으로 RF 전 Mz를 구하고, 횡 ODE를 각 TE/T2*로 별도 적분한다. Product 정상상태 식이나 반환 신호를 reference 입력으로 쓰지 않는다. 사전 허용오차는 신호·비율1e−8, 이완률/시간 단위 변환1e−9다. 추가 감쇠 비 exp(−20C TE초), C0의 두 선 일치, 비단조 반례도 별도 검산한다.

## 근거와 제외 범위

[Rohrer 등2005 원전 초록](https://pubmed.ncbi.nlm.nih.gov/16230904/?dopt=Abstract)과 [원전 PDF](https://mriquestions.com/uploads/3/4/5/7/34572113/rohrer_relaxivity_00004424-200511000-00005.pdf)의 p2/p5를 직접 읽었다. 이완률 차이와 농도의 기울기, field·용매·선형 농도 범위에 따른 조건을 확인했다. 논문은 T1/T2 실험이며 본 모형의 r2*=20이나0…4mM의 실제 선형성을 검증한 자료로 쓰지 않는다. 숫자와 범위는 교육 예시로 직접 정의했다. GRE의 공통 반복/정상상태 가정은 [C06 검증](../2026-10-15/C06-physics.md)을 재사용한다.

실제 약제·혈관/세포 구획·exchange·실제 r2/r2* 관계·주입량/시간동태·환자 안전/최적농도·CNR/진단·subtraction/registration은 이번 범위가 아니다.
