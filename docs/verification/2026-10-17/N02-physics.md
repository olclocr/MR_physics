# N02 기본 · Peak 위치·면적·폭·TE 검증 (W45)

2026-10-17. **가상 단일 peak/연속 absorption 부분 모형 대상 버전 통과.** 실제 대사물·J결합/overlap·농도/진단은 미구현이다. 외부 전문가 검토 미시행.

## 대상과 사전 기준

[학습 페이지](../../spectral_peak_features.html)는3T/물4.7ppm 기준, 중심2/2.1/2.2ppm,초기 진폭0.5/1/2,T2*40/80/160ms,획득 전TE0/40/80/160ms의108조건이다. T2=200ms의 이상적 refocused TE 손실과 획득 시작 뒤T2*를 별도로 명시했다. T2*≤T2이고 추가 지수 탈위상을 가정하는 한계 모형이다. 실제 pulse나 echo 전체를 계산하지 않는다. TE0은 수학적 기준이다.

N01의 유한 복소 FID magnitude와 달리 무한 시간의 이상적 단일 지수에서2Re Fourier 적분으로 정의한 absorption이다. 이 규약에서 전체 면적은echo시작진폭A(TE)와 같다. 2배를 명시하고 자동 peak 정규화로 취급하지 않는다. 높이의 단위는상대신호·초,Hz주파수 적분 면적은상대신호,폭은Hz다. 고정 가로창은2.1ppm 기준±40Hz,세로창0–0.7이다. 수치는401표시 표본의최대/fit이 아닌 연속 모형의 정답이다.

[독립 기준](../../../tests/helpers/spectral-line-reference.cjs)은 복소 ODE를 시간 적분한 선형계의 소거법,시간영역 Simpson적분,주파수 구적,반높이 이분법을 사용한다. TE 진폭도0.01ms 이하 RK4 반복으로 구한다. [시험](../../../tests/spectral-line.test.cjs)과 [수집기](N02-numerical.cjs)는 지표/곡선/적분1e−8을 사전 기준으로 두었다.

## 근거와 독립 수치

[Kreis 등,2021 DOI10.1002/nbm.4347](https://pmc.ncbi.nlm.nih.gov/articles/PMC7887137/)의 저자 합의 문서 §2.1–2.3에서 복소 감쇠·진폭/면적·Lorentzian과 폭의 용어를 대조했다. 직접열기는captcha였고 원문 검색 결과에서식/내용을 읽었다. 합의 문서를 이 앱의 실험 검증으로 취급하지 않는다. 이 페이지의2Re 정규화와구간별TE/T2* 가정은 명시적으로 유도한 교육 모형이다.

[결과](N02-numerical.json), [화면 기준](N02-display-reference.json):108조건/43,308곡선 표본,15개 시간 적분에서 최대 지표차이9.04e−13,곡선1.91e−13,시간 적분2.76e−13으로 기준 통과다. 면적 구적은Lorentzian 꼬리를 포함한 전체 주파수 구간을tan변환으로 적분하고,표시 창 구적은 별도로 계산했다.

기본T2*80ms는면적1/높이0.16/FWHM3.978874Hz다. T2*40ms는면적1/높이0.08/폭7.957747Hz다. 진폭0.5/T2*160ms는높이0.16으로 같지만면적0.5/폭1.989437Hz다. TE80ms는면적0.670320/높이0.107251로 줄어도FWHM은3.978874Hz다. 기본표시창면적0.968363과전체1을 구별한다.
