# N03 후속 · voxel 내 주파수 분포와 linewidth (W54)

2026-10-17. **알려진 균일 공간 분포의 교육 모형 대상 버전 통과.** 실제 shim 최적화·환자 linewidth 품질 판정이 아니다. 외부 전문가 검토 미시행. 전체 회귀·연결 검증은 아래 별도 기록으로 구분한다.

## 대상과 사전 기준

[학습 페이지](../../mrs_field_linewidth.html)는 균일한1D box 폭10/20/40 mm, 잔여 주파수 기울기0/.5/1 Hz/mm, 균일 offset−10/0/10 Hz, 각 위치의 고유T2=80/160 ms의54조건이다. 단일 가상 종·위상0·잡음0이며 기준 주파수에 상대적인Hz다. 실제 대사물이나 field map이 아니다.

단위부피 평균으로 FID(0)=1, 연속 흡수선의 전체 주파수 면적1을 고정한다. 실제 voxel 부피 변화의 신호량/SNR 효과를 계산하지 않는다. 각 위치의 고유 T2 이완과 정적 field 분포를 별도로 계산하며 추가 T2* 지수 감쇠를 중복 적용하지 않는다. 유한 FID/DFT 크기와 연속 흡수선을 구별한다.

[모형](../../assets/mrs-field-distribution-model.js)은 공통 free의 균일 offset/이완, N02의 Lorentz line을 수정 없이 재사용한다. 균일 주파수 분포의 sinc와 arctan convolution, 반높이 해석식 FWHM=2√(a²+h²)를 명시한다. a=gL/2, h=1/(2πT2초)다. 공간 퍼짐의 FID가 비단일 지수일 때 폭을 단순한 독립 조직 T2*로 해석하지 않는다.

[독립 기준](../../../tests/helpers/mrs-field-distribution-reference.cjs)은 공간 변수2048분할 Simpson으로 복소 FID와 Lorentz line을 각각 적분한다. 반높이는60회 이분 root, 표시창 면적은4096분할 주파수 적분이다. [시험](../../../tests/mrs-field-distribution.test.cjs)/[수집기](N03-field-numerical.cjs)의 사전 기준은 FID/흡수선/높이/면적1e−9, FWHM1e−7 Hz다.

## 근거와 수치 결과

[Juchem 등2021 저자 합의문, DOI10.1002/nbm.4350](https://pubmed.ncbi.nlm.nih.gov/32596978/)의 원전 초록을 직접 읽어 B0 균일성·shimming과 MRS linewidth의 연결을 확인했다. Epub2020/issue2021을 구별했다. DOI 직접 열기는 오류여서 전체 본문 직접 열람으로 기록하지 않는다. 이 교육 수치/균일 분포 해석식은 명시한 모형에서 유도하고 독립 적분으로 확인한다. 임상 허용 linewidth나 실제 shim 설정을 제공하지 않는다.

[수치 결과](N03-field-numerical.json), [화면 기준](N03-field-display-reference.json):54조건/16,254 FID표본/21,654주파수표본에서 최대 FID차3.96e−11, 흡수선2.91e−11, 높이3.00e−15, 폭9.80e−10 Hz, 면적5.56e−15로 기준 통과다.

기본20mm/.5Hzmm/T280은 ±5Hz, 높이.075892240신호·s/FWHM10.762501Hz/첫 상쇄 영점100ms다. Offset+10은 높이/폭이 같지만 표시창 면적은.974598385→.973523875로 달라진다. 폭40mm에서는 ±10Hz/높이.043749041/폭20.391945Hz/첫 영점50ms다. g0은 고유 Lorentz 높이.16/폭3.978874Hz이고 추가 공간 영점은 없다. 전체 정규화 면적1과 유한창 면적을 구별한다.

## 통합 내용 판정

재부팅 후 [임시 버전](N03-field-work-in-progress-versions.json)의14개 파일 SHA-256을 실제 파일과 대조해 모두 일치함을 확인했다. 계산·학습 페이지·시험·독립 기준·기존108상태 결과는 그대로이므로 그 검증을 재사용한다. [PubMed 원전 초록](https://pubmed.ncbi.nlm.nih.gov/32596978/)을 다시 읽어 공간 B0 균일성/linewidth 연결과 Epub2020·issue2021 날짜를 확인했다. 아래 해석식의 근거는 논문에 수록된 특정 임상 수치가 아니라 명시한 모형의 독립 적분과 유도다.

| 검토 항목 | 독립 확인·관찰과 적용 범위 | 판정 |
|---|---|---|

이번 내용 검토에서 추가 계산·설명 결함은 발견하지 않았다. 이전 target closed 과정과 중단 기록은 보존하며 통과 증거로 확대하지 않는다. 관측 공간 페이지에는 후속 링크만 추가하고 기존 공간 적분·정규화·조작은 바꾸지 않았다.
