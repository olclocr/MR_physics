# M02 후속 · R1 분배와 ECV 기본 모형 (W55)

2026-10-17. **알려진 평형 분배의 교육 모형 대상 버전 통과.** 실제 환자 ECV/조영제 투여/촬영 프로토콜 또는 임상 정상 범위를 제공하지 않는다. 외부 전문가 검토 미시행. 전체 회귀·탐색 결과는 별도 기록으로 연결한다.

## 대상과 사전 기준

정답ECV20/30/50%, 평형 혈장농도0/.5/1/2mM, 계산용Hct25/40/55%의36조건이다. 실제모형Hct40%, native T1조직1000/혈액1500ms, 두 매질의 동일 유효relaxivity4s⁻¹mM⁻¹를 예시값으로 고정한다. 세포내 조영제0·혈장/조직 세포외 농도 동일·빠른교환의단일유효R1·잡음0이다. 농도0은ΔR1혈액0이므로λ와ECV는정의불가다.

1cm³=1000mm³, 1mM=1µmol/cm³를 사용한다. 구획의 양/단위부피 평균 농도와 R1을 구별하고 실제 조영농도·용량이나 임상 relaxivity로 해석하지 않는다. 독립1mm³ 부피 적분과 종자화RK4로 얻은1초 회복값에서 log 역산한 R1/T1을 대조한다. 사전 허용오차는 R1 1e−9s⁻¹, T1 1e−6ms, 분율/양1e−9다. 그래프 고정축0…5s⁻¹/분율막대0…100%, 원표와정답/실제두화면을 별도 확인한다.

## 근거

[Messroghli 등2017 합의문, DOI10.1186/s12968-017-0389-8](https://link.springer.com/article/10.1186/s12968-017-0389-8)의 Table1과 T1/ECV 원리 부분을 직접 읽었다. T1 역수의 전후 변화 비율·Hct 보정·퍼센트 표기를 확인했다. PMC 웹은captcha였으나 출판사 본문 및 EuropePMC fullTextXML로 확인했다. 임상 투여·측정 시점·참고 범위는 이 모형에 복사하지 않는다. 교육용구획/유효relaxivity값과 다음의 보존식은 별도 가정이며 논문의 환자 실험을 재현하지 않는다.

## 독립 계산과 반례

[학습 페이지](../../ecv_r1_partition.html), [순수 모형](../../assets/ecv-partition-model.js), [독립 기준](../../../tests/helpers/ecv-partition-reference.cjs), [시험](../../../tests/ecv-partition.test.cjs). 독립 기준은 각1cm³를1mm³ 구획1000개로 나누어 물질량을 합하고, 1초의 종자화 회복을5000단계 RK4로 적분한 뒤 −ln(1−M)에서 R1을 역산한다. 추정 ECV는 혈액 평균 물질량/가정 혈장 부피로 혈장 농도를 얻고 조직 물질량을 그 농도로 나누는 보존식으로 확인한다. Product의 infer/forward 함수를 재사용하지 않는다.

[수집기](M02-ecv-numerical.cjs), [수치 결과](M02-ecv-numerical.json), [화면 기준](M02-ecv-display-reference.json):36조건과1476곡선점을 비교했다. 최대 R1차2.16e−13s⁻¹, T1차7.17e−12ms, 양/부피차8.89e−16, 비율/분율차6.79e−14, 곡선의R1차2.16e−13으로 사전 기준을 통과했다.

기본 정답30%/농도1mM/입력Hct40%는 조직/혈액의 평균 농도.3/.6mM, ΔR1 1.2/2.4s⁻¹, λ.5, 계산ECV30%다. Post T1은 각각454.545455/326.086957ms다. 농도2mM이면ΔR1은2.4/4.8s⁻¹로 두 배이고 post T1은294.117647/182.926829ms로 바뀌지만 계산 ECV는30%다.

같은 T1 자료에 입력Hct25%를 사용하면37.5%,55%면22.5%다. 실제모형Hct40%·구획·T1은 바뀌지 않으며 계산−정답은 각각+7.5/−7.5 percentage points다. 농도0에서는 native/post가같고λ/ECV/bias는null이다.0%로 대체하거나 과도하게 정규화하지 않는다. Native/post T1의 차이가 아니라 역수의 차이이며 계산은 반올림 전 값을 사용한다.
