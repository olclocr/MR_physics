# AI02 · 벤더 공개 자료 읽기 검토 (W52)

2026-10-17. **공개 역할·출처 읽기 페이지의 대상 버전 통과.** 알고리즘 재현/제품 성능·기관별 지원/임상 우열 검증은 아니다. 외부 전문가 검토 미시행.

## 대상과 검토 방법

[페이지](../../vendor_ai_reading.html)와 [로컬 자료](../../assets/vendor-ai-reading.js)는 네 벤더의8명칭을 다룬다. AIR Recon DL, Deep Resolve Gain/Boost/Sharp, SmartSpeed/SmartSpeed Precise, MRI AiCE/PIQE다. 전체/잡음/표본·가속 조합/행렬·선명도의 읽기 필터이며 기능 전체나 성능의 점수화가 아니다. 새 과학 계산·AI 실행·합성 임상 사진은 넣지 않았다.

[주장별 원문 대조](AI02-source-review.md)에 직접 읽은6공식 자료, 위치·문서 날짜·미확인 범위를 기록했다. 제품 명칭/문서 코드/발행일/확인일/설치 software 버전을 분리했다. 설치 버전은8개 모두 미확인이라고 표시한다. 문서의 개발 예정이나 특정 범위의 예시를 최신 전체 지원 보장으로 바꾸지 않는다.

물리 검토는 역할·입력/처리 단계·획득/표시 행렬·data consistency와 정답의 구별·서로 다른 성능 과제·퀴즈 정답에 대해 원문과 기존 AI01/AI03/A03 모형을 대조했다. Gain을 제품군 이름만으로 모두 신경망이라고 쓰지 않고, PIQE의 문서가 구별한 행렬 확대와 AI 처리 단계를 유지했다. 원문 표기의 과장된 보편 성능 표현은 옮기지 않고 임상 우열을 추정하지 않았다.

## 실제 화면과 수정

[브라우저 절차](AI02-browser-check.js), [결과](AI02-browser-check.json)는 Chrome155.0.8059.82, 1920×1080/390×844의8필터 상태다. 전체8명칭/잡음7/가속3/선명도4의 정확한 행과6출처, 버전 미확인 표시, Home/End/ArrowUp·초기화/세 예시·정답/오답·수식 펼침을 확인했다. 모바일 표의 가로/세로 이동과 JS오류/화면 가로 넘침도 확인했다. 이 수는 문서 분류의 개수이며 제품 성능 수치가 아니다.

첫 표의 자동 열 배분에서 출처 열이 좁은 것을 직접 보고 고정 비율/최소1000px로 수정했다. 두 화면의 모든 상태를 다시 실행했고 [데스크톱 전체](AI02-all-1920.png), [모바일 오른쪽](AI02-table-right-390.png)을 직접 열었다. [선명도 모바일](AI02-sharpness-390.png), [펼친 모바일](AI02-expanded-390.png)도 보존했다. 본문은 화면 안에 있고 큰 비교 표만 이름 붙인 영역에서 스크롤된다.

## 판정과 재현

공식 설명의 역할·조건·날짜/버전·근거 유형과 교육적 반례의 정합성을 검토해 해당 읽기 범위 통과로 판정한다. 새 수치 모형이 없는 가역적 페이지여서 구현을 그대로 복제한 새 단위 시험은 만들지 않았다. [기존 전체 시험](W52-tests.txt), [SHA-256](AI02-versions.json), [전체 연결/화면](checkpoint-W52-navigation.md), [링크 감사](checkpoint-W52-link-audit.json)를 보존한다.
