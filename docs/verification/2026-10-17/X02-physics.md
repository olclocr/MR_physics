# X02 기본 · Slab 유입과 반복 RF 포화 (W61)

2026-10-17. **이상적 균일 slab/TE0 RF 직후 진폭 범위 대상 버전 통과.** 실제 TOF 혈관 영상·프로토콜이나 환자 혈액값의 검증이 아니다. 외부 전문가 검토 미시행. 전체 회귀/탐색은 별도 근거로 연결한다.

## 범위와 사전 기준

v0/5/10/20cm/s, TR10/20/40ms, flip10/30/60°의36조건이다. Slab0…30mm, T1=1200ms/M0=1, 정확한 순간 균일 RF·완전 spoiling, TE0·잡음0을 고정한다. Slab 밖 spin은 RF를 겪지 않은 평형이다. +z plug flow와 같은 T1의 정지 참조를 비교하며 각 RF 시점에 충분히 반복된 공간 profile을 관측한다.120깊이 중점(0.125…29.875mm)을 표시 표본으로 사용하고 voxel/PSF 평균이라고 부르지 않는다.

이동 거리 d(mm)=v(cm/s)×10×TR(ms)/1000, 과거 RF 횟수 n=floor(z/d)다. C06의 q=exp(−TR/T1)cosα와 RF 직전 정상상태 Mz_ss를 재사용해 Mz_before=Mz_ss+(1−Mz_ss)qⁿ을 구한다. 이는 RF/회복 점화식과 같다. 현재 RF는 n에 포함하지 않으며 n0이면 RF 직전 Mz=1이다. v0은 분모0이나 유한 횟수로 취급하지 않고 무한 반복 정상상태다. TE0의 신호=Mz_before sinα이며 C06의 고정 TE 감쇠는 사용하지 않는다.

독립 기준은 각 세계선에서 과거80RF의 실제 위치를 검사해 slab 안 RF만 적용하고 Rodrigues/RK4 회복을 누적한다. Product의 floor/폐형식 점화식을 reference에 사용하지 않는다. 최대 필요한 과거 RF는59회로80회가 전체 이력을 덮는다. 정지는 별도 독립 고정점 반복으로 구한다. 신호/자화/비율1e−8, 과거 RF 횟수 정확 일치를 사전 기준으로 둔다. 모든 자화/신호는0…1이며 중점의 횟수 경계 모호성이 없는 메뉴다.

## 근거와 제외 범위

[Kodama·Watanabe1997 저자 초록](https://pubmed.ncbi.nlm.nih.gov/9481591/)의 flow phantom 결과에서 TR·flip·속도에 따른 포화와 별도의 위상 분산/맥동 효과를 확인했다. 검색 도구가 반환한 전체 저자 초록을 읽었고 직접 페이지 열기는 HHS 링크만 반환했다. 원전 본문을 읽었다고 기록하지 않는다. 실험의1.5T/실제 phantom 성능을 이 모형의 수치 검증으로 확대하지 않는다. T1·속도·TE0은 교육용 정의다. [C06 검증](../2026-10-15/C06-physics.md)의 RF/정상상태 개념을 재사용하며 [X01 위상](X01-physics.md)과 이번 포화를 구별한다.

실제 혈액/조직별값·B0/gradient phase/T2*·B1/수신·속도 분포/난류·역류/재순환·실제2D/3D TOF/MIP·프로토콜/진단은 제외한다.120점 평균은 표시 요약이고 실제 영상 전체의 신호나 CNR이 아니다.
