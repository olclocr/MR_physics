# AI03 기본 · 작은 구조와 질감 평가 검증 (W51)

2026-10-17. **명시한 대리처리와 알려진 쌍의 교육 모형 대상 버전 통과.** 실제 학습 모델·환자 검출력·임상 SNR 검증은 아니다. 외부 전문가 검토 미시행.

## 대상과 독립 기준

[학습 페이지](../../structure_texture_evaluation.html)는 N64/FOV64 mm의 단계 원본, j32의 점 0.15, 질감 0.06 cos(2π·12j/64)를 사용한다. 전표본 영상 영역 Re/Im σ0/.05/.15, seed A/B, identity/평활/선명도/Haar 1회의 24조건이다. AI01의 k-space 잡음과 입력 영역을 명시적으로 구별한다. 점 없는 쌍과 질감 없는 쌍에도 동일 잡음을 넣은 뒤 같은 처리를 적용한다.

[모형](../../assets/structure-evaluation-model.js)은 기존 AI01 처리와 Q04 RNG를 수정 없이 재사용한다. [독립 기준](../../../tests/helpers/structure-evaluation-reference.cjs)은 별도 radix FFT와 필터 주파수 응답, 명시적 Haar 기저 행렬로 계산한다. [고정 입력](../../../tests/helpers/structure-evaluation-noise.json)은 두 seed의 128개 정규 입력이다. 새 잡음 분포 검증이나 평균 성능 추정으로 확대하지 않는다. [시험](../../../tests/structure-evaluation.test.cjs)과 [수집기](AI03-numerical.cjs)의 사전 기준은 신호/지표 1e−9다.

## 근거와 수치 판정

[Antun 등, 2020, DOI10.1073/pnas.1907377117](https://pubmed.ncbi.nlm.nih.gov/32393633/)의 원전 초록과 그림 설명, 저자 본문 검색 결과에서 입력 교란과 작은 구조 변화의 별도 평가를 확인했다. PMC 직접 열기는 captcha였으며 전체 본문 직접 열람으로 기록하지 않는다. 연구에서 시험한 신경망의 결과를 모든 모델로 일반화하지 않으며 이 페이지는 해당 신경망/실험을 재현하지 않는다. [fastMRI 저자 저장소](https://github.com/facebookresearch/fastMRI)는 참조 자료와 평가의 연결 자료다.

[수치 결과](AI03-numerical.json), [화면 기준](AI03-display-reference.json): 24조건/7,680복소값에서 최대 차이 1.11e−15, 지표 2.22e−15로 기준 통과다. 기본 σ.15/평활/A에서 입력 NRMSE44.318011%→출력29.893239%, 점 정점50%, 국소 대비25%, 질감 진폭69.134172%다. 잡음0/선명도에서 출력 오차13.144167%, 점 정점150%/국소 대비175%/질감130.865828%다. 과장된 반응을 정확한 복원으로 부르지 않는다. Haar/σ.15/B의 점 정점55.020106%는 동일 조건 A의94.469747%와 다르며 비선형 문턱과 맥락의 영향을 보인다.

점 반응의 전체 범위는 −.0375… .225, 질감 반응은 ±.078519498로 고정 창 안이다. 점의 국소 대비는 정점에서 두 이웃 평균을 뺀 값을 원래 .15로 나눈다. 질감 비율은 알려진 cos에 대한 투영이며 전체 주파수 해상도나 단일 영상 SNR이 아니다. 복소 전체 NRMSE와 실수 쌍 차이 지표를 구별했다. 선형 쌍에서는 동일 잡음의 상쇄를 독립적으로 검산했다.
