A02 움직임 · 획득 순서 · 이상적 gating 검증 (W35)

2026-10-17. 대상 모형 통과 — 순간 q표본 사이의1D 강체 이동 범위. 외부 전문가 검토 미시행. A02의 실제2D/호흡·ECG/navigator 구현은 남아 있으며 전체 임상 모형 완료로 해석하지 않는다.

대상 · 사전 기준

학습 페이지는 N32/FOV160mm/5mm 격자의 두 점(−20mm:1,+35mm:0.6)을 함께 이동시킨다. 모든 q−16…15를 각각 순간에 하나 읽는다. 슬롯250ms, 주기8슬롯/2s는 교육 예시다. 주기 δ=A[1−cos(2πs/8)]/2, 한 번 이동은 slot16부터δ=A다. A0/5/10/15/20mm, linear/centric, 주기 모형에만 phase0 gating을 허용한다. centric 순서는0,−1,+1,…,−15,+15,−16이다.

실제 이동 좌표에서 각 q의 신호를 직접 합성하고 inverse1/32로 복원한다. 같은 수락 시각의 순간 전체 복소 영상을 평균한 결과도 별도로 표시한다. 복소 NRMSE 기준은 이동 전 정적 영상이며 움직이는 물체의 유일한 임상 정답이라는 뜻이 아니다. 두 그림 모두 magnitude 창0–1.2 고정이다.

독립 기준은 정적 격자의 radix-2 FFT, 이동의 위상 변조 커널, 그 커널과 원래 두 점의 공간 원형 convolution이다. 시간 사건은 반복문 대신 ungated slot=i/gated slot=8i의 닫힌 수열로 대조한다. 복소 자료·영상·평균·이동 거리의 절대 오차1e−10, 정수 q/수락/대기와 종료 시간의 정확 일치를 사전 기준으로 정했다. 실제 브라우저는 전체30조건을 두 화면에서 확인한다.

실제 확인한 근거

  • Wood와 Henkelman, 1985, DOI10.1118/1.595782: 원전 초록에서 주기 운동 phantom·simulation, 번짐과 phase 부호화 방향 ghost의 관찰을 확인했다. 공개 PDF는 스캔 본문으로 텍스트를 읽지 못했으므로 전문의 수식/그림을 확인했다고 기록하지 않는다.
  • Schultz 등, 1984, DOI10.1148/radiology.152.1.6729101: 원전 초록에서 움직임 ghost와 gating에 따른 영상 개선/시간 증가를 확인했다. 초안에 잘못 적은 저자명을 서지 대조 후 Schultz로 수정했다.

여기의 파형·시간·순서·phase0 완전 수락은 직접 만든 모형이며 원전의 실제 환자/phantom 실험 수치를 사용하지 않았다. 핵심 정량 주장은 Fourier 이동 정리와 독립 convolution으로 확인했다.

독립 결과

수집기, 결과, 화면 기준값, 독립 FFT/공간 convolution, 시험을 사용했다. 30조합/2,880개 복소 계수·영상 표본에서 최대 오차는 계수2.78e−15, 영상1.17e−15, 순간 복소 평균1.20e−15, 이동 거리1.78e−15mm였다. 전체 조건이 사전 기준을 통과했다.

기본 주기/linear의 복소 NRMSE는116.762124%, 순간 복소 평균은87.379960%다. centric는 재구성116.760103%로 달라지지만 순간 평균은 동일하다. 오차 수치가 비슷하다고 복소 영상 자체가 같은 것은 아니며 각 pixel도 비교했다. 한 번 이동/linear는100%, 순간 평균70.710678%다. A0 또는 이상적 gated 조건은 정적 기준과 일치한다.

ungated는32슬롯/8s, gated는32수락+217대기=249슬롯이다. 마지막 수락 시작62s, 마지막 슬롯을 포함한 종료62.25s가 정확히 일치했다. phase0 이외의 대기 슬롯에는 q가 배정되지 않는다. gate를 켠 뒤 한 번 이동으로 전환하면 부적합한 조합을 자동 해제하고 설명한다.

실제 브라우저 · 내용 검토

절차와 결과는 Chrome155.0.8059.82,1920×1080/390×844의60상태다. 정적/재구성/평균 canvas의5,760개 pixel 중심, 복소값·오차·magnitude SVG·32수락점·최대249개 사건 표·q순서·종료 시간을 독립 기준값과 대조했다. 최대 SVG 좌표 오차7.67e−6px로 허용1e−4px 이내다. ArrowRight/Home/End·초기화·세 예시·문제의 정답/오답·gating 해제/disabled·펼친 표를 확인했다. JS 오류·페이지 가로 넘침은 없었다.

데스크톱 주기 모형, 모바일 gated, 모바일 한 번 이동, 중앙 q 순서를 직접 확인했다. 기본 상태에서는 주황 곡선과 회색 평균이 다르고 gated에서는 정적 기준과 겹친다. δ축은0–20mm, 영상 창은0–1.2로 유지된다.

단위·위상 부호·주기 격자·q/시각 대응·동일32줄·복소 평균과 magnitude 평균의 차이·정적 기준 NRMSE·위치 일치를 전제로 한 gating·유한 대기 시간·실제 TR/임상과의 구분·두 문제 정답을 검토했다. 주기 이동이 모든 조건에서 단순한 고정 간격 복제만 만든다는 과도한 주장은 하지 않는다. 이 페이지의 y축1D 모형을 실제2D ghost 방향 전체의 검증으로 확대하지 않는다.
