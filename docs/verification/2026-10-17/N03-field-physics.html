N03 후속 · voxel 내 주파수 분포와 linewidth (W54)

2026-10-17. 알려진 균일 공간 분포의 교육 모형 대상 버전 통과. 실제 shim 최적화·환자 linewidth 품질 판정이 아니다. 외부 전문가 검토 미시행. 전체 회귀·연결 검증은 아래 별도 기록으로 구분한다.

대상과 사전 기준

학습 페이지는 균일한1D box 폭10/20/40 mm, 잔여 주파수 기울기0/.5/1 Hz/mm, 균일 offset−10/0/10 Hz, 각 위치의 고유T2=80/160 ms의54조건이다. 단일 가상 종·위상0·잡음0이며 기준 주파수에 상대적인Hz다. 실제 대사물이나 field map이 아니다.

단위부피 평균으로 FID(0)=1, 연속 흡수선의 전체 주파수 면적1을 고정한다. 실제 voxel 부피 변화의 신호량/SNR 효과를 계산하지 않는다. 각 위치의 고유 T2 이완과 정적 field 분포를 별도로 계산하며 추가 T2* 지수 감쇠를 중복 적용하지 않는다. 유한 FID/DFT 크기와 연속 흡수선을 구별한다.

모형은 공통 free의 균일 offset/이완, N02의 Lorentz line을 수정 없이 재사용한다. 균일 주파수 분포의 sinc와 arctan convolution, 반높이 해석식 FWHM=2√(a²+h²)를 명시한다. a=gL/2, h=1/(2πT2초)다. 공간 퍼짐의 FID가 비단일 지수일 때 폭을 단순한 독립 조직 T2*로 해석하지 않는다.

독립 기준은 공간 변수2048분할 Simpson으로 복소 FID와 Lorentz line을 각각 적분한다. 반높이는60회 이분 root, 표시창 면적은4096분할 주파수 적분이다. 시험/수집기의 사전 기준은 FID/흡수선/높이/면적1e−9, FWHM1e−7 Hz다.
