# 게시 승인과 야간 개발 일정

2026-10-17 Asia/Seoul. 사용자가 현재까지의 작업을 커밋·푸시·GitHub Pages 게시하고, 이후 사용 가능한 한도까지 개발을 계속하도록 승인했다. 후속 게시 시각은 **2026-10-18 01:05 / 06:30 / 11:55 한국시간**이며 각 게시 후 개발을 재개한다. 이 승인 범위에서는 게시를 위해 다시 승인을 요청하지 않는다. 강제 push·사용자 변경 삭제·비밀값 게시·사용량 초기화는 승인에 포함되지 않는다.

일회 heartbeat 예약 세 개는 현재 대화에 연결했다. 현재 로드맵 W55부터 진행 중 작업을 우선 재개하며, 작업별 구현·독립 물리 검산·실제 데스크톱/모바일 검증·기록을 계속한다. 한 요청당 한 작업이라는 기본 단위보다 이번 사용자의 지속 개발 지시를 우선한다. 한도 수치를 반복 조회하지 않는다.

게시 시에는 저장소의 safe-github-sync 절차로 원격 상태와 staged 파일을 검토하고 시험을 확인한다. 완료와 미완료 체크포인트를 구분하며 검증하지 않은 내용을 완료로 올리지 않는다. 기존 GitHub Pages는 main의 /docs를 사용하는 설정이다. 공개 주소: https://olclocr.github.io/MR_physics/ . 실제 배포 성공과 새 학습 페이지의 응답을 확인한 뒤 게시 완료로 기록한다.

Windows 절전/자동 재시작 방지의 실행 파일·백업·상태는 공개 저장소에서 제외한 `.local-operations/`에 둔다. 마지막 예약의 게시와 앞선 두 예약의 결과를 확인한 뒤 `scheduled-publications-complete` 파일을 만들어 임시 보호를 해제한다. 설정이 실패했거나 한도가 막히면 수행 사실과 정확한 재개 지점을 남긴다. 로컬 실행에는 PC 전원·네트워크와 Codex 앱 유지가 필요하다.
