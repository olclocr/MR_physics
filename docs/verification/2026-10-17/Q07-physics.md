# Q07 SMS · slice 분리 · CAIPI 검증 (W33)

2026-10-17. **대상 버전 통과 — 두 slice/coil의 명시한 선형 모형 범위.** 외부 전문가 검토 미시행. 실제 RF·장비·임상 성능 검증으로 확대하지 않는다.

## 대상과 사전 기준

[학습 페이지](../../sms_slice_separation.html)의 N32/FOV160mm 두 slice·두 coil 선형 모형이다. 모든 32개 q를 획득하고 두 번째 slice만 d0/16 pixel 순환 이동한다. 초기 위상·잡음·이완은 0/없음이다. 감도 열은 길이 1이고 실수다. 공간 감도 a(j)=θ+10cos(2πj/32)°와 균일 감도를 비교한다. slice1 감도 [cos a,sin a], slice2 감도 [sin a,cos a]이다.

정확한 감도 또는 θ+5° 오보정으로 역산한다. 실제 감도의 특이성과 가정한 감도의 가역성을 별도로 표시한다. 측정 잔차는 가정한 감도에 대한 값이고, T=Ĉ⁻¹C의 비대각 RMS는 이 페이지가 정의한 교육용 leakage 계수다. 실제 임상 leakage 지표나 성능을 재현하지 않는다.

독립 공간 중첩→radix-2 FFT와 Householder QR, 각도 차이로 계산한 g를 사용한다. 368개 UI 조합, 모든 복소 자료·분리값·전달계수의 절대 오차 1e−10, g 상대 오차 1e−10을 사전 허용 기준으로 정했다. 실제 브라우저는 1920×1080/390×844에서 대표·경계·특이점·오보정·초기화·키보드·모든 그림/수치를 대조한다.

## 근거와 적용 범위

- [Breuer 등, 2005 원전](https://doi.org/10.1002/mrm.20401): CAIPIRINHA의 원리와 서지 확인. 수치/그림을 복제하지 않았다.
- [Setsompop 등, 2012 원전](https://pmc.ncbi.nlm.nih.gov/articles/PMC3323676/): 원문 [공개 PDF](https://mriquestions.com/uploads/3/4/5/7/34572113/blipped_cipirinha_setsompop_et_al-2012-magnetic_resonance_in_medicine.pdf)의 초록·도입·이론에서 위상 부호, FOV/2 이동, 공간 감도와 g의 의존성, 면내 가속과 SMS의 차이를 확인했다. 실제 blipped gradient를 이 페이지에서 계산했다고 주장하지 않는다.

phantom, 감도 함수, 각도 범위, 독립 2 s 블록의 4→2 묶음 산수는 직접 만든 예시다. 실제 RF/profile/SAR·spin history·공간적 calibration·잡음 상관·장비 시간·SNR·임상 진단은 제외한다. 같은 slice TR을 2 s라고 가정한 시간표가 아니다.

## 독립 수치 확인

[재현 수집기](Q07-numerical.cjs), [결과](Q07-numerical.json), [화면용 독립 기준값](Q07-display-reference.json), [독립 QR/FFT](../../../tests/helpers/sms-reference.cjs), [관련 시험](../../../tests/sms.test.cjs)을 사용했다. 368조건/11,776개 겹침 쌍에서 최대 오차는 Fourier 1.07e−14, 겹친 복소 신호 2.06e−15, 분리 신호 2.91e−12, 전달계수 3.43e−12였다. g 상대 오차 5.63e−14, 정확한 감도의 복원 NRMSE 최대 4.05e−14, 완전 분리 가능한 조건의 측정 잔차 최대 2.26e−14로 사전 기준을 통과했다. 특이점은 임의의 역산값 대신 분리 불가로 처리하는지 따로 대조했다.

기본 공간 감도/θ20°의 RMS g는 1.450787, 최대 g는 2다. FOV/2 이동 후 둘 다 1.305407이다. 균일 감도는 이동 전후 g=1.305407로 동일하다. 균일 θ45°는 이동 후에도 32위치 모두 식별 불가다. 기본 상태의 θ+5° 오보정은 복원 NRMSE 16.327198%, 측정 잔차 1.19e−15, 두 방향 leakage 계수 RMS 0.163840이다. 이는 작은 잔차가 정확한 slice 분리를 보장하지 않는 반례다.

g를 1/sqrt(1−dot²)로 계산하면 열이 거의 평행할 때 소수점 상쇄에 민감해진다. 같은 단위 열 모형의 1/|det C|를 사용하도록 안정화하고 전체 범위를 다시 검산했다. 독립 역산은 Householder QR로 수행한다.

## 실제 화면과 내용 검토

[브라우저 절차](Q07-browser-check.js)와 [결과](Q07-browser-check.json)는 Chrome 155.0.8059.82, 로컬 HTTP, 1920×1080/390×844에서 96상태를 기록한다. 정답·coil 합·분리 영상의 18,432개 pixel 중심, 위치별 g와 실수 신호 SVG, 두 leakage 계수 표, 복원 오차 표시를 독립 기준값과 대조했다. Canvas 회색 값은 고정 창 0–1.6과 일치한다. SVG는 소수점 좌표 저장을 고려한 1e−4 px 기준을 사용했다. 초기화·세 예시·range의 ArrowRight/Home/End·두 문제의 정답/오답·접힌 수식과 표를 펼친 화면을 확인했다. JS 오류와 페이지 가로 넘침은 없었다.

[데스크톱 기본 화면](Q07-base-1920.png), [모바일 오보정](Q07-leakage-390.png), [모바일 특이점](Q07-singular-390.png), [모바일 실수 곡선](Q07-leakage-signal-390.png)을 직접 확인했다. 작은 화면에서 두 열의 제목 줄바꿈 때문에 영상 높이가 어긋나는 문제는 제목 최소 높이를 맞춰 수정했다. 모바일 SVG 글자 크기가 줄지 않도록 viewBox를 실제 폭에 맞췄다.

설명·식·수치·그림·문제의 다음 항목을 대조했다: q/k의 단위, forward/inverse 정규화, 음의 위상 부호와 +d 이동, 원래 좌표 복귀, 길이 1의 감도 열, 실제/가정한 감도 구분, g의 잡음 가정, 특이점 처리, 오보정 T와 잔차, 고정 표시 창, MB와 면내 가속 구별, 이상적 묶음 수와 실제 TR/시간의 구별. 문제 정답은 균일 특이점과 오보정 반례에 일치한다.

## 버전 · 시험 · 남은 한계

[대상 SHA-256](Q07-versions.json)의 로컬 미커밋 버전이다. [전체 회귀 시험](W33-tests.txt)과 [전체 링크/화면 점검](checkpoint-W33-navigation.md)을 별도 기록한다. 구현 시험·브라우저·이 내용 판정은 외부 전문가 검토를 대신하지 않는다.
