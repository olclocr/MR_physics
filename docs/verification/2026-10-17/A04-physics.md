# A04 Chemical shift 위치 이동 · 혼합 상쇄 검증 (W37)

2026-10-17. **대상 버전 통과 — Q02/F01을 재사용한 분리된 두 실험 범위.** 외부 전문가 검토 미시행. 두 현상이 동시에 나타나는 임상 영상을 합성하거나 검증한 결과가 아니다.

## 대상 · 사전 기준 · 실제 근거

[학습 페이지](../../chemical_shift_artifacts.html)는 서로 다른 정규화의 두 실험을 명시적으로 구별한다. 실험1은 물−30mm/지방+30mm의 순수 점 진폭1, N64/FOV240mm/3.75mm, BW50/100/200/400/800Hz/pixel, polarity±1이다. Q02의 점 응답을 이동해 각 점의 magnitude를 따로 표시하며 혼합하지 않는다. TE 전역 위상은 순수 점 magnitude를 바꾸지 않는다. 표시 곡선 간격1mm는 획득 pixel 크기가 아니다.

실험2는 F01의 한 voxel 물/지방 복소 합이다. f0/.5/1, 공통T2*40ms, TE0/첫OP/첫IP/3/6ms를 사용한다. 벡터·곡선은 공통 감쇠를 나눈 신호이며 실제 감쇠 포함 S도 출력한다. f는 신호 비율이며 PDFF가 아니다. B0는1.5/3T로 두 실험에 공통이다. 정확한 IP/OP 선택은 B0 변경 때 TE도 조정하고3/6ms는 고정한다. BW/polarity는 실험1, TE/f는 실험2에만 적용된다.

지방−3.5ppm, γ̄42.57747892MHz/T, S의 exp(−i2πΔft) 부호와 Q02의 Δx=polarity×Δf/(Hz/pixel)×3.75mm를 확인한다. 독립 SI gradient 위치 역산/닫힌 Dirichlet와 물·지방 실수/허수 RK4 ODE를 사용한다. 위치·PSF·복소 합·정규화 비·시간 곡선 절대 오차1e−9를 사전 기준으로 정했다. 모든300 UI조합과 두 실험의 독립성을 검산한다.

원전 [Soila 등, 1984](https://pubmed.ncbi.nlm.nih.gov/6494479/)의 초록에서 물/지방 주파수 차이에 따른 오등록의 기전을 확인했다. IP/OP는 이전 F01에서 확인한 [Dixon, 1984](https://doi.org/10.1148/radiology.153.1.6089263)와 연결한다. Q02/F01의 원래 검증 범위·한계는 보존하고 순수 계산 자산을 수정하지 않았다. 위치·비율·BW 메뉴 등은 직접 만든 교육 조건이다.

## 독립 수치 결과

[수집기](A04-numerical.cjs), [결과](A04-numerical.json), [독립 화면 기준](A04-display-reference.json), [독립 기준 구현](../../../tests/helpers/chemical-artifact-reference.cjs), [시험](../../../tests/chemical-artifact.test.cjs)을 사용했다. 300조건에서 위치 오차0mm, 순수 PSF144,600점 최대 오차8.09e−16, 복소 합1.21e−10, 정규화 비5.88e−11, 시간 곡선180,300점1.06e−14였다. 모든 항목이 사전1e−9 기준을 통과했다. ODE 오차는 Q02의 공간 Dirichlet 오차와 구별해 기록했다.

기본3T의 Δf=−447.06352866Hz, 첫OP1.1184092818ms, 이동−2.2353176433pixel/−8.3824411624mm, 지방 배정 위치21.6175588376mm다. BW800에서 이동은1/4이며 같은 TE/f의 실험2 신호는 같다. 극성 반전은 위치 이동 부호만 바꾼다. 첫IP는 혼합 신호 정규화 크기1을 회복하지만 실험1의 이동은 같다. 순수 지방 f1은OP에서도 정규화 크기1이다. 같은 voxel에서 f.5일 때만 이 모형의 정확OP에서0이 된다.

## 실제 브라우저 · 내용 검토

[절차](A04-browser-check.js), [결과](A04-browser-check.json)는 Chrome155.0.8059.82의1920×1080/390×844에서300조합씩600상태다. 순수 PSF289,200개 SVG점과 시간 곡선360,600점, 실제/배정 위치, 물/지방/합 벡터, 신호 수치를 독립 기준과 대조했다. 최대 SVG y오차7.73e−6px로 허용1e−4px 이내다. 이 페이지는SVG를 사용하며 canvas pixel 검사를 했다고 기록하지 않는다.

Home/End/ArrowUp의 BW select 조작, 초기화·세 예시·두 문제 정답/오답·펼친 수식/설명을 확인했다. JS 오류와 페이지 가로 넘침은 없었다. [데스크톱 OP](A04-base-1920.png), [모바일 순수 지방](A04-pure-390.png), [모바일 IP 벡터](A04-ip-vectors-390.png), [넓은 BW](A04-wide-1920.png)를 직접 확인했다.

단위·지방 주파수 부호·극성/위치 식·TE/초 변환·공통 감쇠 전후 신호·순수/혼합의 구별·B0에 따른 정확한 IP/OP 시간·서로 다른 정규화·획득/표시 간격·한계와 문제 정답을 검토했다. IP로 모든 오등록이 사라진다거나 BW로 모든 OP 상쇄가 제거된다는 주장을 하지 않는다.
