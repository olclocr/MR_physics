AI03 반복 잡음 · 평균/분산/공분산 검증 (W53)

2026-10-17. 알려진 정답·대리처리의 반복 교육 모형 대상 버전 통과. 실제 학습 모델·임상 SNR 표준/검출력 검증이 아니다. 외부 전문가 검토 미시행.

대상과 사전 기준

학습 페이지는 N64/FOV64 mm, 원본0/.2/1/기존 단계+작은 점, 영상 Re/Im 각각 σ0/.05/.15, 기존 identity/평활/선명도/Haar1회의48조건이다. Seed0x41493035의512회 복소 입력을 모든 조건에서 공유한다. 출력 복소수는 유지하고 지표가 다루는 Re와 Im를 명시한다. 배경 공간 SD와 위치별 반복 SD를 혼동하지 않는다.

모형은 Q04 RNG와 AI01 처리를 수정 없이 재사용한다. 평균/분산/이웃 공분산을 Welford 방식으로 누적한다. 표본분모m−1, j63의 이웃j0인 순환 경계, SD0의 비/상관 null을 명시했다. 표본평균−정답 RMS는 bias의 추정이며 유한 반복의 평균 변동도 포함한다.

독립 기준은 고정65,536정규입력, 주파수 응답/별도 FFT·명시 Haar 행렬과2pass 평균/분산/공분산이다. 입력 분포를 이번 작업에서 새로 검증했다고 주장하지 않는다. 시험/수집기의 사전 기준은 신호/상관/지표1e−9, 분산/공분산1e−10이다. 선형 기대값은64tap의 제곱합/순환 내적으로 별도 계산한다.

근거와 수치 판정

Dietrich 등, 2007 DOI10.1002/jmri.20969의 출판사 초록을 직접 읽어 반복 획득과 단일 영상 배경 통계의 구별을 확인했다. Robson 등, 2008 DOI10.1002/mrm.21728의 초록에서 pseudo multiple replica의 선형 재구성 적용 범위를 직접 확인했다. PMC 직접 열기는 captcha였고 전체 본문을 읽었다고 기록하지 않는다. 이 페이지는 해당 환자/coil 실험이나 임상 SNR법을 구현하지 않았다.

수치 결과, 화면 기준:48조건/24,576처리 영상/3,072위치 통계에서 최대 평균차7.11e−15, 분산1.53e−16, 공분산4.86e−17, 상관5.64e−15, 지표1.71e−13으로 기준 통과다. 입력 seed와 신호가 고정된 유한 실험이며 모집단 기대값과의 불일치를 실패나 정확 일치로 혼동하지 않는다.

기본 단계/σ.15/평활은 위치별 SD평균.092168, 표본평균−정답RMS.057285, j32/33상관.627185다. 선형 모집단 분산.0084375/공분산.005625와 유한 표본의 위치별 값은 구별한다. 선명도는 이웃 공분산 기대−.016875, j32/33표본상관−.307201이다. 평활과 선명도가 모두 원본 평균을 바꿀 수 있음을 확인했다.

σ0/평활은 SD0과 표본비/상관 정의 불가이지만 공간 평균오차RMS.057068695다. σ.05/Haar의 j32분산은 신호0에서.000130727, 상수1에서.000159571이며 같은 입력 잡음으로 신호 의존성을 보인다. 상수1의 평균도.989228515여서 분산 감소와 bias를 별도로 읽는다. 이는 실제 AI 전체에 대한 주장이나 임상 SNR 향상 배수가 아니다.
