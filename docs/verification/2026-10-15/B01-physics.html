B01 스핀·ensemble·열평형 검증 (W04)

2026-10-15 (Asia/Seoul). 판정: 아래 범위에서 대상 버전 통과. 외부 전문가 검토 미시행. 기준 commit d78db6c 이후 로컬 변경을 검토했다. 대상 파일 SHA-256은 버전 목록에 기록한다. GitHub 게시 확인과 구별하는 로컬 개발 기록이다. 시작 전체 시험은 36/36 통과했다.

설계

  • 중심 질문: 많은 핵에서 순자화는 어떻게 생기는가?
  • 목표: 개별 spin의 양자 상태와 ensemble 평균을 구별한다. 낮은 에너지 준위의 아주 작은 초과 population을 M0와 연결한다. 비유·확대 표시와 실제 비율을 구별한다.
  • 선행: 벡터 합과 비율만 간단히 안내. B00 고전적 바퀴는 선택이며 필수로 삼지 않는다.
  • 세 관찰: (1) 고르게 분산한 단위 위상 벡터와 일치한 벡터의 합 비교, (2) 실제 population 차이와 차이만 10,000배 확대한 막대 비교, (3) B0를 1.5→3 T 또는 온도를 하나씩 바꾸어 실제 편극 비교.
  • 위상 그림은 개별 핵의 숨은 방향이나 평형 밀도행렬의 분해를 주장하지 않는 벡터 합 보조 도식이다. 그 길이 R과 열평형 P·M0를 혼동하지 않게 별도 표시한다.
  • 조작: B0=3 T (0~7 T, 0.1), T=310 K (250~400 K, 1), 기본 확대 OFF, 위상 분산. 초기화는 모든 기본값·퀴즈 상태를 돌린다. RF·이완·임상 온도 조절·SNR 예측은 범위 밖이다.
  • 계산: spin-1/2, 양의 proton γ, 독립 Zeeman 두 준위, ΔE=h γ̄ B0, P=tanh(ΔE/(2kT)), p낮음=(1+P)/2. 같은 핵 밀도에서 M0 상대값은 3 T·310 K 기준. γ̄는 기존 챕터와 같은 교육용 상수, h·k는 SI 정확값.
  • 표시: population 수치는 실제 계산값. 막대의 확대 여부는 바로 위에 표시. 백만 개당 숫자는 통계적 기대개수이며 실제 고정 표본 수를 뜻하지 않는다. 위상 도식 R은 16개 단위 벡터 평균 길이로 실제 Mxy/M0가 아니다.

사전 검증

Python Decimal 60자리 Boltzmann 가중치와 비교해 P 절대 오차 ≤1e−15, 각 population ≤2e−16, 상대 M0 ≤1e−12. 독립 고온 급수와 대칭·B0=0·온도 반비례·population 합 1을 Node 시험으로 확인한다. 그림의 확대 비율·범례·값은 같은 계산 상태를 사용한다. 실제 1920×1080·390×844에서 모든 관찰·경계·키보드·초기화·정답을 확인한다.

주장별 근거와 독립 내용 검토

  • Larson, Principles of MRI: Spin Physics (2026, 확인 2026-10-15), Fractional Polarization의 Boltzmann 점유율·ΔE·고온 근사와 대조했다. 양의 proton γ에서 낮은 준위가 +z이다. B0 증가·온도 감소가 작은 편극을 키우며, 같은 밀도에서 M0=nμP이다. 이 구현은 절대 n을 정하지 않고 상대 M0를 표시한다.
  • Tong, Cambridge Statistical Physics §1.2.3·1.3.2의 독립 두 상태와 정규화된 Boltzmann 가중치를 기준으로 했다. Tong의 일반 예시에서 up/down 명칭과 proton의 낮은 +z 명칭은 다를 수 있으므로, 이름이 아닌 에너지 0/ΔE의 점유율로 대조했다. 이를 ±ΔE/2로 평행 이동해도 점유율은 같다.
  • NIST CODATA 2022 상수 표에서 h=6.62607015e−34 J·s, k=1.380649e−23 J/K의 SI 정확값을 확인했다. γ̄는 기존 페이지의 교육용 42.57747892 MHz/T를 재사용하며 최신 γ의 정밀 측정을 구현한다고 주장하지 않는다.
  • Fitzpatrick, UT Austin: Pauli Two-Component Formalism 식 472–490의 spinor·Pauli 행렬로 양자 설명을 대조했다. |+z>=(1,0), |−z>=(0,1)에 대해 x/y 행렬의 대각 성분이 0이므로 횡방향 기대값은 0이다. 열평형의 대각 밀도행렬 ρ=diag(p낮음,p높음)에 대해 Tr(ρσx)=Tr(ρσy)=0, Tr(ρσz)=P도 직접 확인했다. 화살표 원뿔·고전적 자전을 개별 핵의 실제 궤적으로 제시하지 않는다.
  • 기존 mr_physics.md의 VI(두 z 성분·에너지·작은 population 차이), VII(고유상태의 횡방향 기대값 0·RF 후 coherence)와 새 페이지의 진술이 일치한다. 개념 문서에는 기초 챕터 링크만 추가했다. 2,000여 줄 문서 전체나 후반 심화 유도까지 이번에 통과시켰다는 뜻은 아니다.

단위는 B0[T], 온도[K], f0[Hz], ΔE[J], P[무차원]이다. ppm은 P×10⁶이며, 백만 개당 초과 차이는 통계적 기대개수이다. 낮음·높음의 기대개수를 고정 정수로 반올림해 모델에 다시 넣지 않는다. 0 T에서는 에너지 차이가 0인 축퇴 조건이며 두 점유율 1/2, M0=0이지만 spin 자체는 남는다.

위상 보조 도식의 R=|Σexp(iφ)/16|은 편극 P 및 Mxy/M0와 별도다. 고르게 분산한 위상은 16차 단위근이므로 합이 0이고 일치한 위상의 평균 길이는 1이다. 실제 16개 무작위 표본이 항상 정확히 상쇄한다는 주장은 하지 않는다. 위상 조작으로 왼쪽 열평형 계산을 바꾸지 않는 이유와 실제 RF 동역학을 계산하지 않는 범위를 페이지에 명시했다.

구현·표시 점검과 수정

  • 실제 비율 막대에는 차이가 거의 보이지 않는다. 차이 P만 10,000배 확대한 표시를 켜도 실제 점유율·P·M0 숫자는 그대로이며, 바로 위에 배율을 명시한다. 화살표 개수와 population을 연결하지 않는다.
  • 기본 상대 M0의 계산 순서에서 부동소수점으로 1.0000000000000002가 생길 수 있어 기준점과 현재점의 곱셈 순서를 맞췄다. 기준 3 T·310 K의 상대값은 정확히 1이다. 독립 수치를 다시 수집했다.
  • 브라우저 CSS 백분율 직렬화가 계산보다 자릿수를 줄이는 것을 확인했다. 막대의 표시 검증은 1e−4 percentage point 이내로 확인하며, 과학 값 P의 사전 오차 기준은 변경하지 않았다. 이는 실제 막대 폭에서 0.001 px보다 작은 차이다.
  • 초기 위상 그림이 무작위의 실제 표본처럼 읽히지 않게 대칭인 대표 위상·유한 무작위 표본의 잔여합·개별 핵의 궤적과의 차이를 명시했다.
  • 정답 1은 0 T의 같은 점유율과 평균 M0=0, 정답 2는 작은 population 차이의 약 두 배다. spin 소멸·양자수 변경이라는 오답에는 이유를 제공한다. 두 정답을 위 수치·고유상태 설명과 대조했다.
