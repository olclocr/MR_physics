# B05 k-space·역변환 통합 검증 (W08)

2026-10-15. **대상 버전 통과**. 기준 commit `4200dc1` 위의 미커밋 작업을 [파일별 SHA256](B05-versions.json)으로 특정한다. 시작 전체 51/51, 최종 53/53 통과. 외부 전문가 검토 **미시행**.

중심 질문은 “k-space 한 점은 영상의 한 점인가?”다. 세 단계(한 성분·합치기·덜 채우기)를 유지하고 선행 복소수/크기·위상, 예측 문제, 모형·표시 범위 안내를 보강한다. N=16, 물체·좌표·복소 DFT·마스크·정규화를 독립 radix-2 FFT와 비교한다. 각 방향 FFT 후 역방향에만 1/16을 적용해 총 1/256으로 복원하며 제품의 삼각함수 기저를 재사용하지 않는다.

4개 원본, 복소수 성분과 위상/진폭 경계·자기 짝, conjugate symmetry, Parseval, 중심·외곽·격줄 마스크, 합성 순서·최종 원본 복원, zero filling의 정보 제한을 검토한다. DFT/IFFT 성분과 재구성 오차 ≤1e−10, 성질 ≤1e−10을 사전 기준으로 한다. 실제 1920×1080·390×844에서 그림·수치·조작·키보드·애니메이션·초기화를 확인한다. 기존 stub 시험을 화면 검증으로 간주하지 않는다. 실제 partial Fourier·병렬 재구성·잡음·임상 영상·가변 matrix는 범위 밖이다.

## 모형·조작 범위와 내용 검토

- N=16, x=열−8, y=7−행, kx·ky도 −8…7의 무차원 인덱스다. 양의 y/ky는 위쪽이다. 예시 proton density 0~1, 전방 DFT는 음의 위상, 역방향은 양의 위상과 1/256이다. 실제 물리 좌표의 k 단위 cycles/m와 구별했다. 위상은 atan2(imaginary,real), 진폭은 |K|/256이다.
- 기본 한 성분 (1,0), gain=1 (0~2, 0.1), 위상 추가=0° (−180~180, 5), DC·짝 포함, 무늬 밝기 확대, 재구성 실수부다. 원본은 비대칭 합성 단면이며 bars·spot·uniform을 선택한다. 모든 값은 실제 조직값이 아닌 교육용 예시다.
- 합성은 130개 conjugate 묶음 (256성분), progress 0~130/1, 속도 0.3~2×/0.1, 중심/외곽 순서다. 이 시간은 MR의 TE나 실제 획득 시간이 아니다. 재생 정지·이전·다음·완료·초기화로 관찰할 수 있다. 마스크는 full·low·high·alternate, 정사각 cutoff 0~7/1이다.
- 원본 실수에서 K(−k)=K(k)*다. 모듈로 16의 DC·Nyquist 조합 네 점은 자기 짝이며 실수만 적용한다. 실제 복소 MR 영상에서 이 대칭을 항상 가정하지 않는다. 한 복소 성분만은 영상 전체에서 일정한 magnitude이고, 실수부/허수부의 줄무늬와 구별했다.
- 단일 무늬의 밝기 확대는 명시적 선택이다. 이를 끄면 원본 1 기준 고정 범위다. K 점의 로그 크기 표시는 선택 원본의 최대 |K|를 기준으로 하므로 원본 간 절대 크기 비교가 아니다. 재구성은 자동 window 없이 실수부 −1~+1, magnitude 0~1 기준이며 범위 밖은 포화된다. 음수는 보라, 양수는 청록, magnitude는 합을 구한 뒤 회색이다. 복소 NRMSE는 표시 모드와 무관하다.
- uniform은 DC=256 하나, spot은 모든 |K|=1이다. full 재구성은 두 합성 순서 모두 원본 복원, low+high는 복소 원본과 일치한다. cutoff2의 low는 25, high는 231, alternate는 128성분이다. 격줄 ky는 ρ(x,y)와 ρ(x,y+8)의 절반 합이다. 이 수식·화면·확인 문제를 함께 대조했다. 0을 채운 값은 측정으로 얻은 0과 다르다.

## 수정과 정답 검토
