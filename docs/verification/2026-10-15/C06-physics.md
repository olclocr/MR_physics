# C06 Spoiled GRE·flip angle 검증 (W18)

2026-10-15. **대상 버전 통과 (W18 완료)**. 외부 전문가 검토 미시행.

중심 질문은 짧은 TR에서 왜 작은 flip이 큰 반복 신호를 만들 수 있는가이다. 반복 pulse의 포화, flip sweep, TR 비교를 세 관찰로 둔다. TR20 ms(5/10/20/50/100/500/2000/5000), flip20°(0~90,0.1), T1 A600 ms(300/600/1000)·B1200 ms, 공통M0=PD1·TE2 ms·T2*40 ms다. 고정0~1 신호 창, 50회 pulse와 정상상태·1% 잔차 기준을 표시한다.

완전 spoiling·순간 RF·균일한 실제 flip·단일 지수 이완의 이상 모형이다. m(n+1)=1+[m(n)cosα−1]exp(−TR/T1), TE의 횡성분 감쇠를 별도로 적용한다. 잔여 coherence·bSSFP·실제 RF spoiling·B1·magnetization preparation·임상 조직/영상·잡음·CNR·검사 시간 최적화는 제외한다.

독립 확인은 3D Rodrigues 회전, RK4 종자화 회복, 횡성분 reset의 시간 순서 반복으로 수행한다. 정상상태 폐쇄식을 기대값에 쓰지 않는다. 신호/종자화 절대1e−8, 독립 수치 최대점과 Ernst angle1e−4°, 실제 SVG좌표1e−6·화면수치 반올림 범위를 사전 허용한다. 첫 pulse/90°/0°·긴 TR·1% 기준·A 신호와 A−B 대비의 최대점 차이·TE 감쇠 위치·단위/정규화를 검토한다.

근거는 실제 읽은 Larson2026 Basic Contrast Mechanisms의 반복 RF/정상상태·Ernst 식과 Fast Imaging의 spoiling 구분이다. Epstein·Mugler·Brookeman1996의 원 논문 초록(PMID8622589)을 읽고 실제 spoiling이 이상 모형과 달라질 수 있음을 반영한다. 특정 임상 flip/위상 scheme을 권장하지 않는다.

## 독립 수치와 내용 검토

대상은 commit `417aa00` 이후 로컬 파일로 [SHA-256 목록](C06-versions.json)에 특정한다. [독립 기준](../../../tests/helpers/gre-reference.cjs)은 3D Rodrigues 회전, RK4 이완의 시간 전파, 횡성분 reset과 고정점 반복을 사용한다. 최대 신호 각도는 반복 모형의 수치 삼분 탐색으로 찾으며 Ernst 식을 기대값으로 쓰지 않는다. 1% 도달 횟수를 검토할 때, TR5000/T1 300/flip0.1°에서 처음 오차가8.8e−14라는 이유로 독립 기준이 이미 같다고 처리했다. 0°만 처음부터 정확히 같은 경우로 정의하고, 이 작은 유한 오차도 상대 잔차 기준으로 세도록 제품/기준을 명확히 했다. 전체384개 조건의 pulse 번호가 일치한다. 이 횟수는 실제 장비 dummy 권장이 아니다.

기본 TR20 ms/flip20°에서 A/B 신호는0.1171/0.0709, 차이0.0462이며 Ernst angle은14.71°/10.43°다. 첫 pulse의 TE 신호는 두 구획이 같고 이후 회복 차이가 나타난다. T1 차이의 신호 비교를 PD·T2* 변화와 혼동하지 않도록 공통 조건을 표시했다. Gradient spoiling만으로 모든 미시적 coherence가 사라졌다는 설명을 피하고, 원 논문에서 실제 RF spoiling과 이상 모형을 구별했다.
