C01 — 영상 대비 실험실 물리 검증

날짜: 2026-10-15 (Asia/Seoul). 판정: 대상 버전 통과. 외부 전문가 검토: 미시행.

대상: C01 페이지, 대비 모형, 공통 모형의 spinEchoInitialMz 함수. e14d801 기반 미커밋 로컬 작업이며 최종 대상은 SHA-256 목록으로 식별한다. W00 및 기존 사용자 문서 변경을 보존했다. 공통 모형의 코드는 변경하지 않았다. 본 판정은 이 C01의 이상적 반복 SE 모형·현재 세 조직값·아래 표시와 조작 범위에 한정한다. B03 전체의 물리 검증을 통과시킨 결과가 아니다.

착수 시 검증 설계

중심 질문은 “같은 조직이 TR·TE에 따라 왜 다르게 보이나?”다. 기존 세 관찰(TE 고정/TR 증가, TR 고정/TE 증가, PD 차이 제거), 설명·식·단위·그래프·구획 영상·퀴즈를 모두 검토한다. 실제 임상 영상·잡음·질병·새 시퀀스는 제외한다.

  • 독립 기준: 구현의 SE 식을 쓰지 않고 이상적 90° → 자유 이완 → 180° → 자유 이완 → 다음 90°를 시간 순서로 적용한다. 별도 Bloch 이완 RK4와 이상적 회전을 사용해 대표·경계 조건을 대조한다.
  • 사전 오차: 해석적 시간 순서와 모델의 상대 자화·신호 절대 오차 ≤1e-12. RK4(dt ≤0.5 ms) 절대 오차 ≤1e-8. 화면 3자리 값은 반올림 오차 ≤0.0005(+부동소수점 1e-12), 8-bit gray는 독립 신호 기준 ±1 gray level. 곡선 현재점은 같은 신호 계산의 회복/감쇠 인자를 사용해야 한다.
  • 조건: 세 조직 × TR 200/500/6000/10000/12000 ms × TE 5/10/15/100/180 ms와 세 preset, PD 동일/기본. 극한은 TR≫T1, TE=0, TR=TE 및 TE 증가 시 신호 감소·TR 증가 시 회복 증가다. 유효하지 않은 TR<TE·비유한 입력은 거부해야 한다.
  • 물리 주장: T1·T2와 TR·TE 구별, PD 역할, 이상적 SE 정상상태와 통상 근사의 차이, 회복된 Mz의 180° 반전, 고정 신호 창, 강조영상과 정량 map 구별, 유한 TR/TE의 PDW 잔여 대비, 합성 모형의 범위를 근거·표시와 연결한다.
  • 화면: Chrome 1920×1080 / 390×844에서 세 관찰, 입력 경계·빈 입력·초기화, 키보드, resize와 표/막대/곡선/영상 동기화를 확인하고 실제 캡처를 직접 연다.

착수 시 문헌·독립 계산·실제 화면·최종 버전 식별은 미수행으로 시작했다. 아래는 실제 수행 결과이며 과거 시험을 소급해 통과시키지 않았다.

모형·단위·좌표·시간·정규화

  • 시간과 T1/T2는 모두 ms. TR은 연속 90° pulse 중심 사이, TE는 90° 중심에서 echo 중심까지다. 이상적 순간 180°는 TE/2에 있다. 유한 pulse 길이·B1 오차·slice profile은 포함하지 않는다.
  • B0를 +z로 정의한다. 독립 RK4는 오른손 좌표와 양성자 양의 gamma에서 90° x pulse를 −90° 회전으로 적용하여 +y 횡자화를 만들고, 180°에서 y와 z를 함께 반전한다. 표시 S는 위상 없는 비음수 magnitude다. 음의 y echo를 음의 밝기로 표시하지 않는다.
  • M0는 조직별 평형 종자화다. A=다음 90° 직전 Mz/M0이고 상대 PD와 별도 인자다. 다음 여기 직전 잔여 횡자화를 0으로 두는 perfect spoiling, 조직 내 단일 T1/T2, 자화 교환 없음, 각 구획의 균일 감도를 가정한다.
  • 표시 신호는 S=PD×abs(A)×D, D=exp(−TE/T2). PD=1, 완전회복, TE=0의 기준 신호를 1로 두며 모든 조건에서 창을 0–1로 고정한다. 영상 gray는 round(255×S), 막대 너비는 100×S percent다. 자동 정규화·noise·CNR은 포함하지 않는다.
  • 예시값은 WM (PD 0.70, T1 800, T2 70), GM (0.85, 1300, 100), CSF (1.00, 4000, 2000). 값 표도 모형 데이터에서 생성해 이중 관리하지 않는다. PD 동일 비교에서는 신호 계산의 PD만 1로 바뀌며 기본 예시값 표는 그대로 유지된다.
  • 조작은 TR 200–12000, step 50, 기본 500 / TE 5–180, step 5, 기본 15다. 최소 TR이 최대 TE보다 커 항상 TR>TE를 만족한다. 대표값은 T1W 500/15, T2W 6000/100, PDW 10000/10이다. 이 범위 전체를 임상 프로토콜로 권장하지 않는다.

독립 계산과 사전 오차의 판정

회복 곡선은 매 TR에 대한 A, 감쇠 곡선은 매 TE에 대한 D를 같은 모형에서 계산한다. 기본 T1W 상태의 여섯 현재점(두 그래프×세 조직)은 독립 RK4 값으로 예측한 위치의 실제 픽셀 색을 확인했다. 기본 T1W 밝기 순서는 WM>GM>CSF, T2W는 CSF>GM>WM이다. T2W에서도 CSF 회복은 약 77%여서 T1 영향이 완전히 없어지지 않는다.

  1. 설명 범위: 기존 회복 그래프 제목은 TR 증가가 항상 회복 차이를 줄인다고 읽혔다. 위 반례로 확인하고 “회복이 진행됩니다”로 변경, 차이가 처음 커질 수 있음을 본문에 추가했다. 수치 회귀와 실제 곡선 재확인 완료.
  2. 근사·시각화의 연결: 정확한 식과 근사식은 이미 구별되어 있었지만 TE가 A도 바꾼다는 연결과 M0 정규화/첫 shot의 차이는 부족했다. 시간 순서·A의 정의·기준 신호·동적 근사 비교·원전 근거를 보강했다. 감쇠 곡선의 별도 지수 계산을 공통 신호 모형의 D로 바꾸고 예시값 표를 데이터에서 생성했다. 정확한 SE 신호 식과 공통 모형 코드는 유지했다.
  3. 모바일 눈금: 390px 실제 캡처에서 회복 곡선의 오른쪽 12,000 눈금이 잘렸다. 양 끝 눈금의 정렬을 안쪽으로 변경하고 재캡처·직접 확인했다.
