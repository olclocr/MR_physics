C02 SE/GRE 재위상화 검증 (W06)

2026-10-15 (Asia/Seoul), 대상 버전 통과. 기준 commit 7de8555 위의 미커밋 작업을 SHA256 목록으로 특정한다. 시작 전체 시험 44/44, 최종 48/48 통과. 외부 전문가 검토 미시행.

설계와 사전 기준

  • 중심 질문: SE와 GRE는 각각 무엇을 되돌리는가? 목표는 시간도식 읽기·gradient 면적과 RF 반전 구별·정적 off-resonance 분포의 영향 예측이다.
  • 세 관찰: 같은 ensemble에서 SE/GRE 전환; 두 번째 gradient 면적 비율 1→0.6; 정적 주파수 분포 추가. 공통 주파수 이동은 분포와 구별한다.
  • 45개 대표 묶음: 위치 −2…2의 5개 동일 가중치 × 정적 Δf의 9개 이산 Gaussian 가중치(±2 폭). 각 위치마다 같은 Δf 분포를 사용한다. 개별 핵의 실제 궤적이 아니라 ensemble의 순자화다.
  • 기본값: SE, 명목 TE=40 ms (10~80, step 2), T2=80 ms (20~200, step 5), gradient 효과 g=20 Hz/step (0~40, step 1), 두 번째 면적 비율 b=1 (0~2, 0.05), 공통 Δf=0 Hz (−80~80, 5), 분포 폭=0 Hz (0~60, 5). 관찰은 0~1.5TE, step 0.1 ms, 기본 TE. 초기화는 모든 설정·정답을 돌린다.
  • GRE는 첫 절반 −g, 둘째 +bg; SE는 첫 절반 +g, 둘째 +bg와 TE/2의 순간 180°x. 두 모드 모두 t=0 순간 90° 직후 (0,1,0), 초기 Mxy=1. T2만 감쇠하고 T1·TR 정상상태·RF/gradient ramp·확산·bSSFP는 제외한다.
  • 계산은 기존 free·rotate를 재사용한 시간 순서 모형이다. 독립 기준은 별도 해석적 복소 위상이다. t=TE/2의 SE는 pulse 직후 값이며, 반전으로 mx 유지·my 반전이다. SE의 실제 gradient 면적과 현재 위상에 남은 유효 면적을 구별한다.
  • 모든 성분 절대 오차 ≤1e−11, echo magnitude ≤1e−12, 180° 좌우 극한 반전 ≤1e−8. 양·음 Δf, 0/최대 분포·g·b, TE/T2 경계, TE 전/중/후, 면적 불균형을 확인한다. 곡선·화살표·도식·숫자는 같은 계산을 사용하고 1920×1080·390×844 실제 조작을 확인한다.
  • Gradient 유효 면적 0은 위상 재결맞음의 기준 시점이며, T2 감쇠가 곱해진 magnitude 곡선의 최대점과 무조건 같다고 하지 않는다. 이산 모형의 반복 결맞음도 범위를 표시한다.

독립 계산·회귀·실제 조작

구현은 공통 free·rotate의 시간 순서 계산이다. 독립 기준은 이를 호출하지 않는 해석적 복소 위상이다. 전반 φ=π/2−2π(δ+s gx)t/1000 (GRE s=−1, SE s=+1), 후반 GRE φ=π/2−2π[δt+gx(−τ+b(t−τ))]/1000, SE φ=−π/2−2π[δ(t−2τ)+gx(−τ+b(t−τ))]/1000. 각 벡터 크기는 exp(−t/T2), τ=TE/2이며 주파수 묶음·위치의 가중 합으로 신호를 구한다.

내용·수식·도식·정답 검토와 수정

  1. 양성자 Δf=fspin−fRF, dM/dt=γ M×B 규약에서 주파수에 대한 위상 진행은 음의 방향이다. g=γbar G Δx의 단위는 Hz/격자 step이며 실제 T/m 값이 아니다. 면적 cycles/step, 시간 ms, 수식 위상 rad와 화면의 도를 구별했다.
  2. b=1, TE=40, T2=80에서 SE/GRE 크기는 exp(−0.5)=0.6065306597이다. SE −y, GRE +y는 180°x 규약의 결과다. SE의 실제 gradient 면적은 TE에서 0.8 cycles/step, 위상에 남은 유효 면적은 0이다. GRE는 둘 다 0이다. RF 바로 뒤는 우극한이다. 시간도식·표와 대조했다.
  3. b=0.6의 TE 유효 면적은 −0.16, 신호는 0.148005이다. gradient 위상 항 0은 53.333 ms이며 명목 TE는 40 ms다. 이 시점과 T2를 곱한 곡선의 최대점을 동일시하지 않는다. g=0이면 고유한 gradient echo 시점을 표시하지 않는다.
  4. σ=35 Hz에서 TE의 SE=0.60653, GRE=0.01017155이다. 폭 σ는 잘린 이산 분포의 실제 표준편차와 같지 않다. 이산 모형의 반복 결맞음은 임상 T2* 단일 지수 fitting이 아니다. 공통 δ는 GRE의 전체 위상만 돌려 같은 시점의 크기는 유지한다. 이 차이와 SE가 T2를 회복하지 않는다는 내용을 정답·오답 설명과 대조했다.
  5. 모든 그래프·벡터·표는 같은 상태와 모형 결과를 사용한다. 원 반지름 1, 신호 축 0~1은 고정이다. 얇은 선은 대표 묶음, 붉은 선은 가중 합이다. 실제 핵의 고전적 궤적이나 임상 영상으로 표시하지 않는다.
  6. 모바일 시간도식을 두 줄 시각 표식으로, 벡터 수치를 아래 배치로 수정했다. 반올림된 −0.0000을 0.0000으로 표시하고 실제 값은 유지한다. 신호 축 하단 글자의 여백을 늘린 뒤 실제 두 화면을 재확인했다. 공통 물리 자산은 바꾸지 않았다. 선행 페이지에는 새 챕터 연결만 추가했다.
