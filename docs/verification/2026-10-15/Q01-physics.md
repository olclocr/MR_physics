# Q01 SNR·CNR·NEX 검증 (W11)

2026-10-15. **대상 버전 통과 (W11 완료)**. 외부 전문가 검토 미시행.

중심 질문: “평균하면 무엇이 더 잘 보이나?” σ, NEX, 두 구획 참 신호 차이를 각각 바꾸는 세 관찰이다. 단일 복소 채널, 서로 독립인 실수/허수와 반복, 동일 신호/위상·voxel을 가정한다. 평균은 복소 단계에서 먼저 시행한다. 모형 SNR=SA/σ평균, CNR=|SA−SB|/σ평균이며 두 pixel 차이의 SD 정의와 구별한다.

조작: σ=0.2 (0~0.4, 0.05), NEX=1 (1/2/4/8/16), ΔS=0.15 (0~0.6, 0.05), 표시 magnitude 또는 real. A=0.6, B=0.6−ΔS, 배경=0. Seed `0x51a7c0de`, 고정 64×48 격자에서 16회 중 처음 N회를 평균한다. magnitude 창0~1, real 창−0.5~1은 각각 고정하고 전환 시 창 차이를 명시한다. 이 창으로 통계를 잘라 계산하지 않는다.

근거: [Larson SNR](https://larsonlab.github.io/MRI-education-resources/Signal%20to%20Noise%20Ratio.html)의 독립 평균·획득 voxel 관계, [Gudbjartsson & Patz (1995)](https://pmc.ncbi.nlm.nih.gov/articles/PMC2254141/)의 Gaussian 복소 성분·Rician 크기·Rayleigh 배경. 2026-10-15 자료를 실제 검색/열람해 확인했다.

사전 통계 기준: 별도 65,536개 표본·seed 0x51a7c0de/0x243f6a88/0x13579bdf에서 NEX1/4/16의 성분 평균 ≤5σ/√P, SD 상대오차 ≤5/√(2(P−1)), 실수/허수 및 반복 간 상관 ≤5/√P. 단일 표본의 magnitude 평균은 독립 2D Gaussian 확률 적분 기준에서 5 표준오차 이내, 제곱 평균은 E[M²]=S²+2σ²에 대해 5 SE 이내로 확인한다. 생성기의 결정성·nested 평균·σ0·ΔS0·크기보다 먼저 평균하는 순서도 확인한다. 유한 표본에서 모든 pixel의 오차가 단조 감소한다고 주장하지 않는다.

실제 1920×1080·390×844에서 픽셀·수치·곡선·고정 창·ROI·문제·키보드·경계·초기화를 확인한다. 제외: 실제 임상 영상·움직임·coil combination·parallel/AI 재구성·공간 상관·검사 시간 전체·진단 성능.

## 독립 통계 검산과 내용 판정

대상은 commit `417aa00` 이후 로컬 구현이며 [SHA-256 목록](Q01-versions.json)으로 특정한다. [독립 기준](../../../tests/helpers/noise-reference.cjs)은 제품 통계 함수를 쓰지 않고 직접 모멘트를 계산한다. magnitude 기대값은 −8~8의 2D 정규 확률 적분(step 0.04), 제곱 모멘트는 해석식으로 구했다. [수집기](Q01-numerical.cjs)와 [결과](Q01-numerical.json)를 보존한다.

| 검토 항목 | 관측·사전 기준 | 판정 |
|---|---|---|
| Gaussian 성분 평균 | NEX1/4/16, seed 3개, 각 65,536 pixel. 최대 표준화 평균 편차 2.066 SE, 허용 5 SE | 통과 |
| 평균 후 SD | 기대 1/√N에 대한 최대 상대차 0.005934, 허용 0.013811 | 통과 |
| 실수/허수·반복 독립성 | seed별 표본 상관 절대값이 모두 5/√65536=0.01953125 미만 | 통과 |
| 저신호·무신호·높은 신호 magnitude | S=0/0.1/0.6과 각 NEX의 27개 비교. 평균 최대 1.926 SE, 제곱 모멘트 최대 1.852 SE, 허용 각각 5 SE | 통과 |
| 평균 순서 | 반대 부호의 두 복소 표본에서 먼저 평균하면 배경 magnitude=0. magnitude를 먼저 평균하면 1. 구현은 전자 | 통과 |
| σ=0, ΔS=0 | 무잡음은 정확한 참 신호, 비율은 유한 지표로 표시하지 않음. ΔS=0/σ>0에서 CNR=0, SNR_A는 유지 | 통과 |
| 단위·정규화·voxel | 같은 상대 단위의 성분 σ, 고정 voxel·ROI. acquisition voxel 부피의 적분 신호 효과와 표시 격자/공간 평균을 구별 | 통과 |

기본 σ=0.2에서 NEX1/4/16의 σ는 0.2/0.1/0.05, SNR_A는 3/6/12, ΔS=0.15의 CNR은 0.75/1.5/3이다. 무신호 크기 기대 평균은 각각 0.250663/0.125331/0.062666이다. 잡음 분산은 성분별 σ²/N이며 magnitude 분포는 같은 Gaussian이 아니다. 단일 채널 Rayleigh 배경의 SD는 성분 σ와 다른 값이다. ROI 표본 평균이 참 S와 정확히 같거나 모든 pixel이 단조 개선된다고 설명하지 않는다.

두 독립 pixel 차이의 표준편차 √2σ를 쓰는 다른 CNR 정의를 명시했다. 이 페이지의 CNR을 저신호 magnitude ROI 평균 차이/배경 크기 SD로 표시하지 않는다. 실제 다중 코일·비선형 재구성·공간 상관·생리/운동 잡음에 일반화하지 않았다. 독립 반복·고정 신호/위상에서만 제곱근 평균 법칙을 적용한다. 문제의 √4=2와 무신호 magnitude의 양의 기댓값이 수치·영상·수식과 일치한다.
