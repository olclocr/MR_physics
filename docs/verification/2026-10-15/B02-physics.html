B02 — RF 공명·flip angle 물리 검증

날짜: 2026-10-15 (Asia/Seoul). 판정: 대상 버전 통과. 외부 전문가 검토 미시행.

대상은 RF 공명 페이지와 b_eff 문서의 기본 정의·부호·좌표·단위다. e14d801 기반 미커밋 작업이며 최종 버전은 SHA-256으로 식별한다. 기존 이완/시퀀스 모델과 b_eff 후반의 고급 RF·slice·chemical shift 개요 전체는 제외한다. 공통 계산 자산과 C01 계산은 바꾸지 않았다.

사전 기준: 독립 라머계 시간 의존 Bloch RK4(공통 rotate/rfFrame 재사용 없음)와 RF계 해를 대조한다. Δf −2000/−1000/0/+1000/+2000 Hz, B1 3/8/30 µT, 목표 0/90/180/360°, 두 프레임·RF ON/OFF에서 벡터 절대 오차≤1e-8, norm 오차≤1e-10. 해석적 공명 M=(0,sin α,cos α), RF OFF의 M=(0,0,1), pulse 시간 및 gamma 단위 변환을 확인한다. 화면 수치는 표시 반올림의 절반 단위 안에 들어야 한다.

화면은 1920×1080/390×844에서 실행·정지·재개·끝점·초기화, 프레임·관찰·퀴즈·RF OFF·키보드·정규화를 확인하는 것으로 계획했다. 아래는 실제 수행 결과다.

근거·단위·부호·모형

  • Larson, Principles of MRI, Bloch Equation (2026)의 운동방정식·회전좌표계·일정 진폭 pulse를 대조했다. 이완 없는 고전적 ensemble 자화이며 바퀴가 양성자의 실제 회전 구체라는 주장을 하지 않는다. Spin Physics의 평형 자화식으로 고정 온도·밀도에서 M0의 B0 비례 근사를 확인했다.
  • 사용 상수 γ̄=42.57747892 MHz/T는 NIST CODATA 2014 표에 있는 값이다. 공유 구현과 같은 교육용 상수를 유지하며 최신 측정값이라고 표시하지 않는다. MHz/T→Hz/µT에서 같은 숫자를 사용하고 γ=2πγ̄를 rad/s/T에 사용한다. pulse 계산 시간은 초, UI 시간은 ms다.
  • γ>0, 오른손 좌표, dM/dt=γM×B. +x pulse는 −x축 회전각을 적용하여 초기 +z를 +y로 보낸다. 주파수 f0·fRF는 양의 크기이고, Δf=fRF−f0다. RF계에서는 B_eff=(B1,0,−Δf/γ̄), 라머계에서는 B1의 위상이 −2πΔft다. RF계→라머계 변환은 Rz(−2πΔft)다. 이 부호는 정의에서 독립 유도하고 아래 시간 의존 적분으로 확인했다.
  • B1은 co-rotating 성분의 일정 진폭이다. RF ON 기준 시간 T=목표각/(360γ̄B1). RF OFF는 이 기준 시간을 유지하되 적용 B1=0이다. 초기 자화가 +z여서 두 프레임에서 그대로 남는다. 이미 기울어진 자화가 pulse 뒤에 진화하는 실험은 B03에서 다룬다.
  • 각도 설정 0–360°, B1 설정 3–30 µT, offset −2000–2000 Hz, B0 0.5–3 T, playback 0.1–3 물리 ms/화면 초다. 기본값은 180°/8 µT/0 Hz/1.5 T/1 ms/s, 초기 RF ON 설정이다. 프레임·조건 변경은 pulse를 처음부터 관찰하도록 초기화한다.
  • Mz/M0와 Mxy/M0는 현재 B0의 평형자화 기준이다. 도식 길이의 B0/1.5 T 척도와 숫자 정규화를 구분했다. 이완이 없어 자화 norm은 1이며 표시 창 자동 확대는 없다. camera의 공간 척도는 viewport별로 고정하여 허용 필드 범위를 넣는다.
  • 대기 화면 필드는 설정 미리보기, 일시정지는 관찰 시간 동결, 종료 화면은 pulse 끝점의 RF 중 상태를 고정한다. RF계의 detuning z 유효장은 좌표계 효과이며 RF OFF에서도 나타날 수 있다. 실제 RF OFF 비교에서는 B1 화살표를 없애고 적용 B1=0을 로그에 기록한다. 0인 유효장은 방향/norm 검사를 null로 두며 존재하는 축처럼 표시하지 않는다.

Stanford RAD229의 RF·회전좌표계 강의 목록은 추가 학습 링크로 확인했다. 개별 PDF는 용량/접속 오류로 읽지 못했으므로 본 판정의 유일한 식 근거로 삼지 않았다. b_eff 초반의 잘못된 f0=γB0 표기는 γ̄로 고치고, 양의 z 유효장 그림이 Δf<0인 예임을 명시했다.

발견·수정·재검증

  1. 선행 기호·학습 목표·세 관찰·오개념·설명형 확인 문제가 부족해 본문에 추가하고 수식을 접었다. 관찰은 공명 flip, ±offset/프레임, B1·RF OFF 비교로 제한했다. pulse shape와 slice selection은 G02로 남겼다.
  2. 기존 지표는 B0/1.5 T 시각 척도가 곱해진 값을 정규화 설명 없이 보여줬다. 숫자를 현재 M0 기준으로 고치고 도식 길이와 분리해 설명했다. B0=0.5/1.5/3 T의 공명 180°에서 항상 −1.000/0.000임을 시험과 브라우저에서 확인했다.
  3. RF OFF 비교를 추가했다. 적용 B1·f1·방향·도식·로그·퀴즈/초기화가 함께 변한다. OFF에서 Δf/f1은 미정의라 숫자를 만들지 않고, 공명 목표각 검사도 실제 RF가 없는 경우 null이다. 로그의 B1 설정과 적용 진폭을 구분했다.
  4. MHz 3자리 표시는 100 Hz offset을 숨길 수 있어 6자리로 바꿨다. +1000 Hz에서 63.866218→63.867218 MHz 표시를 확인했다. M 화살표의 잘못된 색 설명도 청록색으로 맞췄다.
  5. 수정 전 390px에서 제목/부제와 B_eff 라벨/지표가 겹쳤다. 지표를 도식 아래 흐름으로 옮기고 허용 범위를 담는 고정 camera, 라벨 충돌 회피·연결선을 적용했다. 수정 후 캡처를 직접 열어 재확인했다. 이 변경은 공간 표시 척도만 바꾸고 물리 벡터 계산을 바꾸지 않는다.
