# D03 DWI 신호·EPI 시간·위치 검증 (W28)

2026-10-16. **지정 범위 대상 버전 통과 (W28 완료)**. 외부 전문가 검토 미시행.

TE80ms·T280ms·D0.001mm²/s·PD1·잡음0 신호는 D02 모형을 재사용한다. b0/500/1000/1500, PE Ny32/FOV160mm·점 y0=−20mm, 균일 field50Hz(−100~100,10), PE ±1이다. Single shot은 R1/실제ESP0.8ms/32echo/1shot, PI는 R2/실제ESP0.8ms/16echo/1shot, 읽기 분할은 R1/실제ESP0.4ms/32echo×3shot이다. 분할수로 ESP를 자동 유도하지 않고 예시를 선언한다.

목표는 b와 밝기, 읽기 시간과 위치, field·PE 방향의 세 관찰이다. 실제 읽은 ky 중심과 복소 신호를 계산하지만 kx 내부 ADC·gradient 파형·coil 분리/누락 복원은 계산하지 않는다. 표시 위치는 알려진 점 branch에서 선형 위상 기울기로 예측한 연속 위치이며 실제 영상/PSF가 아니다. R2의 y↔y+80mm 모호성을 표시한다. 서로 다른 kx 구간의 shot 간 위상이 일치한다고 가정한다. TE·신호는 고정하고 실제SNR/최소TE/총시간·motion/eddy·국소 늘어남/dropout을 비교하지 않는다.

독립 기준은 SI 시간표의 반복 생성, Bloch ODE의 시간 위상, unwrap 후 위상-ky 회귀, D02 독립 ODE 감쇠다. 신호/복소1e−9·시간1e−9ms·위치1e−8mm·실제SVG1e−6과 표 반올림/회색 정수 일치를 사전 허용한다. b/읽기 독립성, PE 반전·field0·PI alias와 shot 수를 검토한다.

Holdsworth 등 (2008), PMID17980534/PMC3360876의 원문에서 PE 진행·readout 분할·PI와 navigator/shot 간 위상 문제를 읽었다. 예시 수치·단위/부호/계산은 자체 모형이며 원문 환자 영상/성능을 복제하지 않는다.

## 독립 수치·단위·내용 판정

대상은 commit `417aa00` 이후 로컬 파일이며 [SHA-256 목록](D03-versions.json)으로 특정한다. [독립 기준](../../../tests/helpers/dwi-epi-reference.cjs)은 SI 시간표를 반복 생성하고 공간 위상에서 시작한 Bloch ODE를 t−TE까지 적분한다. 한 shot의 위상을 unwrap하여 ky에 대한 기울기를 회귀한다. 제품의 이동식을 기대값으로 호출하지 않는다. 신호는 D02의 독립 ODE 기준을 사용한다. [수집기](D03-numerical.cjs), [결과](D03-numerical.json)는 **504조건·24,192echo**다.

| 항목 | 최대 차이 | 사전 기준과 판정 |
|---|---|---|
| 신호 크기 | 2.933e−13 | 1e−9 이내 통과 |
| 복소 echo | 2.016e−12 | 1e−9 이내 통과 |
| 예측 위치 | 8.719e−12mm | 1e−8mm 이내 통과 |
| 중심 시간 | 1.564e−13ms | 1e−9ms 이내 통과 |
| ky | 0 | 1e−12cycle/mm 이내 통과 |

b0→b1500은 exp(−1.5)의 신호 비율을 만들며 echo 시간·위치 이동은 변하지 않는다. Δf=0에서 이동0, PE 부호 반전에서 이동 부호 반전이다. 현재 PI와 읽기 분할 예시는 ESP/R=0.4ms로 같으므로 동일 field에서 같은 이동이며 shot 수는 다르다. PI의 모든 짝수 q에 대해 y+80mm의 공간 위상이 같은 복소 데이터를 만드는 것을 별도로 검산했다. branch가 정해진 현재 위상 회귀가 실제 PI 위치의 유일성을 증명하는 것은 아니다.

정규화는 PD1 기준이며 b0도 T2에 의해0.367879다. S/S(b0)는 별도로 표시한다. 모든 TE를80ms로 고정했으므로 최소TE/SNR개선을 계산하지 않는다. Spin echo의 정적 field 위상은 중심TE에서0으로 재집속되고 읽기 중의 t−TE만 남는다. 주파수Hz·시간s·FOVmm의 곱이 mm이며 Ny를 곱한 픽셀 이동과PE Hz/pixel도 같은 시간규칙을 따른다. 중심 처음~끝은 마지막/첫 echo 중심 차이이며 전체ADC readout길이로 부르지 않는다.

## 최종 범위와 남은 D03
