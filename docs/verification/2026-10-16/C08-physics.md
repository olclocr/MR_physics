# C08 bSSFP·잔여 횡자화·주파수 응답 검증 (W30)

2026-10-16. **대상 버전 통과 (W30 완료)**. 외부 전문가 검토 미시행.

TR5ms(3/5/10), flip30°(0~90,1), offset0Hz(−500~500,10), TE=TR/2·T11000ms/T2100ms/M01의 단일 정적 spin이다. 순간RF 위상0/π(+x/−x)를교대하며수신위상도RF를따른다. 각TR의공간gradient0차moment0·횡성분보존, RF중이완/off-res없음·실제gradient파형/voxel분포는계산하지않는다. RF와함께바뀌는좌표의한TR 고정점과실험실두TR주기를구별한다.

초기평형의첫50pulse echo·정확행렬고정점·다음RF직전횡성분·정상상태1001주파수응답을세관찰로연결한다. 반복도달기준은N회TR뒤직전벡터의M0절대거리1e−4다. 신호상대오차/실제검사대기시간이아니다. 정상상태응답세로0~0.25/초기신호0~1의고정축을구별하고 flip0의위상을정의하지않는다. 작은flip의반주기위치를보편적어두운띠라고하지않는다.

독립기준은labframe두RF주기를4×4affine행렬지수로구성하고Householder QR로고정점을풀며, RF/자유세차의직접Bloch ODE를별도로대조한다. 제품의RFframe고정점/회전을기대값으로호출하지않는다. 벡터/신호1e−9·실제SVG1e−6·표반올림/도달횟수일치를사전허용한다. magnitude1/TR주기·TE의복소부호반전·flip0/phase미정·초기/정상구별·균일offset을검토한다.

Carr1958(DOI10.1103/PhysRev.112.1693)의반복RF/freeprecession원논문초록과Bieri2011(PMID20859995)의finiteRF원논문초록을읽었다. Bieri·Scheffler2013의본문도RF위상교대/순간pulse한계·TE=TR/2의교차확인에읽었다. 현재수치/주기/부호는자체Bloch유도·독립검산이며실제권장값/SNR/임상성능을가져오지않는다.

## 독립 계산·부호·반례 판정

대상은 commit `417aa00` 이후 로컬 파일이며 [SHA-256 목록](C08-versions.json)으로 특정한다. [독립 기준](../../../tests/helpers/bssfp-reference.cjs)은 실험실고정좌표의+x/−x 두RF와free TR를 4×4affine행렬지수로 구성해 두TR 고정점을 HouseholderQR로 푼다. 제품의RF좌표한TR행렬/회전을 기대값으로 쓰지 않는다. 별도의 직접Bloch RK4로 RF각도적분→TE자유세차를 대조했다. [수집기](C08-numerical.cjs), [결과](C08-numerical.json): TR3/5/10·flip0/1/15/30/60/89/90·대표7offset의 **147조건**과21개응답의 **21,021주파수점**이다.

같은RF좌표에서 m∞의직전벡터가반복되는것과실험실좌표의두TR부호교대를 독립대조했다. Magnitude는1/TR주기이고 echo의횡복소벡터는주기이동후부호가반대다. TE=TR/2의추가π위상을누락하지않았다. +π/−π는같은위상이라 실제표반올림은순환각도오차로검증했다. flip0에서횡신호0/위상미정이며균일field가gradient moment0으로제거되지않는다.

기본조건의정상상태|S|=0.1559334·직전횡성분0.1520834, 50회echo0.1950497이며 절대직전벡터1e−4기준은1023TR뒤다. offset100Hz의정상상태0.0093191도50회echo0.2242913과구별했다. 초기50회를충분한정상상태로표시하지않는다.

작은flip반례에서TR5/flip1°의on-res신호0.0087175보다반주기100Hz신호0.1573104가높다. 따라서반주기표식은보편적어두운띠가아니며flip에따른응답변화를본문에명시했다. 검산한최대정상상태신호0.158102는고정표시창0~0.25안이다. 첫RF flip90°의높은초기신호는별도0~1축으로표시한다. 현재T1/T2고정모형에서조직대비/SNR나“순수T2”를주장하지않는다.
