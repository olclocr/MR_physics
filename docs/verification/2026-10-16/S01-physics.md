# S01 주파수분포·GRE 신호/위상·blooming 검증 (W29)

2026-10-16. **지정 범위 대상 버전 통과 (W29 완료)**. 외부 전문가 검토 미시행.

한 페이지의 중심은 평균 주파수·분포 폭이 복소 신호에 주는 효과다. 독립 후처리인 phase mask/minIP는 바로 다음 W29b 페이지로 분리한다. N32/FOV32mm·1mm격자, T280ms/PD1·초기+x·잡음0, TE20ms(5~40,5), 평균만/분포만/둘다·평균 부호±1을 쓴다. 기준 원 반지름3mm·평면별 x중심−6/−2/2/6mm·z중심−3/−1/1/3mm이며 기본 index2다. 평균μ=10hHz/SDσ=12hHz, h=exp(−r²/72)인 분포를 직접 정하며 기준 원의 χ로 field를 유도하지 않는다.

C03의 연속 Gaussian GRE크기를 재사용하고 평균의 복소위상을 곱한다. 정규화M0=1, magnitude0~1·phase−π~π 고정창, +주파수→−위상 관례다. 어두운 면적은 같은TE배경 대비0.5미만인 voxel중심 격자 개수×1mm²다. 연속 원의 면적과 격자기준 면적을 구별한다. 기준경계 밖까지 주어진 분포와 문턱으로 어두운 범위가 커지는 모형이며 실제dipolefield/혈관/병변크기/물질을 재현하지 않는다.

독립확인은 정규화한 Gaussian 주파수의 복소 Simpson구적(−9~9SD,1024구간)과 T2 RK4다. 복소/크기/위상1e−9·면적정수일치·실제SVG1e−6·canvas정수일치를 사전기준으로 둔다. 최대위상2.513rad로 wrap이 없고, 분포폭0·평균0·부호반전·TE/기준도형 불변을 검토한다. Haacke등2004(PMID15334582) 원문에서 field/phase·magnitude와 mask후처리 구별을 읽었으며 현재구조/분포는 자체 예시다.

평균만이면 신호크기는 균일T2배경과 같고 위상만 바뀐다. 분포폭만이면 위상0이며 magnitude는 둘다모드와 같다. 평균부호 반전은 복소conjugate이며 magnitude를 바꾸지 않는다. 기준도형 격자면적은32mm²로 고정이고 둘다모드의 TE5/20/40ms 어두운면적은0/52/208mm²다. 물체를 키운 결과가 아니라 주어진 분포/TE/문턱의 표시 결과다. 원의 연속면적π9와 voxel중심기준32를 구별했다.

Mx+iMy·초기+x·+주파수의 음위상·γbar42.57747892Hz/µT·시간초/주파수Hz·mm좌표를 대조했다. 중심10Hz는234.86595nT의평균field에 해당한다. 분포와 원사이χ→field 유도는 수행하지 않았다. Gaussian분포의감쇠와 T2의곱을 단일지수T2*로 부르거나 임상fit결과로 해석하지 않는다. 최대위상2.513rad에서 wrap은없고 현재잡음0/비영신호의위상을 표시한다. 실제물질·좌표/vendor부호를 영상흑백만으로 추정하지 않는다.

## 최종 범위

주어진Gaussian주파수분포·C03 GRE크기 재사용·평균위상·단위/부호·정규화·고정창·문턱면적·설명/문제는 대상버전통과다. S01의mask/minIP는 바로다음W29b로 남긴다. 실제χ→dipolefield/조직방향·PSF·noise·background filtering/unwrap·임상물질/질환/크기진단·장비성능과 외부전문가검토는 미시행또는모형밖이다. 분포/TE/T2/정규화/문턱·격자/표시를 바꾸면 독립적분/면적과 실제두화면을 재검증한다.
