# X17 후속 · 축별 배율과 길이/면적 (W100)

2026-10-18. **지정된 배율/회전/길이/면적 모형 대상 버전 통과.** 25개 알려진 점/20mm 간격·128mm 정사각 FOV·pixel 간격(행2,열1)mm에서 S=diag(sx,sy)를 적용한 뒤 원점 반시계 R을 적용한다. 배율 unit(1,1)/x(1.02,1)/y(1,.98)/sameArea(1.02,1/1.02)·회전0/30도·네 선분의32조건, 기본sameArea/30도/중심 가로다. 원래 좌표와 RSp의 물리 좌표/pixel 좌표·같은 선분의 길이·네 모서리 면적을 비교한다. 면적비det S=1이어도 일반적으로 길이비1이 아니다.

제품은 PhantomGeometry의 warp0 알려진 점/선분·MRPhysics.rotate를 재사용하고 공통 자산은 바꾸지 않는다. 독립 참조는20mm 격자를 직접 생성하고 정확한30도 sin=.5/cos=√3/2의 행렬곱·역행렬·모든300점쌍의 제곱 길이·배율 최소/최대 경계·독립 삼각형 분할 면적과 제품 shoelace 면적을 비교한다. 사전 좌표/pixel/길이/역변환1e−10, 제곱 길이/면적1e−8mm²다. 길이는회전 전후 같고 면적비는sx sy, sameArea의 가로 길이는늘고 세로는줄어드는 반례를 포함한다.

[DICOM PS3.3 2026d C.20.2.1.2](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.20.2.html)의 RIGID/RIGID_SCALE/AFFINE 구별과 [10.7.1.3](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_10.7.html)의 행/열 간격 순서 본문을 읽었다. 여기2D 열벡터/배율·행렬은 직접 정의한 예시이고 실제 DICOM4×4 등록 파일/환자 좌표를 처리하지 않는다. 도식/행렬식/길이 경계는 자체 유도와 독립 검산으로 확인한다. 원문 수식 이미지 시각 검토를 수행했다고 주장하지 않는다.

실제영상 검출/fitting/보간·장비 오차 측정/QA 허용 기준/환자 왜곡은 제외한다. 외부 전문가 검토 미시행이다.

[독립 수치 절차](X17-scale-numerical.cjs)·[결과](X17-scale-numerical.json)는32조건/800점/9,600점쌍에서 좌표 최대1.066e−14mm, pixel1.422e−14, 길이2.843e−14mm, 역변환1.422e−14mm, 제곱 길이3.638e−12mm², 면적1.819e−12mm², 면적비3.331e−16, 배율 길이 경계 위반1.422e−14mm로 사전 기준을 모두 통과했다. 최대 절대 좌표55.334mm는±64mm FOV 안이다. unit의 모든 길이 보존, 회전 전후의 배율 길이 보존, sameArea의 가로/세로 반례, 지원하지 않는 상태 거부도 시험했다.

[실제 Chrome 절차](X17-scale-browser-check.js)·[64개 상태 결과](X17-scale-browser-check.json)는1920/390에서6개 지표·25×9개 원표 값·두 도식의 원래/현재 각25점/변위선/선택 선분/PQ/모서리 다각형·고정 mm 축척·모바일 글자11px 이상·키보드/초기화/세 예제/두 문제·모든 선분 P/Q 행 이동과 좌우 끝 스크롤을 확인했다. SVG 좌표 최대1.137e−13은1e−8 이내, 실제 그린 다각형 좌표로 다시 계산한 면적 오차1.819e−12mm²는1e−8 이내다. JS 오류/페이지 가로 넘침0이다.

기본sameArea/30도/가로는 길이81.6mm/길이비1.02, 면적6400mm²/면적비1이다. 같은면적/세로는78.4313725490196mm/길이비.9803921568627451이며, unit/30도는80mm/길이비1이다. 같은면적의 대각 길이도 원래80√2mm와 일반적으로 같지 않다. sameArea의 sy=1/1.02를.98과 같은 값으로 표시하지 않았다.

설명·행렬 순서·축/행열/초기값·단위·길이 경계/면적식·두 정답과 적용 범위를 검토했다. [대상12개 입력 버전](X17-scale-versions.json)·[전체234개 시험](W100-tests.txt)은 별도 근거다. 초안 상태 문장의 다른 언어 문자를 한국어로 정정한 뒤 전체 시험/브라우저 확인을 수행했다. 공통 자산은 바꾸지 않았다. 시각 검토와 전체 탐색은 통합 기록에서 구분한다.
