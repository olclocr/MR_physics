# X14 기본 · 방향과 magic angle의 제한 모형 (W63)

2026-10-18. **직접 정의한 각도/R2와 유한한 횡이완 모형의 대상 버전 통과.** 실제 조직 fit/이완률·환자 진단이 아니다. 외부 전문가 검토 미시행. 전체 시험·탐색은 별도로 연결한다.

## 범위와 사전 기준

θ0/30/45/정확magic/70/90°,TE2/10/40ms의18조건이다. 완전 정렬 단일 축의 f=3cos²θ−1, R2=50+200f²(s⁻¹)를 방향 성분과 유한 바닥을 분리하기 위해 직접 정의한다.50/200과 함수 전체는 실제 힘줄/조직값이나 문헌 fit이 아니다. 초기 횡진폭1, RF/T1 가중 제외, 추가 offset/잡음0, T2=1000/R2(ms)로 공통 free의 T2 감쇠만 재사용한다. T2*·자화율 분포를 넣지 않는다.

각도0…90/181개0.5°격자와 정확magic의 별도1행, 시간0…60ms/61점, 신호0…1의 고정 축이다. 정확magic이0.5°격자 표본과 같다고 표시하지 않는다. 두 곡선·선택점·수치와 B0 대비 축 도식은 같은 상태를 사용한다. 참조는 R2의 방향 항만0으로 둔 가상 비교로서 실제 다른 조직/시퀀스가 아니다.

독립 기준은 축의 기울기에서 단위 벡터를 만들고 평행/수직 투영 차이로 f를 구한다. tanθ=√2의 root는 atan으로 계산해 product의 acos 근과 대조한다. 횡진폭 ODE를 RK4로 적분하며 공통 free/지수식을 reference 신호로 사용하지 않는다. 사전 기준은 신호1e−8, R2/T2·기하인자1e−9, 각도1e−9°다. f0이어도 바닥R2=50/T2유한20ms, 음의f의 제곱·양의감쇠, TE/고정 창을 따로 확인한다.

## 근거와 제외 범위

[Fullerton 등1985 출판사 초록](https://pubs.rsna.org/doi/10.1148/radiology.155.2.3983395)을 직접 읽어 방향 의존 T2와 기하 인자의 근을 확인했다. [Erickson 등1991 저자 초록](https://pubmed.ncbi.nlm.nih.gov/1924777/)의1.5T/자원자7명·방향/짧은TE 관찰, [Richardson 등2018 저자 초록](https://pubmed.ncbi.nlm.nih.gov/29995211/)의 교육/설문 연구도 직접 확인했다. 초록의 실제 조직값을 이 R2 식에 fit하지 않았으며 full text를 읽었다고 쓰지 않는다.

1991의 특정 획득에서 짧은TE에 보였다는 결과를 모든 T2W/STIR/DWI의 제외 규칙이나 보편 TE cutoff로 확대하지 않는다.2018 연구의 더 넓은 각도/시퀀스 오개념 논의도 이 제한을 지지하며 이번 모형의 각도 폭이나 정량 성능을 검증하는 자료로 쓰지 않는다.
