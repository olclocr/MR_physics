# X13 후속 · 물질/구획과 refocusing 조건의 독립 내용 검토

2026-10-18. Product 출력으로 정답을 만들지 않고 원전의 초록·대상·획득·물리량을 대조했다. 정성 근거 읽기이며 새로운 수치 이완모형은 없다. 외부 전문가 검토 미시행.

## 직접 읽은 자료와 접근 범위

1. [Gomori 등1987, NMR relaxation times of blood](https://pubmed.ncbi.nlm.nih.gov/3597895/). PubMed 검색 결과가 반환한 전체 저자 초록을 읽었다. 직접 페이지 열기는 HHS 한 줄, 출판사 열기는 접근 오류였으므로 본문을 읽었다고 하지 않는다.0.19–1.4T NMR의 intact/lysed 혈액·산화 상태·field/echo 간격 변화라는 범위를 보존한다. 초록만으로 정확한 pulse열·온도·농도·TE를 재구성하지 않는다.
2. [Thulborn 등1982, Oxygenation dependence](https://pubmed.ncbi.nlm.nih.gov/6275909/). PubMed 저자 초록을 검색 결과로 읽었다. CPMG pulse rate·국소 field gradient와 물 확산이라는 기전 범위만 사용한다. 데이터 피팅/산소포화도 추정은 수행하지 않는다. 서지 시스템의 T-1(2) 표기는 역수 T2의 표현이므로 T1 이완시간으로 옮겨 읽지 않는다.
3. [Thulborn 등1990, Ferritin and hemosiderin](https://pubmed.ncbi.nlm.nih.gov/1690500/). PubMed 페이지의 Abstract를 직접 읽었다. 쥐 혈종의 조직/생화학 대조·대칭/비대칭 T2W SE·linewidth 분포를 확인했다. 동반 comment는 염색 특이성에 관한 논의를 포함하므로 특정 염색만으로 모든 철 물질을 확정하는 진단 규칙을 만들지 않는다. 초록에 없는 field/TE 값은 미제시로 남긴다.

## 수식·도식·문제 검토

이완시간 T2와 역수 R2의 단위, 상대 영상 신호와 이완시간의 차이, interecho interval/TE의 차이를 읽었다. 접힌 식은 순간180°/대칭 Hahn echo의 전후 주파수 적분이 같을 때 정적 위상이 상쇄된다는 충분 조건이다. 각 적분은 rad이며, 물의 이동 후 서로 다른 주파수 이력을 가질 수 있다는 설명과 일치한다. 이 식으로 확산/T2 값을 새로 계산하지 않는다.

Oxy/deoxy의 세포 기호는 같은 수로 두어 농도 차이를 암시하지 않았다. 용혈액은 막 경계 없이 Hb 기호를 두며, 경계 소실이 모든 이완 소실을 뜻하지 않는다고 표시한다. 철 저장 도식은 분포 비교만 나타내며 임상/현미경 영상으로 제시하지 않는다. 분자 크기·절대량/전체 환자 분포로 확대하지 않는다.

용혈액 문제의 정답은 조건 의존성 소실과 이완 자체를 구별한다(R03). GRE 전이 문제의 정답은 시료/물리량/획득을 유지하고 일대일 물질·날짜 규칙을 만들지 않는다(R05–R08). 새로운 핵심 주장·field/온도·pulse열/숫자 이완률·실제 영상·환자 해석을 추가하면 해당 범위를 다시 검토한다.
