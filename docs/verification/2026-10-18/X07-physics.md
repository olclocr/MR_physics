# X07 기본 · 단일 구획의 입력과 washout (W74)

2026-10-18. **직접 정의한 혈장 입력/단일 EES 구획 모형의 대상 버전 통과.** 알려진 혈장 농도와 하나의 EES 구획 사이 교환을 전진 계산한다. MRI 신호 변환·실제 AIF·환자 fitting/진단은 포함하지 않는다. 외부 전문가 검토 미시행.

사전 범위는 Ktrans=0/0.1/0.2/0.4min⁻¹, ve=0.2/0.4의8조합이다. Cp=1mmol/L는0≤t<1분, 이후0으로 직접 정의하며 모든 조건에서 같은 입력이다. Ct(0)=0, 혈관 내 농도의 직접 기여 항은0으로 둔다. Ct는 조직 단위부피당 EES 기여 농도이고 Ce=Ct/ve는 EES 자체 부피당 농도다. dCt/dt=Ktrans Cp−kep Ct, kep=Ktrans/ve. 전체0…6분/121점과 선택0/.5/1/2/4/6분의48조건을 비교한다. 기본Ktrans.2/ve.2/t2분.

계산은 구간별 지수 해를 사용한다. 독립 기준은 입력 종료를 나누어 적분하는 입력 종료를 구간 경계로 나누는 scalar ODE RK4와 EES 유출량의 동시 적분, 별도 적응 없는 합성 Simpson 합성곱이다. 분 단위와 mmol/L·mmol/L/min을 유지한다. 사전 기준은 농도/누적량/유입·유출률1e−8, 보존 오차1e−8,1024→2048단계 수렴1e−8이다. UI/표/곡선·경계t1의입력 우극한/농도연속성·Ktrans0·키보드/예시/정답·두화면을 확인한다.

Tofts등1999 [원저자의 표준화 논문 초록](https://pubmed.ncbi.nlm.nih.gov/10508281/)에서 Ktrans/ve/kep의 정의·단위·비율을 확인했다. Ktrans의 혈류/투과성 관계는 조건에 의존하므로 이 페이지에서 하나로 단정하지 않는다. [Tofts와Kermode1991 원논문 초록](https://onlinelibrary.wiley.com/doi/10.1002/mrm.1910170208)은 구획 분석의 역사적 맥락만 뒷받침한다. 이 페이지의 직사각 입력과 계수는 연구의 환자 값/주입량/획득법을 재현하지 않는다. PubMed1991은 HHS안내만 돌아와 출판사 초록으로 확인했다.
