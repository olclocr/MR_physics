# X07 후속 · 혈관 직접항과 EES 항의 시간 응답 (W99)

2026-10-18. **지정된 혈관/EES 성분 모형 대상 버전 통과.** 직접 정의한 Cp1mM on[0,5)초·ve.2를 고정하고 vp0/.05/.1·Ktrans0/.01s⁻¹·t0/2/5/10/20초의30조건을 비교한다. 기본vp.1/Ktrans.01/t2초다. 혈관 기여 V=vpCp, EES의 조직 부피 기준 기여 T=Ktrans∫Cp exp(−kep age), 전체 Ct=V+T, Ce=T/ve를 구별한다. 기존W74/W98의 Ct는 혈관 직접항을 제외한 EES 기여였고 여기 전체Ct와 자동으로 같은 양이 아니다.

EES 초기T0=0이지만 입력은0초에 시작하므로 전체 Ct(0)=vpCp(0)다. 정확히5초의Cp/혈관항은 우극한0, T/Ce는연속이다. 전체Ct의5초 직전/직후 차이는vp×1mM다. 일반 표본4.9초와5초의 차이를 이 한계값 점프로 대신하지 않는다. 도식은5초의 좌극한 점을 따로 더한202점 총Ct곡선/열린 점과 우극한 채운 점으로 표시하고, 원표는201개 우측 포함 정의값을 사용한다.

제품은 W98에서 확장/기존 범위를 재검증한 공통 rectangularInputAt을 초↔분 변환으로 재사용하고 공통 자산은 바꾸지 않는다. 입력을 주어진 저장소로 취급하여 혈관항은vpCp로 직접 계산하고 EES 유입/유출 보존은T에만 적용한다. 전체Ct를 EES 누적 유입−유출로 잘못 계산하지 않는다.
