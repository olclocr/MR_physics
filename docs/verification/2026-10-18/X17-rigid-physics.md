# X17 후속 · 강체 이동과 거리 불변 (W88)

2026-10-18. **지정한2D 강체 변환·축별 pixel 간격의 대상 버전 통과.** W80의 알려진 5×5/20mm 격자를 원점에서 +0/30/90도 회전한 뒤 x로0/5mm 이동한다. 간격1/1 또는1/2mm·네 선분의48조건이다. 기본 이동5/회전30/행 간격2mm/중심 가로다. 기존 PhantomGeometry의 warp0 좌표/간격/선분과 MRPhysics.rotate의 순수 z축 회전을 변경 없이 사용한다. 실제 영상 registration/점 검출·보간/PSF·장비 QA 합격은 계산하지 않는다. X17 전체와 외부 전문가 검토는 미완료다.

독립 기준은 제품 자산을 호출하지 않고 정확한 단위 복소수 (1,0)/(√3/2,1/2)/(0,1)와 역변환, 모든300쌍의 제곱 거리 불변을 사용한다. 좌표/길이1e−10mm·pixel좌표1e−10·제곱 거리1e−10mm²를 사전 기준으로 했다. FOV±64mm 안에 모든 점을 유지하며 최대 절댓값 좌표는59.641017mm다. 전체 회귀·실제 두 화면/표/그림·내용 통합 판정까지 마쳤다.

[DICOM PS3.3 2026d §10.7](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_10.7.html)의 pixel 중심 간 거리·행/열 순서와 [C.20.2.1.2](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.20.2.html)의 RIGID가 회전/평행 이동만 포함하는 orthonormal 변환이라는 본문을 읽었다. 여기 알려진2D변환은 직접 정했고 실제 DICOM 등록 파일/환자 좌표·방향 행렬을 추정하지 않는다. 실제 registration 정확도나 장비/영상 QA 기준을 이 수학적 불변량으로 대신하지 않는다.

## 내용·좌표·단위 검토

설명·회전/이동 순서·mm/좌표 단위·y/v 부호·도식/표·문제 양답을 검토했다. 128×128mm FOV, Δx1mm/Δy1또는2mm,128×128또는128×64격자다. 물리 y는 위쪽, v는 아래쪽이고 u=(X+64)/Δx−1/2, v=(64−Y)/Δy−1/2다. Pixel Spacing 순서는(Δy,Δx)이다. 분수 좌표를 반올림하지 않는다.

회전 R 뒤 이동 b=(d,0)로 r′=Rr+b, Δr′=RΔr, RᵀR=I이므로 물리 길이가 보존된다. 환산 길이는 √[(ΔuΔx)²+(ΔvΔy)²]다. 비등방 pixel 좌표 자체를 같은 각도로 회전하는 연산으로 대신하지 않는다. 점의 이동은 원래 위치와의 차이고 길이 차이와 다르다. 원래 중심점도 d만큼 이동한다. r/c는 원래 점의 ID이며 현재 영상의 행/열 좌표가 아니다.

90도 회전에서 정사각 점 집합이 겹쳐 보여도 각 ID의 대응/선택 선분과 이동선은 바뀐다. 이는 초기화 실패가 아니며 이번 지정 변환의 결과다. 알려진 강체 좌표의 거리 보존을 실제 영상의 등록 정확도·보간/획득 왜곡이나 장비 QA 통과로 확대하지 않는다. 임상 영상은 없다.
