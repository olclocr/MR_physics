# X01 후속 · 첫 gradient moment와 등속 위상 보정 (W83)

2026-10-18. **같은 관찰 종료의 세 구간 gradient·등속 단일 spin 모형은 대상 버전 통과.** 실제 RF/echo/readout·속도 분포/복소합·가속/확산·유입/혈관 밝기·유량·장비/임상 성능은 구현하지 않았다. X01 전체와 외부 전문가 검토는 미완료다.

## 범위·단위와 사전 기준

G=2mT/m, 구간 길이 τ=1/2ms, 초기 위치 −1/0/1mm, 속도 −10/0/10cm/s, 파형 계수 (1,−1,0)/(1,−2,1)의 36조건이다. 기본값은 첫 파형/τ2/x₀1/v10이다. 두 파형 모두 종료 TE=3τ이며 명칭 TE가 실제 RF echo 형성을 뜻하지 않음을 명시했다. 가운데 두 배 lobe는 −4mT/m이다. 초기 M+=Mx+iMy=1, Mz=0, T1 회복/T2 감쇠·추가 offset/잡음은 제외했다. 공통 자유 세차의 T1/T2 기본값은 무한대이다.

기존 FlowGradientPhase의 G/γ와 MRPhysics.free를 변경 없이 재사용했다. 계산 위치 m, 속도 m/s, 시간 s, gradient T/m이며 φ=−γ(x₀A0+vA1)의 음의 자유 회전 규약이다. A0=∫Gdt, A1=∫tGdt는 시작 0초 기준이다. A0의 T·s/m와 A1의 T·s²/m에 각각 10⁶/10⁹를 곱해 mT·ms/m와 mT·ms²/m를 표시한다. A0는 평형 자화 M0와 구별한다. 모든 회전축이 z이므로 시간 평균 주파수의 공통 자유 세차가 같은 누적 위상을 재현한다.

독립 기준은 제품 자산을 호출하지 않고 SI 위치·횡 Bloch·위상·A0/A1 ODE를 각 표시 간격당 20/40단계 RK4로 풀었다. 두 gradient 경계를 정확히 분리하고 종료 모멘트의 독립 합과도 대조했다. 사전 허용 오차는 위상/복소값/위치 1e−8rad/정규화값/mm, 각 모멘트 SI 1e−14, norm 1e−10, 수렴 1e−8이다. 화면 6자리 표/지표 허용 오차는 5.1e−7, SVG는 1e−5 viewBox 좌표 단위이다.

## 근거와 내용 판정

[Haacke·Lenz 1987 원전 PDF](https://www.mriquestions.com/uploads/3/4/5/7/34572113/haake_gmn.pdf)의 p1252 등속 궤적과 p1253 추가 gradient에 의한 재위상화 설명을 텍스트로 읽었다. 이번 PDF 스크린샷은 cache miss로 실패했으므로 도식을 시각적으로 새로 확인했다고 기록하지 않는다. 여기 세 사각 구간은 직접 정한 교육 파형이며 원전의 RF/임상 파형이나 장비 성능을 재현하지 않는다.

설명·수식·단위·부호·그래프·표·퀴즈를 검토했다. 종료 A0=0은 초기 위치 항을 없애지만 등속 항은 A1에 남을 수 있다. (1,−1,0)은 A1=−Gτ², (1,−2,1)은 A0=Gτ(1−2+1)=0, A1=Gτ²(1/2−3+5/2)=0이다. 종료 A0=0이면 시간 원점을 옮겨도 종료 A1이 바뀌지 않는다. 중간 시각의 위상까지 0이라는 주장은 하지 않는다. 이완 없는 한 spin의 norm은 두 파형 모두 1이며 위상 보정을 크기 증가나 실제 flow void 제거로 해석하지 않는다.

시간 0…6ms·gradient ±4mT/m·위상 ±2rad의 고정 축에 각 조건의 0…3τ 301점을 그린다. 확인한 최대 절댓값 위상 1.605134rad는 창 안에 있다. 경계의 G는 오른쪽 구간 값, 종료 G는 0이며 빈/채운 표식으로 구별했다. 정지/이동 위상과 합이 같은 원표·곡선 계산을 사용한다. 두 문제의 양답 피드백은 A0/A1 조건과 단일 spin 크기 불변을 각각 설명한다.

## 수치·실제 화면과 한계

[독립 절차](X01-compensation-numerical.cjs)·[36조건 결과](X01-compensation-numerical.json)는 10,836개 시간점에서 통과했다. 최대 위상 차이 3.56e−13rad, 복소값 2.18e−13, 위치 4.81e−13mm, A0 3.48e−19T·s/m, A1 7.24e−22T·s²/m, norm 2.23e−16, 수렴 1.09e−12이다.

기본 종료 A1=−8mT·ms²/m, 위상 +0.214017751974rad, Re/Im=0.977185482965/+0.212387692400, 크기 1, 위치 1.6mm이다. 첫 모멘트도 0인 파형은 같은 위치 1.6mm에서 A0/A1/위상 0, Re/Im=1/0, 크기 1이다. 정지 spin은 첫 파형에서도 종료 위상 0이다. 초기 위치만 −1mm로 바꾸면 종료 위치 −0.4mm이고 중간 위상은 달라도 종료 위상은 기본값과 같다.

[실제 Chrome 절차](X01-compensation-browser-check.js)·[72개 상태](X01-compensation-browser-check.json)는 1920/390px에서 36조건 각각의 7개 수치·301×11 원표·세 위상 곡선·7점 gradient 계단·모든 경계 표식·종료점을 독립 자료와 대조했다. 최대 SVG 차이는 4.998e−6 viewBox 좌표 단위이다. 실제 글자 11CSSpx 이상·720×340 비율·중첩 SVG 없음·고정 축, 세 예제/초기화·키보드 Home/End/Arrow/Enter·두 문제 양답·sticky 표 머리/전체 열·종료 행 점프를 확인했다.
