# X12 후속 · 두 성분과 단일tensor 곡선 (W78)

2026-10-18. **같은 위상/무교환 두Gaussian 신호와 제한 xy ADC맞춤 모형의 대상 버전 통과.** 두 Gaussian 성분의 같은 위상/양의 정규화 신호를 섞고 xy 단일tensor 형태에 제한한 ADC 최소제곱 곡선과 비교한다. 실제 교차섬유 추정/성분 수 결정·tractography는 포함하지 않는다. 외부 전문가 검토 미시행.

두 성분은W77의고유값(1.4,.5,.5)×10⁻³mm²/s이고A는회전0/B는0/45/90도다. A의b0신호분율f=0/.25/.5/.75/1, b0/500/1000s/mm²의45조건이다. 기본분리각90도/f.5/b1000. 두성분간교환/위상차/잡음은없고f는신호분율이며실제섬유수/조직부피분율로해석하지않는다.

기존DiffusionTensor/ADCFit을변경없이재사용한다. Smix=fSA+(1−f)SB이고b>0에서ADCapp=−ln(Smix)/b이다. 0…175도/5도간격36고유방향에서1/cos2θ/sin2θ에동일가중투영한다. 180도는표시중복점일뿐fit에추가하지않는다. 신호공간이아닌ADC공간의최소제곱이고일반3D tensor fitting은아니다. b0은ADC/fit/잔차를정하지않는다.

독립기준은성분의상대각고유값방향식·양의지수합과별도3×3피벗정규방정식이다. Product의Fourier투영/기존신호API는사용하지않는다. 사전기준D/fit/잔차1e−12mm²/s,신호1e−8,신호분율보존/b0/단일성분·분리각0의반례1e−10이다. 실제두화면·37점원표/두곡선·b0미정표시·예시/키보드/정답과전체회귀를확인한다.

[Tuch등2002 원논문 초록](https://onlinelibrary.wiley.com/doi/10.1002/mrm.10268)에서단일tensor를벗어난방향패턴과Gaussian성분혼합의맥락을확인했다. 이페이지는그논문의성분복원/최적화/환자결과를재현하지않는다. 고유값/분율/각도는직접정의한교육값이다. 기본단일tensor정의는 [W77](X12-physics.md)에연결한다.
