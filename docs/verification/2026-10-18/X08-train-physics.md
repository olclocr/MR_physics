# X08 후속 · 유한 packet 방출과 도달/T1 차이량 (W91)

2026-10-18. **초기 총 차이량1·균일 유한 방출·같은 T1·도달 뒤 보관 모형의 대상 버전 통과.** D=.5/1초 동안 방출하며 각 packet은 방출 직후 control Mz=+1/label Mz=−1로 정규화한다. 이동 지연 δ=.5/1초, T1=1.6/2.2초, 첫 방출부터의 시각 t=0/.5/1/2/3초의40조건이다. 실제 ASL RF/읽기·효율/MT·PCASL PLD·조직 교환/유출·CBF/임상 추정은 계산하지 않는다. X08 전체와 외부 전문가 검토는 미완료다.

착수 시 W90의 전체214개 시험·실제 화면·내용 판정은 통과였다. 새 계산은 공통 MRPhysics.relax의 control/label 차이 (control−label)/2를 각 방출 시각 s에 대해 Simpson64로 적분한다. 초→ms를 명시적으로 변환하고 기존 순간 packet 자산과 공통 이완 자산은 바꾸지 않았다. W79의 gamma 커널은 다른 물리 모형이므로 재사용하지 않았다.

[Alsop 등 ASL consensus 원문](https://onlinelibrary.wiley.com/doi/10.1002/mrm.25197)의 Introduction 및 Time Delay Between Labeling and Imaging 본문을 읽었다. 실제 PCASL PLD는 labeling train 종료부터 acquisition까지이며 여기의 t(첫 방출 시작부터)와 다르다. 원문의 임상 권고값은 복사하지 않았고 D/δ/T1는 직접 선택한 교육용 값이다. 2015 권고 논문(온라인2014년)을 최신 임상 지침으로 표현하지 않는다.

## 독립 수치 판정

L=clamp(t−δ,0,D), 방출 분율=clamp(t,0,D)/D, 도달 분율=L/D이다. 남아 있는 차이량은 R=(1/D)∫₀ᴸexp[−(t−s)/T1]ds이며 닫힌 식은 (T1/D)exp[−(t−L)/T1]·[−expm1(−L/T1)]이다. 각 packet의 T1 시계는 방출 때 시작하며 도착 후에도 계속된다. 방출률/도달률은 각 구간 안에서1/D초⁻¹이다. 두 구간은 시작 포함·종료 제외이며 정확히 첫 도달 시각에는 도달률이 양수여도 누적 도달량/R은0이다.

[독립 절차](X08-train-numerical.cjs)는 제품 계산을 가져오지 않는 Gauss32/64 packet 구적·닫힌 식 및 도달 입력/회복 ODE의 RK4를 비교한다. ODE는 도달 구간에서 R′=exp(−δ/T1)/D−R/T1, 나머지에서 R′=−R/T1이며 경계를 분리하여 .025초당20/40단계를 썼다. 8개 D/δ/T1 조합의201개 시간점(총1,608점), 선택40조건에서 [최대 차이](X08-train-numerical.json)는 R2.749e−11·분율0·닫힌 식2.749e−11·Gauss 수렴6.67e−16·ODE2.749e−11·ODE 수렴1.02e−14다. 사전 기준은 차이/분율/수렴1e−8이며 모두 통과했다. 0≤R≤도달≤방출≤1과 최고점 δ+D도 확인했다.

## 내용·정규화·표시 검토

초기 총 차이량1은 D와 무관하게 고정된다. D가 짧으면 방출률1/D가 커지고 방출 나이 분포가 달라지며, 실제 labeling 기간을 같은 임상 방출률로 바꾼 조건이 아니다. 도달 분율은 초기량 가중치이고 T1 회복 후 남은 R과 다르다. 같은 T1/유출 없는 보관 가정에서는 모두 도달한 같은 절대 t의 R이 δ와 무관하다. 따라서 지연이 길면 항상 같은 t의 R이 작다는 주장은 하지 않는다. 도식의 막대 높이는 시간 구간을 표시하며 율은 별도 숫자로 읽는다.

기본 D1/δ1/T1 1.6/t2에서 방출=도달1·R=.39801061067419036·최고점2초다. 이른 도달 δ.5/t1은 도달.5·R=.3141667206852347·최고점1.5초/R=.544016003659236이다. 짧은 D.5/δ1/t2는 도달1/R=.33632265541421064·최고점1.5초/R=.45969856589646363이다. δ.5/t2/D1은 기본과 같은 R을 갖지만 최고점은 더 이르다. 수식·단위·포함 경계·정규화·본문/원표/곡선·두 문제의 양답을 이 조건들과 대조했다.

[실제 Chrome 절차](X08-train-browser-check.js)·[80개 상태](X08-train-browser-check.json)는1920/390px에서40조건의5출력·201×6원표·세 곡선/선택점/최고점·방출/도달 구간·시각 선을 독립 자료와 대조했다. 6자리 출력은5.1e−7, SVG는1e−5 viewBox 단위 기준이며 최대 그래픽 차이는4.996e−6이다. 두 그림의720×260/720×340비율·11CSSpx 이상 글자·중첩 SVG 없음·모든 조작의 Home/End/Arrow/Enter·세 예제/초기화·현재/최고 행 이동·전체 표 열·문제 양답/피드백을 확인했다.
