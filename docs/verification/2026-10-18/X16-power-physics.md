# X16 후속 · 주어진 흡수 파워와 에너지/평균률 (W93)

2026-10-18. **주어진 흡수 파워/균일 열손실 없는 모형의 대상 버전 통과.** 주기1초의 이미 주어진 흡수 파워 사각열에서 on파워1/2W·duty.25/.5/1·흡수기간10/20초의12조건을 비교한다. 기본2W/.5/20초다. 질량1kg·일정 비열4000J/(kg·K)는 직접 선택한 교육용 값이다. 전부 균일 내부 열에너지로 남고 다른 일/열손실·상변화는 없다고 가정한다. 실제 RF/B1→흡수·공간적 국소 발열·장비SAR·환자/implant 온도/안전 한계는 계산하지 않는다. X16 전체와 외부 전문가 검토는 미완료다.

평균 파워 Pavg=Pon·duty, E=∫₀ᵀPabs(t)dt, 선택 기간의 질량당 평균률=Pavg/m, ΔT=E/(mc)를 구별한다. 온도 변화는 mK로 표시한다(1K=1000mK). 둘 다 정수 주기라 평균은 duty식과 일치하지만 임의의 짧은 부분 주기의 평균으로 확대하지 않는다. 파워는 각 주기의 시작 포함·on끝 제외, T에서 종료다. 시간0…20초/.05의401점 전체 표/누적 E와 주기 평균으로 대체한 E 곡선, 첫2초 파워 step을 고정 축으로 표시한다.

사전 독립 기준은 명시한 각 on사건의 교집합 적분·이벤트 분리 에너지/온도 ODE의 RK4 8/16단계·정수주기 닫힌 식/에너지 보존이다. 파워/시간1e−12, 에너지/평균률/온도(mK)/수렴1e−9로 정한다. 같은 평균률/다른 기간, 같은 평균률/다른 duty, 같은 에너지/다른 평균률을 독립 검산하고 실제1920/390 화면의12조건/전체 표/그림/키보드/문제를 확인한 뒤 판정한다.

[OpenStax University Physics2 §1.4](https://openstax.org/books/university-physics-volume-2/pages/1-4-heat-transfer-specific-heat-and-calorimetry)의 내부 에너지·일/열·일정 비열 Q=mcΔT와 SI 단위를 본문으로 읽었다. 표의 실제 재질/인체 비열값은 사용하지 않는다. 이미 흡수된 에너지가 열에너지로 남는 직접 정의한 모형에 적용한다. [FDA Benefits and Risks](https://www.fda.gov/radiation-emitting-products/mri-magnetic-resonance-imaging/benefits-and-risks)의 RF 에너지와 신체 가열 가능성만 배경으로 읽었으며 수치/안전 규칙이나 허용 프로토콜을 가져오지 않는다. 기존 RF 회전 자산은 B1/회전을 계산하므로 흡수 파워로 변환하지 않고 그대로 둔다.

## 독립 수치·내용 판정

착수 기준은 W92의 전체218개 시험/실제 화면·내용 판정 통과였다. [독립 절차](X16-power-numerical.cjs)·[결과](X16-power-numerical.json)는12조건/4,812점에서 각 on사건의 교집합 적분과 제품의 주기 분해식을 비교한다. 사건 경계를 분리한 dE/dt=Pabs, dΔT/dt=Pabs/(mc)의 RK4 8/16단계도 비교했다. 최대 파워/시간/에너지/평균률/온도 직접 차이는0, ODE 에너지4.811e−12J·온도8.456e−13mK·수렴4.285e−12·E=mcΔT 보존1.777e−15J로 사전 기준 안이다. 구간 안의 미분은 일정하여 RK4 수렴 검사는 이 경우 적분 누적 부동소수점도 반영한다. 시간0에서E=0, 종료 후E/ΔT 유지, 주기 경계/on끝/T 포함 여부를 대조했다.

설명·단위·시작/끝·평균 기간·에너지/률·열용량/온도 변화·도식/표/두 문제 양답을 검토했다. 선택 T가 정수 주기인 경우에만 Pavg=Pon·duty를 썼고 임의 부분 주기의 평균으로 확대하지 않았다. 흡수 에너지와 정자기장의 유효 위치 에너지는 서로 다른 모형이다. W/kg를 실제 장비SAR/국소 발열 또는 허용 기준으로 표현하지 않으며 절대 체온은 정의하지 않았다. 흡수 입력과 열손실이 없어지는 것을 혼동하지 않았다.
