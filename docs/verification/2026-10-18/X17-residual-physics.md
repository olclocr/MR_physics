# X17 후속 · 이동 적합 잔차와 알려진 오차 (W103)

2026-10-18. **지정된 이동 적합/결정론적 오차 모형 대상 버전 통과.** 알려진25점 p의 실제 이동을 b0=(5,0)mm로 두고 관측 qj=pj+b0+(bias,0)+a(cos(2πj/25),sin(2πj/25))를 직접 정의한다. bias0/1/3mm·a0/.5/1mm의9조건, 기본bias3/a0이다. j는 원래 행 우선 점 순서이며 오차는 난수가 아니다. 이동만 최소제곱 적합하여 b̂=mean(q−p)를 구하고 RMS 잔차와 |b̂−b0|를 구별한다. 목표는 잔차/정답 오차·공통 편향/평균0 산포·독립 정답 정보의 필요성이다.

제품은 PhantomRigid shift5/angle0/rectangular의 알려진 점을 재사용하고 MRPhysics.rotate로 결정론적 원 위 오차를 생성한다. 공통 자산은 바꾸지 않는다. 독립 기준은 직접 생성한20mm 격자·Taylor 급수의 단위 복소근/반복 곱·이동 최소제곱 정상방정식·목적함수의 평행이동 제곱 완성으로 검산한다. 좌표/적합값/RMS/오차/합0은 사전1e−10mm, 목적함수는1e−8mm²다. 알려진 원 위 오차에서 RMS 잔차=a, 정답 이동 오차=bias이고 J(b̂+δ)=J(b̂)+25|δ|²를 독립 확인한다.

[Fitzpatrick/West/Maurer1998 원전 PDF](https://rire.insight-journal.org/pubs/ieee_tmi_special.pdf)의 PDF2–3쪽(인쇄1–2쪽)을 실제 렌더링하여 초록과 도입의 FRE/TRE 정의·적합 오차와 등록 정확도의 차이를 읽었다. 웹 추출 문자는 깨졌고 웹 screenshot 도구는 이미지 본문을 반환하지 않아 로컬 Poppler 렌더링으로 확인했다. 다른 PMC 자료는 봇 확인 화면이므로 본문을 읽었다고 주장하지 않는다. 원전의 확률/기하 분포/수술 오차 예측식을 구현한 것이 아니다. 이번 값은 직접 정의한 결정론적 이동 전용 반례이며 일반 FRE/TRE 통계적 독립성을 입증했다고 부르지 않는다.

실제영상 fitting/회전/변형 추정·장비QA 허용 기준/환자 등록/수술 오차 예측은 제외한다. 외부 전문가 검토 미시행이다.

[독립 수치 절차](X17-residual-numerical.cjs)·[결과](X17-residual-numerical.json)는9조건/225점과27개 목적함수 변화에서 좌표최대7.106e−15mm, 적합 이동/지표2.665e−15mm, 잔차 벡터합3.908e−14mm, 목적함수8.882e−15mm², 제곱 완성/최소점 항등식1.564e−13mm²로 사전 기준을 모두 통과했다. 반복 복소근은 제품의 회전 함수를 참조값으로 사용하지 않는다. 지원하지 않는 상태도 거부한다.

SVG 좌표 최대3.980e−13은 사전1e−8 이내이고 JS 오류/페이지 가로 넘침0이다. canvas stub으로 실제 화면을 대신하지 않았다.

기본bias3/a0은 적합(8,0)mm/잔차0mm/이동 오차3mm/관측 정답RMS3mm다. bias0/a1은 적합(5,0)mm/잔차1mm/이동 오차0mm, bias3/a1은 적합(8,0)mm/잔차1mm/이동 오차3mm/관측 정답RMS√10mm다. bias0/a0은 모든 오차0이다. 미소 부동소수점 잔여는 표시6자리의0과 구별한다.
