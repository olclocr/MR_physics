# X10 기본 · 주기 운동과 관찰 시간창 (W82)

2026-10-18. **알려진 주기 운동과 직접 정의한 양의 1D 단면 시간 평균의 대상 버전 통과.** 실제 MR cine 영상·복소 신호/k-space 수집·재구성·gating/부정맥·심장 기능 측정은 구현하지 않았다. X10 전체와 외부 전문가 검토는 미완료다.

## 범위와 사전 기준

위치 x(t)=10cos(2πt)mm, 주기 1초, 진폭 10mm를 직접 정했다. 각 시각의 단면은 중심 x(t), 표준편차 1mm, 공간 전체 면적 1인 Gaussian이다. 밀도는 mm⁻¹이다. 중심 위상 0/.125/.25/.5주기와 대칭 창 0/100/400ms의 12조건이다. 기본값은 위상 .25/100ms이다. 창 0은 순간 극한이며 0인 이완시간/신호 소실을 뜻하지 않는다.

시간은 −.25…1.25초/0.005초의 301점, 공간은 −18…18mm/0.1mm의 361점으로 고정했다. 실제 환자의 운동 범위/주기나 권고 창 길이는 아니다. 시간창 안의 41개 동일 시간 간격 점은 위치 예시이고 계산은 별도의 Simpson256 적분이다. 기존 W70의 API는 고정 bolus 파형/초 단위의 한정 창이므로 변경하지 않고 새 주기 단면 모형을 분리했다.

독립 기준은 Gauss-Legendre64/128과 x′=v, v′=−ω²x에 위치/위치제곱 적분 상태를 더한 ODE512/1024이다. Product의 닫힌 모멘트나 Simpson을 독립 기준에서 호출하지 않는다. 사전 기준은 밀도/적분 수렴 1e−7mm⁻¹, 평균/분산·ODE/수렴 1e−8mm/mm², 유한 공간창 면적 1e−10이다. 표시 지표/시간 표는 5.1e−7, 평균 밀도 표는 계산 오차+6자리 반올림을 포함해 6e−7, SVG는 1e−4 viewBox 좌표 단위로 대조한다.

## 근거와 내용 검토

[SCMR 교육 페이지의 공개 요약](https://learn.scmr.org/AssetListing/Physicians-Pre-Conference-Cardiac-Function-5054/Cine-Imaging-acquisition-and-recognizing-artifacts-41714)에서 시간/공간 해상도와 부정맥/호흡 움직임이 다뤄짐을 확인했다. 동영상이나 전체 자막을 시청했다고 기록하지 않는다. 관련 2013 cine 논문의 PMC 접근은 CAPTCHA로 돌아와 본문을 읽지 못했다. 이 페이지의 궤적·폭·양의 균등 평균은 직접 정의했고 실제 cine 시퀀스/재구성·심장 기능·임상 설정을 재현하지 않는다.

설명·수식·단위·평균/분산·도식/표·퀴즈를 검토했다. W는 입력 ms를 1000으로 나눈 초 단위이다. g평균=(1/W)∫g dt의 단위는 mm⁻¹이며 적분 구간은 t₀−W/2…t₀+W/2이다. 최초 내용 검토에서 W의 초 환산 설명과 혼합된 위/아래 첨자 적분 구간을 보강하여 명확한 문자식으로 바꿨다. 계산은 이미 초 단위를 사용했으며 결과를 바꾸지 않았다.

μ=Acos(ωt₀)sinc(ωW/2), E[x²]=A²[1+cos(2ωt₀)sinc(ωW)]/2이다. 위치 분산은 E[x²]−μ², 단면 분산은 σ²+위치 분산이다. 표준편차는 평균 주위의 퍼짐이며 원점 기준 RMS나 FWHM과 같지 않다. 평균 위치 0이 정지나 Gaussian 모양을 보장하지 않는다. 양의 단면의 전체 공간 면적 1은 시간 평균 뒤에도 1이고 유한 표시창의 면적은 따로 수치 확인했다. 이를 MR 자화/영상 신호 보존이나 실제 MR 재구성 전체로 확대하지 않는다.

## 독립 수치와 실제 화면

[독립 절차](X10-numerical.cjs)·[결과](X10-numerical.json)는 12조건·4,332밀도점에서 통과했다. 밀도 최대 차이 2.02e−8mm⁻¹, Product256/512 수렴 1.89e−8, 독립64/128 수렴 3.89e−16이다. 평균 차이 1.07e−14mm, 분산 4.27e−14mm², ODE 평균 2.88e−12mm/분산 5.90e−11mm², ODE 수렴 8.85e−10mm²이다. 공간창 면적 오차는 6.67e−16이다. 시험에서는 공간 밀도의 평균/분산 적분도 닫힌 모멘트와 대조했다.

위상 .25/100ms는 평균 0mm, 위치 표준편차 1.795977675mm, 단면 표준편차 2.055610812mm이다. 창 400ms에서도 평균은 0이지만 표준편차는 6.189215132/6.269480357mm이다. 위상 0/400ms에서는 순간 위치 10mm, 평균 7.568267286mm, 위치/단면 표준편차 2.101177367/2.327003723mm이다. 창 0은 두 단면이 같고 위치 표준편차 0/단면 표준편차 1mm이다.

[실제 Chrome 절차](X10-browser-check.js)·[24개 상태](X10-browser-check.json)는 1920/390px에서 모든 조건의 6개 수치, 361×3 밀도 표/301×2 시간 표, 위치 곡선·두 밀도 곡선·시간창/표본·순간/평균 위치를 독립 자료와 대조했다. 최대 SVG 차이는 1.51e−5 viewBox 좌표 단위였다. 고정 축·실제 viewBox 비율·중첩 SVG 없음·실제 글자 11px 이상, 순간 극한의 같은 곡선/창 표본 1개, Home/End/Arrow/Enter·세 예제/초기화·두 문제 양답·두 표의 전체 열과 세로 스크롤을 확인했다. JS 오류/페이지 가로 넘침은 0이다.
