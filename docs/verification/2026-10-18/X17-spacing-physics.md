# X17 후속 · 정확한 좌표와 잘못 가정한 간격 (W101)

2026-10-18. **지정된 좌표/간격 환산 모형 대상 버전 통과.** 알려진25점·실제 간격(행2,열1)mm·warp0·128열/64행을 고정한다. 가정 간격 square(1,1)/correct(2,1)/wide(2,2)mm·네 선분의12조건, 기본square/중심 세로다. 좌표u/v는모든 조건에서 같은 정확한 분수 pixel 중심 좌표이다. 환산만 다른 간격으로 수행한다. 물리 중심을 공통(0,0)으로 정의하고 가정 X=(u+.5−64)Δx가정, Y=(32−v−.5)Δy가정으로 표시한다. 실제/가정 FOV도 열수×열간격·행수×행간격으로 구별한다.

제품은 PhantomGeometry warp0/rectangular의 점/선분을 재사용하고 공통 자산은 바꾸지 않는다. 독립 기준은SI 단위의 물리 좌표/실제간격으로 pixel 좌표를 생성하고 별도로 가정 간격을 곱한다. 모든 좌표/선택 길이·모든300점쌍의 가정 축별 길이·정확한 간격의 보존·행/열 순서/가로/세로/대각 반례를 사전1e−10mm 및 제곱 길이1e−8mm²로 검산한다.

[DICOM PS3.3 2026d 10.7.1.3](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_10.7.html)의 행/열 중심 간 거리/값 순서 본문과10.7.1.1의 calibration 정보가 없을 때의 제한을 읽었다. 여기 간격은 직접 정한 가정/정답이며 metadata를 읽거나 수정하지 않는다. 실제 촬영/오보정 검출·장비QA 허용 기준/환자 계측/영상 보간은 제외한다. 외부 전문가 검토 미시행이다.

[독립 수치 절차](X17-spacing-numerical.cjs)·[결과](X17-spacing-numerical.json)는12조건/300점/3,600점쌍의 좌표·SI 환산/선택 길이·모든 쌍의 가정 축별 길이와 pixel 좌표 불변을 검산했다. 최대 좌표/pixel/길이/제곱길이 오차와 조건 간 pixel 좌표 변화는 모두0으로 사전1e−10/1e−8을 통과했다. 독립 값은 원점 중심 mm→m→실제 간격의 pixel→가정 간격의 mm 경로이며 제품 함수를 참조값으로 호출하지 않는다.

[실제 Chrome 절차](X17-spacing-browser-check.js)·[1920/390의24개 상태](X17-spacing-browser-check.json)에서6개 지표·25×7개 원표·두 도식의25개 점/선택선분/PQ/같은 mm 축·실제/가정 FOV 사각형·모바일 글자11px 이상·키보드/초기화/세 예제/두 문제·모든 선분 P/Q 행 이동과 좌우 끝 스크롤을 확인했다. SVG 좌표 오차0은 사전1e−8 이내이고 JS 오류/페이지 가로 넘침0이다. canvas stub으로 화면 확인을 대신하지 않았다.

기본(1,1)/세로의 같은 Δu0/Δv−40pixel은 정답80mm/환산40mm/오차−40mm/비.5다. 정확한(2,1)/세로는80mm/오차0, 같은(1,1)/가로는80mm/오차0이다. (2,2)/대각선은 정답80√2=113.13708498984761mm, 환산80√5=178.88543819998318mm다. (1,1)/대각선은40√5=89.44271909999159mm다. 한 방향의 일치로 전체를 보장하지 않는 설명/정답과 단위/행열 순서·두 FOV·원점 선택을 대조했다.
