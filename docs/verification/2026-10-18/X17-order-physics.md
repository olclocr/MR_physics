# X17 후속 · 회전/평행이동 순서와 원점 (W96)

2026-10-18. **알려진2D 강체 변환의 두 순서·같은 원점 모형의 대상 버전 통과.** W88의 알려진25점·중심20mm 간격·±64mm FOV와 같은 순수 회전을 사용한다. 반시계 θ0/30/90도·+x이동 d0/5mm·pixel 간격1/1 또는1/2mm·네 선분의48조건이며 기본30도/5mm/직사각/가로다. 열벡터의 순서A=T R p=R(p)+b, 순서B=R T p=R(p+b)를 같은 원점에서 비교한다. 현재 점 위치는 달라도 두 순서 모두 강체로 모든 길이를 보존한다. X17 전체와 외부 전문가 검토는 미완료다.

제품은 PhantomRigid.calculate의 회전 뒤 이동(A)·점/간격/선분을 그대로 쓰고, 공통 MRPhysics.rotate로 Rb를 구해 일정한 차이 Rb−b를 더하여 B를 만든다. 기존 자산은 바꾸지 않는다. 순서 차이의 크기는 모든 점에서 |Rb−b|=2d sin(θ/2), d0 또는θ0이면0이다. mm의 물리 좌표에서 변환한 뒤 u=(X+64)/Δx−.5, v=(64−Y)/Δy−.5로 표시한다. 비등방 pixel 좌표를 같은 각도로 직접 회전하지 않는다.

독립 기준은 정확한 각도 cos/sin 계수의3×3 동차행렬 곱 T R/R T와 역변환·각 순서300쌍 거리 불변이다. 사전 좌표/길이/순서 차이1e−10mm·pixel1e−10·제곱 거리1e−10mm²를 둔다. 두 도식의 물리 x/y 동등 축척·점/선분/원표·실제1920/390 화면·문제를 대조한다. 실제 점 검출/registration fitting·영상 보간/왜곡·환자 정합/장비QA는 계산하지 않는다.

[DICOM PS3.3 2026d C.20.2](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.20.2.html)의 Matrix Sequence 순서가 행렬 곱 순서에 중요하다는 본문과 C.20.2.1.2 RIGID의 회전/이동 제한을 읽었다. [§10.7](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_10.7.html)의 pixel 중심 간격·행/열 순서를 유지한다. 표준의4×4 실제 DICOM 데이터/환자좌표를 파싱하거나 본문의 이미지 수식을 새로 판독했다고 하지 않는다. 여기3×3 열벡터/순서/원점은 직접 정의한다. 외부 전문가 검토는 미시행이다.

## 독립 수치·내용 판정

착수 기준은 W95의 전체224개 시험·실제 화면·내용 판정 통과였다. [독립 절차](X17-order-numerical.cjs)·[수치](X17-order-numerical.json)는 공통 회전/기하 모델을 import하지 않는 정확한 각도 계수/동차행렬을 사용했다. 48조건의1,200원래점/2,400변환점, 두 순서의28,800점쌍을 대조했다. 최대 물리 좌표1.422e−14mm·pixel1.422e−14·길이2.843e−14mm·순서 차이8.882e−16mm·역변환1.422e−14mm·제곱 거리1.819e−12mm²로 사전1e−10을 통과했다. 최대 절댓값 좌표59.641017mm로 두 순서의 모든 점이±64mm 안이다. 순서A는 기존 W88 값과 정확히 같고 기존 자산은 바꾸지 않았다.

설명·열벡터/오른쪽 먼저 연산·같은 원점·회전 부호/단위·현재 위치/거리 불변·동등 물리 축척/비등방 pixel 환산·점ID/표/두 문제 양답을 검토했다. B는 물체의 새 중심이 아니라 고정 원점에서 이동한 점을 회전한다. 모든 점의 B−A=Rb−b가 같고 각 결과 안의 모든 길이는 보존된다. 전체 점 집합이 대칭으로 겹치는 것과 같은 ID 점의 대응을 구별했다. 길이 보존을 실제 영상 정합 정확도나 장비QA로 해석하지 않았다.

기본30도/5mm에서 원래 중심은 A(5,0)mm/B(4.330127018922194,2.5)mm로 순서 차이2.588190451025207mm다. 선택 가로 길이는 둘 다80mm이고(부동소수점2.85e−14mm 이내) 화면 차이0이다. 90도/5mm는 A(5,0)/B(0,5)mm·차이7.0710678118654755mm이며 길이는80mm다. 회전0/이동5는 두 중심(5,0)/차이0, 이동0/회전30은 두 중심(0,0)/차이0이다. 비등방 간격을 바꿔도 물리 도식/길이는 같고 u/v 환산만 바뀐다.
