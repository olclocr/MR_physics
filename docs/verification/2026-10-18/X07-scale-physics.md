# X07 후속 · 입력 크기와 구획 계수의 구별 가능성 (W98)

2026-10-18. **직접 정의한 입력/계수 스케일·단일 구획 모형의 대상 버전 통과.** Cp=f mM on[0,5)초, f.5/1/2를 직접 정의한다. 고정계수 Ktrans=.01s⁻¹/ve=.2와 보상형 Ktrans=.01/f s⁻¹/ve=.2/f를 비교한다. 두 유형×f3×관찰0/2/5/10/20초의30조건이며 기본보상형/f2/t10초다. kep=Ktrans/ve=.05s⁻¹는 두 유형 모두 고정이다. 고정형에서는 입력을 키우면Ct도 커지지만 보상형에서는 전체 Ct 곡선이 기준f1과 같을 수 있다. 실제 MRI신호/측정AIF·환자fitting/진단의 일반적인 식별가능성 결론으로 확대하지 않는다. X07 전체와 외부 전문가 검토는 미완료다.

Ct는 조직 단위부피당 EES 기여 농도, Ce=Ct/ve는 EES 자체 부피당 농도이며 mM=mmol/L다. 혈관 직접항은 제외한다. dCt/dt=Ktrans Cp−kepCt, Ct0=0을 사용하며 입력 종료5초에서Cp 우극한0/Ct연속이다. 기존W74의 분 단위와 달리 여기t/시간축은초이고 Ktrans/kep는s⁻¹다. 공통 계산 호출에서는 t/60분·Ktrans×60min⁻¹·입력기간5/60분으로 명시적으로 변환한다.

기존 compartment-exchange-model.js의 비공개 사각 입력 계산을 검증/기본값을 가진 rectangularInputAt 공통 함수로 추출하여 입력기간/크기만 확장했다. 기존W74의1분/1mM·분단위 API/모형 결과는 보존했다. 변경 전 기존48모델·96개 실제 상태의 전체모델/출력/원표/SVG 지문을 저장하고 이후 정확히 같음을 확인했다. 기존 독립 수치/실제96상태를 별도 이름으로 재검증한 뒤 공통 자산의 현재 지문을 갱신했다. 과거 검증 기록은 덮어쓰지 않았다.

새 모형은 독립 합성곱 구적/사건분리 구획 ODE·스케일 불변/단위/농도 분모를1e−8로 검산한다. 초0…20/.1의201점·30조건의 실제 두 화면/표/고정 축/대표 비교/문제까지 확인하기 전에는 완료로 표시하지 않는다.

[Tofts 등1999 저자 초록](https://pubmed.ncbi.nlm.nih.gov/10508281/)의 Ktrans/ve/kep 정의·비율과 조건부 혈류/투과성 해석을 읽었다. 입력사각형/기간/계수는 직접 선택했다. 보상형의 스케일 불변은 이 잡음 없는 전진식에서 직접 유도하며 원문이 모든 실제 환자 추정의 비유일성을 증명했다고 표현하지 않는다. 실제 AIF오류/혈관항/잡음·신호변환/환자fitting·진단은 제외한다. 외부 전문가 검토는 미시행이다.

## 새 모형의 독립 수치·내용 판정

[새 독립 절차](X07-scale-numerical.cjs)·[결과](X07-scale-numerical.json)는 제품 함수를 사용하지 않는 초 단위 Gauss32/64 합성곱과 유출 누적 ODE를 비교한다. 6조합/1,206점·30조건의 최대 농도차3.886e−16mM·률3.470e−18mM/s·누적량8.327e−17mM·구적 수렴4.441e−16·ODE2.776e−16·ODE 수렴2.082e−16·스케일 불변0·보존3.470e−16으로 사전1e−8을 통과했다.

단위/초↔분·농도 분모·Ktrans/ve/kep·입력 경계·보상 규칙/기준/고정계수·설명/표/곡선/문제 양답을 검토했다. 보상형은 Ktrans Cp와kep가 같아 같은 초기값의 방정식이 되므로 전체Ct가 같다고 직접 유도했다. 같은Ct/다른Ce=Ct/ve를 구별하며 이 제한된 전진식의 반례를 모든 환자fitting으로 확대하지 않았다. 원표의 보존식은 누적 유입−누적 유출=Ct이며 순간률에서 누적량을 빼지 않는다.

기본 보상f2/t10초는 Ktrans.005s⁻¹·ve.1·kep.05s⁻¹·Ct=.034454024671754284mM/조직·Ce=.3445402467175428mM/EES다. 보상f.5는 Ktrans.02/ve.4/Ct가 같고 Ce=.0861350616793857이다. 고정f2는 Ktrans.01/ve.2/Ct=.06890804934350857·기준과 차이=.034454024671754284다. 보상f2/t5초의 Cp0/유입0이어도 Ct=.04423984338571902·Ce=.4423984338571902이며 Ct는 연속이다. Cp의5초 직전/직후는 열린/채운 점으로 구별했다.
