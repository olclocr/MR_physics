# W85 · 혈류·시간곡선·field 본문의 띄어쓰기

2026-10-18. **정적 공백 편집의 바이트·계산/표시 불변 검증 완료.** 등속 gradient 위상·VENC·선형 field 보정·관측 시간창·DSC 신호 변환의 5개 페이지에서 본문/단위/확인 문제·출처 134개 text node의 공백을 보강했다. 과학 내용/수식/정답 의미·계산/입력 범위는 보존했다. 새 물리 판정을 부여하지 않는다.

## 범위와 정확한 복원

[편집 전 81개 manifest/754항목](W85-before-versions.json)과 [정적 공백 편집 목록](W85-copy-edits.json)을 고정했다. [절차](W85-copy-audit.cjs)·[결과](W85-copy-audit.json)는 748개 입력의 바이트 불변과 6개 HTML 참조 항목의 편집을 확인했다. 고유 편집 파일은 5개이며 X01 HTML이 W60/W69 두 manifest에서 참조된다.

각 text node의 이전/이후 문자열과 위치로 역치환하여 이전 SHA를 정확히 재현했다. 모든 비공백 문자·실제 태그/속성·script/style 바이트가 같다. 링크/강조로 분리된 문장도 node별로 다뤘고 부등호를 문자로 보존했다. [manifest 갱신](W85-manifest-updates.json)은 이 가역적인 공백 편집만 반영했다. 모델/검산 자산은 바뀌지 않았다. 기존 사용자 변경을 삭제하거나 reset/stash를 사용하지 않았다.

SVG 글자·동적 상태/피드백은 script 보존 범위이므로 이번 정적 본문 편집으로 바꾸지 않았다. 공백 외의 어색한 표현은 이번 범위에 섞지 않는다. 선형 field 페이지의 ‘여기 후 관찰 시간’ 문장과 퀴즈의 ‘이완 0’은 후속 W89에서 뜻을 명확히 하는 별도 문구 수정으로 다룬다. 본문은 T1/T2 무한대와 T1 시간을 0으로 설정하지 않음을 이미 명시한다.

## 실제 화면과 표시 데이터

[편집 전 44개 상태](W85-before-browser.json)와 [최종 44개 상태](W85-browser-check.json), [실제 Chrome 절차](W85-browser-check.js), [비교](W85-browser-comparison.json)를 대조했다. 1920/390px에서 각 페이지 기본값·모든 예제를 확인했다. VENC와 DSC는 예제 4개씩, 나머지는 3개씩이다. 모형 결과 전체·모든 tbody 셀·SVG outerHTML의 직렬화 SHA-256과 출력 텍스트/행 수가 모두 같았다. JS 오류/페이지 가로 넘침은 0이다.

[설명 읽기 절차](W85-reading-browser.js)·[두 화면 10경로](W85-reading-browser.json)는 접힌 설명·본문/수식·출처를 펼치고 각 페이지의 문제 버튼 4개와 Enter 초기화를 확인했다. 숫자/기호/단위가 문장에 붙던 부분을 나누고, 같은 가정/경계/출처/한계를 보존했다. 대표 모바일 본문과 데스크톱 수식을 직접 읽었다. [전체 회귀](W85-tests.txt)의 206개 시험이 통과했다.

[편집 대상 16개 입력](W85-versions.json)·[통합 탐색](checkpoint-W85-navigation.md). 기존 X01/X03/X15/X04/X06의 물리 판정은 비공백 문자와 계산/표시 불변 근거로 보존한다. 과거 정확한 문구 assertion은 당시 버전의 기록이며 최신 공백 버전은 W85 절차를 사용한다. 실제 임상/외부 전문가 검토를 새로 수행한 것으로 확대하지 않는다.
