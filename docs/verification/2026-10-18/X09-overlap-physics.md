# X09 후속 · 두 입력의 지연 반응 겹침 (W84)

2026-10-18. **알려진 두 입력·정의한 인과 커널의 선형 합은 대상 버전 통과.** 실제 신경 사건 수/BOLD 신호·산소화/혈역학·실제 HRF 추정·적응/비선형 생리·잡음/fMRI 통계/환자 진단은 구현하지 않았다. X09 전체와 외부 전문가 검토는 미완료다.

## 범위·단위와 사전 기준

첫 입력 u₁은 [2,4)초에 1, 둘째 u₂는 [2+Δ,4+Δ)초에 크기 a이다. 시작 사이 간격 Δ2/6/10초·둘째 크기 a0/.5/1·커널 τ1/2초의 18조건이다. 기본 Δ6/a1/τ1이며 a0은 둘째 입력이 꺼진 경우다. 입력 합이 0…1인 두 구간은 겹치지 않고 Δ2에서 이어진다. 입력 시각·길이·크기는 모두 알려져 있다.

기존 DelayedResponse.calculate의 길이 2초 반응을 변경 없이 사용한다. y₁(t)=y₀(t), y₂(t)=a·y₀(t−Δ), y=y₁+y₂이다. 시간 격자 0…24초/0.1초의 241점에서 이동은 정확한 격자 정수 간격이다. 무차원 입력/반응, 커널 h의 단위 s⁻¹, h 전체 면적 1, 전체 반응 면적 2(1+a)초이다. 고정된 비음수 h와 0≤u≤1에서 0≤y≤1이므로 두 그림의 값 0…1 고정 축과 맞는다. 지표/작은 원/표의 선택 행은 공통 관찰 시각 10초다.

독립 기준은 제품 모형을 호출하지 않고 전역 시간의 각 입력 구간에서 직접 합성곱을 Simpson1024/2048로 적분한다. 별도의 3단계 filter ODE와 누적 반응 적분을 입력 경계 분리·각 표시 간격20/40단계로 풀고, 100초까지 누적 적분으로 전체 면적을 확인했다. 사전 오차는 성분/합/적분 수렴/ODE/수렴/전체 면적 1e−8이다. 화면 6자리 지표/표는 5.1e−7, SVG는 1e−5 viewBox 좌표 단위를 사용한다.

## 근거와 내용 판정

[Boynton 등 1996 원논문 초록](https://pubmed.ncbi.nlm.nih.gov/8753882/)을 다시 읽었다. 선형 가설에 대한 검사는 특정 V1 자료의 경험적 맥락이며 실제 BOLD의 보편적인 선형성을 뜻하지 않는다. [Glover 1999](https://pubmed.ncbi.nlm.nih.gov/10191170/) 직접 접근은 이번에도 CAPTCHA여서 새 본문 검토를 수행했다고 기록하지 않는다. 이 페이지의 gamma 커널·입력/계수는 직접 정의한 교육용 값이며 두 논문의 측정 HRF를 재현하지 않는다.

설명·단위·인과성·입력 구간 포함/제외·이동/가중합·축/표·문제 양답을 검토했다. 입력 2회가 두 개의 분리된 봉우리를 보장하지 않으며 겹침은 각 성분과 합으로 확인한다. a만 반이면 둘째 기여만 모든 시각에서 반이고 첫 기여는 같다. a0이면 첫 반응으로 돌아온다. 입력이 끝나도 반응이 남을 수 있다. 전체 시간 면적과 0…24초 유한 표시창의 면적을 구별했고 이를 실제 BOLD 신호의 보존 법칙으로 확대하지 않는다.

초기 지표 시각 8초는 기본 둘째 입력 시작이어서 크기를 바꿔도 둘째 반응이 0이었다. 예제의 크기 효과를 지표에서도 볼 수 있게 최종 관찰 시각을 10초로 정하고 독립 자료·표/원/문구를 함께 갱신한 뒤 검증했다. 순방향 모형이므로 봉우리 수를 자동으로 실제 사건 수로 판정하지 않는다.
