# X01 후속 · 가속 궤적과 두 번째 gradient moment (W87)

2026-10-18. **일정 가속 단일 spin·두 번째 모멘트 보정의 대상 버전 통과.** x(t)=x₀+v₀t+at²/2, x₀1mm/v₀10cm/s인 단일 spin을 같은 4τ 종료에서 비교한다. G2mT/m·τ1/2ms·a−20/0/20m/s², 네 구간 계수 (1,−2,1,0)/(1,−3,3,−1)의 12조건이다. 초기 M+=1/Mz0, 이완/확산/잡음·RF echo/영상·속도 분포/유량/실제 임상 보정은 제외한다. 기존 FlowGradientPhase의 G/γ와 MRPhysics.free를 변경 없이 재사용하며 W83의 3구간/등속 API는 변경하지 않는다. X01 전체와 외부 전문가 검토는 미완료다.

위상은 −γ(x₀A0+v₀A1+aA2/2), A2=∫t²Gdt이다. A0/A1/A2의 SI T·s/m, T·s²/m, T·s³/m에 각각10⁶/10⁹/10¹²를 곱해 mT·ms/m, mT·ms²/m, mT·ms³/m로 표시한다. 독립 SI 위치/속도·횡 Bloch·위상/모멘트 ODE20/40단계와 종료 닫힌 모멘트를 대조했다. 사전 기준은 위상/복소/위치/속도1e−8, A0/A1/A2 SI1e−14/1e−17/1e−20, norm1e−10·수렴1e−8이다. 고정 시간0…8ms·G±6mT/m·위상±4rad, 401점의 전체 표/네 위상 곡선/예제·실제 두 화면/내용 판정까지 마쳤다.

[Haacke·Lenz 1987 원전](https://www.mriquestions.com/uploads/3/4/5/7/34572113/haake_gmn.pdf) p1252의 궤적/위상 적분과 p1253의 가속 spin·등속 항 제거/추가 파형의 구별을 텍스트로 확인했다. 여기 가속 궤적·네 사각 구간은 직접 정한 교육 모형이며 원전의 RF/임상 시퀀스·보정 성능을 재현하지 않는다. 핵심 A2 계수와 부호는 직접 모멘트 합과 독립 ODE로 검산했다. PDF 도식을 새로 시각 검토했다고 기록하지 않는다.

## 내용·단위·부호 판정

기본은 첫 파형/τ2/a20이다. 모든 자유 회전축이 z이므로 시간 평균 주파수로 같은 누적 위상을 재현한다. 위치m·속도m/s·가속m/s²·시간s로 변환한다. T1 회복/T2 감쇠를 제외하며 공통 기본값은 무한대이고 이완시간0을 뜻하지 않는다. 실제 RF echo를 계산하지 않는다.

설명·수식·단위·부호·표/도식·문제 양답을 검토했다. 첫 파형은 종료 A0=A1=0, A2=Gτ³(1−14+19)/3=2Gτ³이다. 두 번째는 A0=A1=A2=0, A2=Gτ³(1−21+57−37)/3=0이다. 가속 위상의 1/2은 at²/2에서 나온다. 종료 A0/A1=0이면 시간 원점 이동에도 종료 A2는 같다. a0은 같은 A2에서도 가속 항이0이다. 두 파형 모두 단일 spin 크기1이며 중간 위상이 항상0이거나 실제 모든 움직임/flow void를 제거한 결과는 아니다. 음의 가속에서 속도가 반전되는 조건도 같은 궤적/부호로 계산한다.
