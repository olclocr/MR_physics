# X09 기본 · 입력과 지연 반응 (W79)

2026-10-18. **직접 정의한 입력과 인과적 gamma 합성곱 모형의 대상 버전 통과.** 실제 신경 활동·BOLD 백분율·표준 HRF를 추정하지 않는다. X09 전체의 산소화/BOLD 기전·fMRI 분석/통계·활성화 추론은 미구현이며 외부 전문가 검토도 미시행이다.

## 범위와 사전 기준

입력은 2초에 시작해 D=2/6초 동안 1, 그 외 0이다. 시작은 포함하고 종료는 제외한다. 커널 h(t)=t²exp(−t/τ)/(2τ³)는 t≥0에서만 정의하고 τ=1/2초이다. 입력과 반응은 무차원, h는 s⁻¹, 커널 전체 면적은 1이다. 선택 시각 0/2/4/8/12/20초의 24조건, 반응 0–24초의 241점, 커널 0–12초의 121점을 사용한다. 기본값은 D=2초/τ=1초/t=8초이다.

Product는 구간별 gamma 누적함수의 차이와 연속 최고점의 해를 사용한다. 독립 기준은 Simpson 합성곱 1024/2048 구간, 입력 시작/종료에서 분리한 3단 저역통과 ODE의 RK4 1024/2048 단계, 최고점 도함수의 이분법이다. 사전 허용 오차는 반응·커널·ODE·수렴 1e−8, 최고점 시각 1e−8초이다. 표시 6자리 값은 5.1e−7, SVG 좌표는 1e−5 viewBox 좌표 단위로 확인한다.

## 근거와 내용 검토

[Boynton 등(1996) 원논문 초록](https://pubmed.ncbi.nlm.nih.gov/8753882/)에서 일부 V1 자료의 선형 변환 가설을 검사한 맥락을 확인했다. [Glover(1999) 검색 색인 초록](https://pubmed.ncbi.nlm.nih.gov/10191170/)에서 적용 범위와 비선형성의 문제를 확인했다. 직접 접근은 CAPTCHA로 돌아왔으므로 본문을 읽었다고 기록하지 않는다. 커널과 수치는 두 논문의 측정값·표준 HRF를 복제하지 않고 직접 정했다.

설명·수식·단위·범위·도식·표·퀴즈를 다음 내용과 대조했다. y(t)=∫u(s)h(t−s)ds의 단위는 무차원×s⁻¹×초이므로 무차원이다. 인과성 때문에 t≤2초의 반응은 0이다. h의 도함수는 t(2τ−t)exp(−t/τ)/(2τ⁴)이므로 커널 최고점은 지연 2τ이다. y의 도함수 h(t−2)−h(t−2−D)의 근은 2+D/[1−exp(−D/(2τ))]초이고 입력 종료보다 뒤에 있다. 입력 종료 시각의 입력은 0이지만 과거 입력의 반응은 양수일 수 있다. 입력의 경계 한 점은 연속 적분 면적에 영향을 주지 않는다.

고정된 비음수 커널의 면적이 1이므로 전체 반응 면적은 D초이다. 0–12초 커널이나 0–24초 반응의 유한 표시창 면적이 전체 면적과 같다고 표시하지 않는다. τ가 커져도 전체 커널 면적은 같고 폭/높이는 달라진다. 이 면적 관계를 실제 BOLD 보존 법칙이나 신경 활동 복원으로 해석하지 않는다. 퀴즈는 입력 종료 뒤 반응이 남는 것과 교육용 지연 곡선으로 환자의 신경 활동 시각을 판정할 수 없는 것을 정답으로 둔다.
