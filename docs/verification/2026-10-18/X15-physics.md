# X15 기본 · 균일 offset과 선형 field 보정 (W68)

2026-10-18. **알려진1차원 직선 field/동일 가중401점 모형의 대상 버전 통과.** 실제 장비 shim/측정·고차field·RF/안전/환자 품질의 검증은 아니다. 외부 전문가 검토 미시행. 전체 회귀/탐색은 별도로 연결한다.

## 사전 범위와 독립 기준

Field는 균일(a30Hz/b0), 선형(a0/b2Hz/mm), 혼합(a30/b2)의 세 조건, 보정은 무보정/상수/상수+선형, TE0/5/12.5ms의27조건이다.40mm 관측 구간의401개 동일 가중 중점, 초기횡자화1이며 관찰 동안T1회복/고유T2감쇠를 포함하지 않는다(공통free의T1/T2기본값무한대). RF를 적용하지 않고 잡음/이동/수신 차이도 포함하지 않는다. T1시간0을 뜻하지 않는다. 관찰은 평균/퍼짐·상수의 공통 위상·기울기 제거와 복소합이다.

Product는 원 field의 평균/중심화 최소제곱 직선을 구해 해당 항을 빼고, 공통 free로 각 위치를 회전시킨 뒤 복소 평균한다. 위상은|S|≤1e−8에서null로 표시하며 수치 규칙이지 임상SNR 역치가 아니다.0…30ms/121점·주파수−80…80Hz·공간−20…20mm·|S|0…1을 고정한다.

독립 기준은 대칭 중점 격자의 기하급수 복소합과 좌표 moment 항등식이다. Product 반복 회전/최소제곱 코드를 사용하지 않고, 정의한 원계수와 정확한 투영으로 잔여계수/평균/σ를 구한다. σx=40√[(401²−1)/(12·401²)]mm이며 signal은 유한401점 geometric sum이다. 추가로 선택TE의401위치 횡ODE RK4/512단계와1,024단계 수렴을 대조한다. 복소/크기/위상1e−8, Hz/기울기/좌표1e−9를 사전 기준으로 둔다.

## 근거와 물리 내용 검토

[Gruetter1993 FASTMAP 원전](https://onlinelibrary.wiley.com/doi/10.1002/mrm.1910290613)의 출판사 검색 결과가 반환한 저자 초록을 읽었다. 실제 first/second-order coil과 field projection을 통한 localized adjustment를 확인했다. PubMed429/출판사 직접 열기 오류로 본문 전체를 읽었다고 표현하지 않는다. 원전의 장비·차원/coil·측정·선폭/성능은 이번 상수/선형 모형의 정량 근거로 쓰지 않는다.

40mm/30Hz/2Hz/mm·401점은 직접 정의한 교육값이다. 이 보정은 알려진 field를 빼는 이상적 연산이며 실제 coil 전류나 calibration을 구하지 않는다. 동일 상수 주파수 이동은 위치 사이 주파수 차이를 유지해 공통 위상만 바꾼다는 설명, 분산/위상분포·복소합/절댓값합·평균0/균일성의 차이를 검토했다.

N03의 연속 구간 sinc/고유T2 모형과 유한점/이완0의 이번 조건을 구별한다. 같은 회전은 공통 free를 재사용하지만 기존 메뉴에 맞지 않는 순수 field projection/유한점 합은 새 함수로 분리했다. 기존 N03 계산/자료를 바꾸지 않는다. 접힌 최소제곱 식과 단위·population σ/FWHM의 차이·401점/가중·복소 회전 부호·T2와 상쇄 재상승·수치 역치·도식/표/퀴즈 정답의 정합성을 검토했다. 추가 계산 오류는 발견하지 않았다.
