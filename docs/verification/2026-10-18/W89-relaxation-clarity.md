# W89 · 관찰 시간과 이완 제외의 표현

2026-10-18. **세 문구의 정확한 편집 범위·계산/표시 데이터 보존 검증 완료.** linear_field_correction의 설명 두 곳과 같은 표현을 쓰던 정답 피드백 한 곳을 명확히 했다. 계산·공통 자산/입력 범위·수식/물리 조건/정답 의미는 유지하며 새 물리 판정을 부여하지 않는다.

## 바뀐 표현과 실제 계산

‘여기 후 관찰 시간’은 ‘이후 관찰 시간’으로 고쳤다. 정답의 ‘이완 0 가정’은 ‘이완 효과를 제외한 가정’으로 바꿨다. 정답 선택 뒤 피드백에도 같은 모호한 표현이 있어 ‘이완/잡음0’을 ‘이완 효과 제외/잡음0’으로 맞췄다. 정적 문구만 고치고 피드백을 남기면 같은 혼동이 다시 생기므로 같은 작업 범위로 처리했다.

실제 LinearFieldCorrection의 signal은 MRPhysics.free에 초기(1,0,0), timeMs, 주파수만 전달한다. free/relax의 t1Ms/t2Ms 기본값은 Infinity이며 회복/감쇠를 제외한다. T1/T2 시간을0으로 설정한 계산은 없다. 기존 본문의 ‘T1 시간을0으로 설정한다는 뜻이 아니다’와 실제 동작이 일치함을 읽어 확인했다. 고유 T2와 공간 위상 상쇄는 구별하며 기존 W68/W76 판정을 확대하지 않는다.
