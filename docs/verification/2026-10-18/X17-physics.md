# X17 기본 · 알려진 격자와 영상 거리 (W80)

2026-10-18. **직접 정의한 2D 점 좌표·비선형 위치 변형·축별 간격의 대상 버전 통과.** 실제 촬영한 phantom/환자 영상이 아니며 QA 허용치나 장비 합격을 판정하지 않는다. X17 전체의 SNR/균일도/ghosting·실제 획득/계측은 남아 있고 외부 전문가 검토는 미시행이다.

## 범위와 독립 기준

각 축 −40/−20/0/20/40mm의 알려진 25점을 직접 정했다. FOV는 128×128mm, 열 간격 Δx=1mm, 행 간격 Δy=1/2mm이며 격자는 128×128/128×64이다. 변형은 r′=r[1+k(x²+y²)/(40mm)²], k=0/.02/.04이다. 중심 가로/세로·가장자리 가로·대각선 네 선분의 24조건이다. 기본값은 간격 1/1mm, k=.02, 중심 가로이다.

Product는 반지름 제곱을 사용한 좌표 변형과 분수 pixel 좌표로부터의 거리 환산을 계산한다. 독립 기준은 x′=x+k(x³+xy²)/1600, y′=y+k(y³+yx²)/1600의 전개된 다항 좌표와 선택 선분의 닫힌 길이이다. 중심 가로/세로 길이는 80(1+k), 가장자리 가로는 80(1+2k), 대각선은 80√2(1+2k)mm이며 최대 점 이동은 80√2·k mm이다. 제품의 거리 환산 함수를 독립 기준에서 호출하지 않는다. 사전 허용 오차는 좌표/거리 1e−10mm, 좌표 index/상대 차이 1e−10이다. 표시 6자리 값은 5.1e−7, SVG는 1e−8 viewBox 좌표 단위로 대조한다.

기존 G01의 geometry는 획득 수 16/32/64와 점/경계 Fourier 모형에 맞춘 API이다. 이 페이지는 정확히 주어진 128열 좌표 도식이며 G01의 획득/PSF 계산을 호출하거나 변경하지 않았다. 단순 축별 환산에 획득/재구성 의미를 혼합하는 의존성을 추가하지 않았다. 기존 자산은 이전 manifest와 대조하여 그대로 보존했다.

## 근거와 내용 판정

[DICOM PS3.3 2026d §10.7](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_10.7.html)의 중심 간 거리 정의와 §10.7.1.3의 행/열 값 순서를 실제로 읽었다. 첫 값은 세로의 인접 행 중심 간격, 둘째 값은 가로의 인접 열 중심 간격이다. 이 예에서는 (Δy, Δx)이다. [ACR 2026-02-06 실제 phantom 안내](https://accreditationsupport.acr.org/support/solutions/articles/11000061035-large-medium-phantom-testing-mri-revised-9-27-23-)의 실제 물체 치수/배치·획득 조건을 확인했다. 안내 PDF 직접/첨부 접근은 내부 오류/서명 URL 접근 실패였으므로 PDF 본문을 읽었다고 기록하지 않는다. 실제 검사 수치·한계값을 가져오지 않았다.

설명·수식·단위·축 부호·원점·도식·표·퀴즈를 대조했다. 영상 u는 오른쪽, v는 아래로 증가하며 물리 y의 위쪽과 부호가 다르다. FOV 경계는 x=−64/y=+64mm이고 u=(x′+64)/Δx−1/2, v=(64−y′)/Δy−1/2이다. 따라서 (0,0)은 첫 pixel의 중심이고 FOV 경계가 아니다. 정확한 분수 위치를 쓰며 정수 반올림/점 검출/PSF·실제 DICOM 방향 행렬을 계산하지 않는다.

거리 L=√[(Δu·Δx)²+(Δv·Δy)²]에서 부호는 길이 제곱 안에서 처리한다. 한 축의 간격을 두 축에 모두 쓰지 않는다. 길이 차이의 규약은 환산−기준이며 양수는 이 모형에서 늘어난 길이를 뜻한다. 실제 QA 지침의 부호/한계값을 그대로 옮긴 것이 아니다. 알려진 올바른 pixel spacing은 변형된 물리 위치를 환산할 뿐 변형 자체를 제거하지 않는다. 중심 고정 한 점이 전체 거리 정확도를 보장하지 않는 것을 두 번째 반례로 확인했다.

## 수치와 실제 화면

[독립 절차](X17-numerical.cjs)·[결과](X17-numerical.json)는 24조건·600점에서 통과했다. 물리 좌표 최대 차이 3.56e−15mm, pixel index/길이 1.43e−14, 상대 차이 1.83e−14%이다. 변형 0/행 간격 2mm의 세로 선분은 Δu=0/Δv=−40이지만 길이 80mm/오차 0이다. k=.04에서 중심 가로는 83.2mm/차이 3.2mm/4%, 가장자리 가로는 86.4mm/차이 6.4mm/8%, 최대 점 이동은 4.525483400mm이다. 중심점 이동은 항상 0이다.

[실제 Chrome 절차](X17-browser-check.js)·[48개 상태](X17-browser-check.json)는 1920/390px에서 모든 조건의 7개 수치와 간격 순서/행 수, 25×8 표, 기준/변형 표식 50개와 이동선 25개·선택 선분 2개, 중심 간격 도식의 6개 cell/중심을 독립 자료와 대조했다. 최대 SVG 차이는 2.85e−14 viewBox 좌표 단위였다. 고정 물리축/실제 비율·중첩 SVG 없음·실제 글자 11px 이상, 세 예시/초기화·Home/End/Arrow/Enter, 두 문제의 양답, 표의 두 선택점/시작점 찾기·고정 제목 가림 없음·가로/세로 스크롤을 확인했다. JS 오류와 페이지 가로 넘침은 0이다.
