# X06 기본 · 신호비와 ΔR2* 변환 (W72)

2026-10-18. **단일 지수/양의 기준 신호 변환 모형의 대상 버전 통과.** 실제 DSC pulse sequence·농도/혈류/AIF·T1/leakage/noise/환자 진단의 검증은 아니다. 외부 전문가 검토 미시행. 전체 회귀/탐색은 별도 연결한다.

## 사전 범위와 독립 기준

NativeR2*=30s⁻¹, ΔR2*(t)=40sin²(πt/20)s⁻¹을0<t<20초에 직접 정의하고 밖은0이다. TE10/30/60ms와 기준신호입력배율k.8/1/1.2의9조합, t0/5/10/15/20/30초의54선택조건이다.121시간점을 표시한다. 초기횡진폭1·같은PD/스케일·T1가중변화/누출/잡음없음·단일지수 진폭을 가정한다. t초와TEms는 다른시간이며 지수/변환분모에는TE초를 넣는다.

Product는 M03과 같은 T2Fit의 generic지수함수를 공유하고 유효T2*ms=1000/(30+ΔR2*)로 호출한다. W70의 순간함수에서(.05/.25의고정스케일을제거한) 무차원 모양만 재사용하며 그 신호/시간창 평균을 물리적으로 복사하지 않는다. S0=exp(−30TE초), S0입력=kS0, q=S/S0입력, 추정ΔR2*=−ln(q)/TE초다. 모든신호/비는양수이며음의변화량추정을clip하지않는다.

독립기준은 cos형 시간모양과 초단위 횡감쇠ODE/RK4 512단계다. Product의지수함수/공통모델을 import하지 않는다.1,024단계로 수렴을 대조하고해석적편향 ln(k)/TE초도 별도로 확인한다. 신호/비1e−8, rate1e−6s⁻¹를 사전기준으로 둔다. 양의 입력 범위를 벗어난 log처리/잡음바닥 모형은 구현하지 않는다.

## 근거와 내용 검토

[AJNR2007 원전](https://pubmed.ncbi.nlm.nih.gov/17569962/)의 PubMed 검색 결과가 반환한 신호곡선/ΔR2* 변환 Figure 설명에서−ln(St/S0)/TE를 읽었다. 직접 페이지 열기는 HHS한줄이어서 전체본문을 직접 열었다고 하지 않는다. 원전의 환자/질환 구분 성능은 이번 모형의 근거로 쓰지 않는다. [Rosen 등1990 저자 초록](https://pubmed.ncbi.nlm.nih.gov/2345506/)은 신호/농도 관계와 tracer kinetic 모델을 통한 혈류/혈액량 계산을 구별하는 범위로 읽었다. ΔR2*를 계산한 것이 농도·CBF/CBV/MTT를 이미 구한 것이라는 설명을 채택하지 않는다.

Native30/peak40s⁻¹·sin²모양·입력배율은직접정의한교육값이다. 변화율/절대R2*·단일지수/분포, 초/ms·경과시간/TE, 양의신호/log·부호/편향, 올바른기준/입력오류를검토했다. “T1을0으로둔다”가아니라T1가중변화를포함하지않는다고명시했다. 실제음의추정원인을이번기준오류하나로단정하지않는다. 도식/표/지표/정답도같은한계를유지하며추가계산오류는발견하지않았다.
