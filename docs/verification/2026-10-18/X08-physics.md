# X08 기본 · 순간 표지의 도달과 T1 감쇠 (W75)

2026-10-18. **순간표지/동일T1/도착뒤보관 packet 모형의 대상 버전 통과.** 가상20cm 경로의 한 packet을 순간 표지하고 도착 뒤 보관하는 관찰 규칙이다. 실제ASL획득/조직교환/혈류정량은 구현하지 않는다. 외부 전문가 검토 미시행.

속도10/20/40cm/s, 같은packet의T1=1000/1600/2200ms, 순간표지 직후 관찰지연t=.5/1/2/3초의36조건이다. 경로20cm이므로 도달시간은2/1/.5초다. 초기control Mz=+1/label Mz=−1을 직접 정하고 RF과정은 계산하지 않는다. 동일 T1의 공통relax로 각Mz를 구한 뒤(control−label)/2로 초기차이1에 정규화한다. 도착 전 관찰값0/도착 순간부터 남은 차이를 보관한다. 이동 전후 T1은같고 교환/유출·readout/잡음·label효율은없다.

0…3초/61점 곡선과36선택조건을 독립 운동학/회복ODE RK4512/1024 및 차이 감쇠 해로 확인한다. 사전허용오차:자화/정규화차이1e−8,도달/위치1e−10,수렴1e−8이다. 실제 두 화면에서 원표/이동표시/도착gate의 수직 경계/기본값·예시·키보드/정답을 확인한다.

[Alsop등2015 원저자 합의문](https://onlinelibrary.wiley.com/doi/10.1002/mrm.25197)의 Introduction과 Time Delay Between Labeling and Imaging을 확인했다. 지연이 짧을 때의 미도달과 긴 지연의 T1감쇠를 구별하는 맥락만 사용한다. 실제PCASL의PLD는 유한 표지 pulse train의 끝부터이고 순간표지 직후 시간과 그대로 같지 않다. 본 수치/순간packet/보관규칙은 직접 정의한 교육 모형이며 실제 프로토콜/임상 기준이 아니다. PMC주소는CAPTCHA로돌아와출판사본문으로확인했다.

## 독립 확인과 내용 판정

[독립 절차](X08-numerical.cjs)와 [결과](X08-numerical.json)는9조합/36조건·2,196시간점에서통과했다. 최대자화/차이2.23e−16,위치3.56e−15cm,도달0초,별도회복ODE1.84e−13/수렴2.77e−12이다. 초기Mz의부호/control−label/2정규화·초→ms변환·도달시각/포함경계·T1시계시작을대조했다. 도착gate만불연속이고packet자화/남은차이는연속이다.

기본v20/T1 1600ms/t2초에서도달1초/위치20cm,control1/label0.426990406/남은차이와관찰차이0.286504797이다. t.5초에는위치10cm/남은차이0.731615629지만관찰0이다. T1 1000ms/t2초는0.135335283이고 t3초/T1 1600ms는0.153354967이다. 도착경계t1초는0.535261429부터관찰하며,도착때회복시계를다시시작하면이동중회복을누락한다. 이미모두도착한t3초에서는세속도의남은/관찰차이가같다. 이속도는혈류량이아니며초기한packet의관찰값으로CBF를추정하지않는다.
