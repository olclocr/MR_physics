X18 후속 · 1초 포화 뒤 같은 두 풀의 회복

다른 풀의 포화를 멈추면 물 풀도 곧바로 회복할까요?

포화를 끄는 순간 바뀌는 항과, 두 풀 사이에 남아 있는 불균형을 구별하세요. 작은 풀은 회복하기 시작해도 물 풀의 종자화는 잠시 더 감소할 수 있습니다.

목표: 포화 종료와 상태 연속, 물과 작은 풀의 서로 다른 미분, 고유 회복률과 교환 결합 모드를 구별합니다.

선행 · 같은 두 풀에서 포화 구간만 바꿉니다

지속 포화 전달과 같은 초기평형 w=1/s=.1, R1w=R1s=1 s⁻¹를 사용합니다. w/s는 같은 M0w 단위, s/.1은 작은 풀 자신의 평형으로 나눈 무차원 값입니다. s→w는 k s⁻¹, w→s는.1k s⁻¹로 짝지어 평형에서 양방향 교환량을 맞춥니다.

s의 직접 지정 포화율 W=5 s⁻¹를0≤t<1초에 적용하고 t≥1초에는0으로 둡니다. 물의 직접 포화는 없습니다. t=1의 자화는 앞 구간의 끝 상태를 그대로 넘기며, 원표와 지표의 W/미분은 종료 직후 값을 씁니다. 스핀 수/풀 크기가 변하는 모형이 아닙니다.

실제 RF에서 W를 계산하지 않는 종방향 부분 모형입니다. 평형 크기/교환율/시간은 교육용 예시이며 실제 MT/CEST 획득이나 환자 신호를 생성한 결과가 아닙니다.

  2. 물의 최솟값 뒤1.2초와 비교하세요.
  3. 교환이0이어도 같은 물 감소가 생길까요?

교환과 관찰 시각

기본: k2 s⁻¹ / 1.2초. W5는[0,1)초에만 적용하고 이후에는0입니다. 물의 직접 포화는 없습니다. 풀 크기와 고유 R1은 그대로이며 w→s는.1k로 함께 바뀝니다. 원표의1초는 종료 직후 미분을 표시합니다.

포화 종료 뒤에도 두 풀은 교환합니다

막대는 물 w/M0w=w와 작은 풀 s/M0s=s/.1이며 각자의 평형1에 대한 높이입니다. 위 초록 화살표는 s→w의 ks, 아래 주황 화살표는 w→s의.1kw입니다. 숫자는 공통 M0w 단위/초이고 화살표 길이는 양을 나타내지 않습니다.

파랑 w · 주황 s/.1 · 회색 가로 점선은 평형 대비1입니다. 옅은 주황 영역은 포화 적용0–1초, 초록 세로선은 종료1초, 회색 세로선과 두 점은 관찰 시각입니다. 검은 테두리 원은 전체 곡선에서 물의 최솟값입니다. k0에서는 물이 항상1이라 고유한 최소 시각/표식이 없습니다. 시간0–4초/값0–1.1의 고정 축입니다.

포화를 끄는 순간 w와 s는 점프하지 않습니다. s의 식에서−Ws가 사라지므로 s′는 종료 직전에 비해5s만큼 커집니다. 반면 w의 식에는 W가 직접 들어 있지 않아 같은 순간의 w′는 연속입니다.

k2에서는1초의 w′가 음수여서 물이 잠시 더 감소합니다. s가 회복되면서 두 방향 교환의 불균형이 줄고, 물의 회복 항이 순교환 손실을 따라잡은 뒤 w′가0을 지나 양수가 됩니다. 이 예시의 물 최소 시각은 약1.147541초입니다. k.5에서는 약1.299913초로 더 늦습니다. 이는 직접 정한 조건의 결과이며 일반 임상 시각이 아닙니다.

물의 최소 시각은 현재 관찰 시각과 별도로 전체0–4초 곡선에서 구합니다. k0이면 물은 처음부터 항상1이고 고유한 최소 시각이 없습니다. 포화를 껐다는 사실만으로 즉시 평형으로 돌아가거나 모든 성분이 같은 곡선으로 회복하는 것은 아닙니다.

수식 · 종료 뒤 두 회복 모드

W0에서 w′=(1−w)−.1kw+ks, s′=(.1−s)+.1kw−ks입니다. 두 풀의 합은 (w+s)′=1.1−(w+s)이므로 전체 합의 평형 차이는1 s⁻¹로 감소합니다. 개별 물 자화의 평형 차이는 일반적으로 exp[−(t−1)]과 exp[−(1+1.1k)(t−1)] 두 항의 합입니다. k의 단위는 s⁻¹이며 두 지수의 률도 s⁻¹입니다.

고유 R1이 둘 다1 s⁻¹여도 교환 모드가 추가되므로 물의 곡선 전체를 무조건 단일 exp(−t)로 읽을 수 없습니다. W0 뒤 총 자화는 평형1.1로 접근하지만 유한 시각에 정확히 도달한다고 가정하지 않습니다. 실제 RF/횡자화/다른 풀을 포함한 완전한 MT/CEST 모형은 아닙니다.
