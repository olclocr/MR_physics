X01 기본 · 등속 단일 spin · 두 사각 gradient lobe

정지한 spin을 다시 모은 gradient가 움직인 spin도 같은 위상으로 돌려놓을까요?

같은 크기·반대 극성의 두 lobe는 정지한 spin의 위상을 상쇄합니다. 두 번째 lobe를 겪을 때 spin의 위치가 바뀌었다면 어떨까요?

목표: 위치 궤적의 적분과 gradient의 0차·1차 moment를 연결하고, 위상이 남는 것과 신호 크기가 줄어드는 것을 구별합니다.

선행 · 초기 상태와 단위

B04의 위치별 주파수와 D01의 시간 적분을 연결합니다. 모든 spin은 t=0에 x0=1mm, M+=Mx+iMy=1+0i에서 시작합니다. 같은 출발 위치의 정지 참조와 알려진 등속 spin을 비교합니다. v의 표시 단위는 cm/s이며 계산에는 m/s로 변환합니다.

G 크기2mT/m, 각 lobe 길이τ1/2/3ms, 첫 lobe의 부호를 선택합니다. 두 lobe를 바로 이어0…2τ 동안 적용합니다. 180°RF는 없고 이완도 없습니다(T1/T2∞). 확산·추가 B0 offset·잡음·수신 위상은0입니다. γ̄=42.57747892MHz/T, γ=2πγ̄(rad/s/T)입니다. 그림은 교육용 궤적이며 실제 혈관 영상이 아닙니다.

두 가지 moment는 다른 질문에 답합니다

정지한 spin은 두 lobe에서 같은 위치를 유지하므로 같은 크기의 위상을 얻고 잃습니다. 등속 spin은 뒤의 lobe를 더 나중의 위치에서 겪습니다. 두 면적의 합이0이어도 시간으로 가중한 적분은0이 아닙니다.

수식 · 부호 · SI 변환

x(t)=x0+vt
A0(t)=∫₀ᵗG(u)du (T·s/m)
A1(t)=∫₀ᵗuG(u)du (T·s²/m)
φ(t)=−γ∫₀ᵗG(u)x(u)du = −γ[x0 A0(t)+v A1(t)]
M+(t)=exp[iφ(t)]
+G→−G의 끝: A0(2τ)=0, A1(2τ)=−Gτ²
φ(2τ)=+γvGτ²

시간 기준은 최초 t=0입니다. 표시 A0는 SI값×10⁶, A1은 SI값×10⁹으로 바꿉니다. mT·ms²/m와 T·s²/m를 혼용하지 않습니다. 공통 γ는 양수이고 양의 Gx는 M+를 음의 위상으로 회전시킵니다. 초기 M+=1의 위상을0으로 잡았습니다. 다른 RF/수신 위상을 사용한 자료와 비교할 때는 그 기준을 맞춰야 합니다.

여기 A0/A1은 gradient moment이며 평형 자화 M0와 다른 기호입니다. 0차 moment가0이어도 1차 moment는 남습니다. 등속 보상에는 1차 moment도 맞춰야 하지만 추가 lobe의 실제 flow compensation 설계는 이번 페이지에서 계산하지 않습니다. 표의 G는 lobe 경계에서 오른쪽 값을 사용하고 종료 시각에는0입니다. 순간 경계의 값 선택은 적분을 바꾸지 않습니다.

위상 변화와 신호 소실을 구별하세요

“움직이면 언제나 신호가 줄어든다.” → 여기서는 한 spin이 회전할 뿐 |M+|=1입니다. 여러 속도/위치의 복소합, 이완, RF 영역의 출입 등을 추가해야 신호 크기 변화를 논할 수 있습니다. 이 그림만으로 혈관 밝기나 flow void를 예측하지 않습니다.
