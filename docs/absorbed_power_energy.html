X16 후속 · 이미 주어진 흡수 파워의 에너지 모형

평균 흡수 파워가 같으면 누적 에너지도 같을까요?

순간 파워, 기간 평균, 누적 에너지와 온도 변화는 다른 양입니다. 같은 평균률의 서로 다른 기간과 같은 에너지의 서로 다른 평균률을 비교합니다.

목표: duty와 평균 파워의 관계·시간 적분의 에너지·질량당 평균률과 열손실 없는 온도 변화를 구별합니다.

선행 · 이미 흡수된 파워와 단위

여기 입력은 물체가 이미 흡수하는 파워 Pabs(t)입니다. 실제 RF 장/B1이나 송신 파워에서 흡수량을 계산하지 않습니다. 정자기장 힘/torque나 RF에 의한 자화 회전과도 다른 계산입니다.

주기 1초의 각 시작에서 duty×1초 동안 Pon=1/2W를 흡수하고 나머지는 0W입니다. duty는 .25/.5/1이며 전체 기간 T는 10/20초의 정수 주기입니다. 평균은 선택 기간 전체에서 구합니다. 시작 포함·on끝 제외이고 T에서 모두 종료합니다. 1W=1J/s이므로 파워를 시간에 대해 적분하면 에너지 J입니다.

질량 m=1kg·일정 비열 c=4000J/(kg·K)는 직접 정한 교육용 값입니다. 흡수 에너지가 모두 균일 내부 열에너지로 남고 다른 일·열손실·상변화는 없다고 가정합니다. 환자 체온이나 특정 재질의 값을 나타내지 않습니다.

예측하고 비교할 세 가지

  1. 기본 평균 1W를 유지하고 기간을 10초로 줄이면?
  2. 기본 2W/duty .5를 연속 1W로 바꾸면?
  3. 첫 예제와 같은 에너지 10J를 더 긴 기간에 흡수하면?

주어진 파워와 기간

기본: Pon 2W / duty .5 / T 20초. 주기 1초·m 1kg·c 4000J/(kg·K)는 고정입니다. 파워가 0인 부분에서도 누적 에너지와 모형 온도 변화는 그대로 남습니다.

파워의 높이·on 시간과 누적 면적

파랑 step: 첫 2초의 주어진 Pabs · 회색 점선: 선택 기간 평균 Pavg. 주기 1초, 파워 0–2.2W의 고정 축입니다. duty 1은 연속 흡수이며 이 확대도에는 전체 종료 시각 10/20초를 표시하지 않습니다.

파랑 실선: 실제 사각열의 누적 에너지 E · 회색 점선: Pavg를 연속 적용한 누적 에너지. 세로선/원은 T의 종료점입니다. 정수 주기 끝의 에너지는 같아도 주기 안의 경로는 다릅니다. 시간 0–20초·에너지 0–42J의 고정 축입니다.

평균률은 전체 에너지가 아닙니다

같은 Pavg에서 T가 두 배이면 E도 두 배입니다. 같은 E라도 더 긴 T에 걸쳐 흡수하면 평균률은 작습니다. duty를 줄이는 효과는 on 파워가 고정되어 있을 때와, 평균 파워를 같게 맞출 때를 구별해야 합니다. 여기에서는 직접 정한 on 파워와 duty를 따로 조작합니다.

이 모형의 ΔT는 E/(mc)이며 1K=1000mK입니다. 열손실·전도·관류·체온조절과 국소 분포가 없으므로 실제 환자 온도/화상을 예측하지 않습니다. Pavg/m의 단위는 W/kg이지만 실제 장비의 SAR 추정이나 안전 한계를 계산한 값은 아닙니다. 평균 기간은 여기 선택한 10/20초 전체입니다.

수식 · 평균, 에너지와 열용량

Pavg=(1/T)∫₀ᵀPabs(t)dt=Pon·duty (여기의 정수 주기 T). E=Pavg·T, 선택 기간 평균률=E/(mT)=Pavg/m입니다. J/(kg·s)=W/kg이며 W/kg에 질량과 시간을 곱해야 전체 J가 됩니다. 임의의 짧은 부분 주기에 Pon·duty를 그대로 적용하지 않습니다.

흡수 에너지가 열에너지로 모두 남는 일정 c 모형에서 E=mcΔT입니다. J/[kg·J/(kg·K)]=K입니다. 온도 변화는 mK로 표시하고 절대 체온은 정의하지 않습니다. 파워가 꺼지면 입력 에너지가 더 늘지 않지만 이 모형에는 냉각이 없어서 ΔT가 바로 0으로 돌아가지 않습니다.
