X11 후속 · 정확한 위상과 알려진 감도

위상 보정만 하면 강도도 균일해질까요?

신호의 방향을 맞추어도 크기에 곱해진 감도는 남습니다. 참조의 크기로 나누면 공통 감도를 제거할 수 있지만, 참조 자체의 대비도 결과에 섞입니다.

목표: 위상 보정과 강도 정규화, 공통 감도와 참조 대비, 표시값과 실제 자화 회복을 구별합니다.

선행 · 자화와 두 복소 신호의 정의

IR 신호와 위상 참조에서 단위 참조의 역할을 먼저 확인하세요. 이번에도 M0=1에서 완전 회복 뒤 이상적 반전과 자유 T1 회복을 가정합니다. T1=1000 ms, Mz=1−2exp(−TI/T1)이며 단위는 M0에 대한 무차원 값입니다. 유한 TR 반복 IR이나 실제 readout을 계산한 결과가 아닙니다.

공통 감도 A>0와 정확한 배경 위상 φ=30도를 두고 S=A Mz exp(iφ), 참조 Q=A r exp(iφ)로 직접 정의합니다. A=.5/1/2, 참조 계수 r=.8/1은 무차원 교육용 예시입니다. r은 독립적으로 지정한 참조 크기 계수이며, 참조 획득 시각이나 pulse에서 계산한 회복량이 아닙니다. 공간 감도 지도를 그리거나 추정하지 않습니다.

위상만 제거한 C=SQ*/|Q|와, 이를 다시 참조 크기로 나눈 N=C/|Q|를 비교합니다. Q와 S에는 같은 A와 φ가 적용되고 r은 양수입니다. 정확한 위상과 양의 참조 크기를 알고 있다는 조건을 고정합니다.

  3. 회복 후 양의 자화에서도 같은 원리가 성립할까요?

관찰 시각과 알려진 계수

기본: TI 400 ms / A2 / r1. T1 1000 ms, M0=1, φ=30도입니다. A와 r은 실제 자화 회복을 바꾸지 않습니다. 모든 신호와 표시값은 이 정규화/계수 정의에 대한 무차원 값입니다. 임상 신호의 절대 단위가 아닙니다.

방향을 맞추는 것과 크기를 나누는 것

파랑 S · 초록 Q · 회색 점선은 φ=30도의 기준 직선입니다. 실수/허수 축은 같은 축척의 ±2.2로 고정합니다. 음의 Mz에서는 S가 Q의 반대 방향입니다. 두 선은 크기를 포함한 원래 복소 좌표이며 아래의 위상 제거 실수값과 구별하세요.

참조 크기에 무엇이 들어 있나요?

위상 보정은 Q의 방향만 사용합니다. 이 모형에서 C=A Mz이므로 부호는 정확해도 A가 남습니다. 같은 Mz를 A2와 A.5에서 비교하면 위상 보정 실수부의 크기는4배 차이입니다. 강도 차이를 모두 자화 차이로 읽으면 안 됩니다.

참조 크기 |Q|=A r로 나누면 공통 A는 소거되고 N=Mz/r이 됩니다. r1일 때만 이 정의에서 Mz와 일치합니다. r.8이면 위상은 정확해도 정규화 값의 절댓값이 실제 Mz의1.25배입니다. 음의 Mz는 더 음수가 됩니다. 비율 설명은 Mz가0이 아닐 때 적용하며, 실제 자화 null은 여전히 T1 ln2≈693.147 ms입니다.

여기서는 같은 자화에서 A만 바꾸어 공통 감도 제거를 비교합니다. 실제 조직/참조 대비가 공간마다 다를 때 같은 정규화가 정확한 감도 보정이 되는지는 별도로 확인해야 합니다. 표시를 나누는 연산이 T1이나 자화 회복 자체를 바꾸지는 않습니다.

수식 · 단위 참조와 참조 magnitude의 서로 다른 역할

Q*/|Q|=exp(−iφ)이므로 C=SQ*/|Q|=A Mz입니다. N=C/|Q|=Mz/r입니다. 정확한 위상, A>0, r>0이므로 두 실수부는 Mz와 같은 부호이며 허수부는0입니다. 이번 허용 범위에서 |Q|의 최솟값은.4이고 분모0은 없습니다. 실제 참조 잡음이나0 근처 분모의 안정성을 다룬 결과로 확대하지 않습니다.

r=.8은 참조 크기가 이상적 계수1보다20% 작은 직접 예시입니다. 역수 연산이므로 정규화 크기의 변화는20%가 아니라25%입니다. A의 소거와 r의 잔류를 따로 확인하세요.

가정과 근거
