겹친 두 slice를 어떻게 다시 나눌까요?

여러 slice를 동시에 여기하면 수신 coil에는 그 신호가 함께 들어옵니다. 서로 다른 coil 감도와 알려진 위상 부호를 사용하면 이 합을 나눌 수 있습니다. 합을 잘 맞췄다는 사실만으로 올바른 slice를 얻었다고 판단할 수는 없습니다.

목표: 동시 획득과 면내 undersampling을 구별하고, CAIPI의 겹침 위치 이동을 관찰하며, 감도 오차가 만드는 slice leakage를 확인합니다.

선행 개념 · 좌표와 신호 단위

G02의 slice 선택과 Q04의 두 coil 연립방정식을 사용합니다. 두 줄은 서로 다른 z의 slice이며, 각 줄 안의 y 방향만 32 pixel로 표현합니다. FOV 160 mm, pixel 중심 y=0, 5, …, 155 mm의 주기 격자입니다. 끝과 끝이 연결되는 교육용 경계 조건입니다. 실제 해부학 영상이 아닙니다.

진폭은 공통 기준 1에 대한 비율이며 초기 위상 0, 잡음 0입니다. coil 감도는 실수이고 위치마다 두 coil의 감도 제곱합이 1입니다. θ는 실제 coil의 회전각이 아닌 감도 유사도를 바꾸는 교육 변수입니다. θ=0° 근처에서는 일부 감도가 음수일 수도 있습니다.

CAIPI는 겹치는 상대 위치를 바꿉니다

두 번째 slice의 q번째 복소 Fourier 자료에 exp(−i2πqd/32)를 곱하면, coil 영상에서 두 번째 slice가 +d pixel 순환 이동합니다. FOV/2에서는 홀수 q의 부호가 반전됩니다. 분리 후에는 이 이동을 되돌려 원래 slice 좌표를 표시합니다. 이동은 실제 해부학적 위치 변화가 아닙니다.

공간 감도 모형은 겹칠 두 위치의 감도 차이가 달라지도록 설계했습니다. 기본 θ20°에서 FOV/2 이동은 가장 나쁜 g를 줄입니다. 그러나 균일 감도에서는 위치를 바꿔도 감도 차이가 같으므로 g가 변하지 않습니다. 실제 CAIPI 이득도 coil 배열과 겹침 위치에 의존합니다.

연립방정식 · 정규화 · 오보정의 의미

b_c[j] = c_c,1[j] x₁[j] + c_c,2[j−d] x₂[j−d]
y_c[q] = Σⱼ c_c,1[j] x₁[j] exp(−i2πqj/32) + exp(−i2πqd/32) Σⱼ c_c,2[j] x₂[j] exp(−i2πqj/32)

forward DFT는 무정규화, inverse는 1/32입니다. q=−16,…,15, k=q/160 mm⁻¹입니다. x₁은 j4–9에서1, 나머지0.1입니다. x₂는 j19–25에서0.7, j12–13에서0.3, 나머지0.1입니다. 각 slice가 별도 종자화/신호로 주어지며 이완·RF profile은 계산하지 않습니다.

a(j) = θ + v cos(2πj/32), v = 10° 또는 0°
c₁(j) = [cos a(j), sin a(j)]ᵀ
c₂(j) = [sin a(j), cos a(j)]ᵀ
C(j) = [c₁(j), c₂(j−d)], g(j) = 1/|det C(j)|

각 열의 길이가 1이고 coil 잡음이 독립·동일 분산일 때 두 분리 성분의 g가 같습니다. θ+5° 오보정은 C 대신 Ĉ를 역산합니다. T=Ĉ⁻¹C의 비대각 원소는 다른 slice가 추정값에 섞이는 계수입니다. 화면은 이 계수의 위치별 RMS를 표시하며 실제 임상 leakage 측정 지표를 재현한 것은 아닙니다.

측정 잔차는 ||F[Ĉx̂]−y||₂ / ||y||₂, 복원 오차는 ||x̂−x||₂ / ||x||₂입니다. 정방 가역 Ĉ는 틀려도 그에 대한 측정을 정확히 맞출 수 있습니다. 실제 감도가 특이한 위치에서는 원래 두 신호를 하나로 정할 수 없습니다. 가정한 행렬의 |det|<10⁻¹⁰이면 해당 위치는 분리하지 않습니다.

횟수가 줄어드는 것과 실제 검사 시간은 구별하세요

이는 각 묶음이 다른 묶음과 겹치지 않는 임의의 2 s 블록인 산수 예시입니다. 같은 slice의 TR, excitation 간격, 실제 interleave를 계산한 타임라인이 아닙니다. 실제 시간과 신호는 TR·회복·RF 제약 등에 따라 달라집니다. Q03의 이벤트 모형에서 별도 가정을 확인하세요.

SMS는 여러 slice를 한 묶음에 넣는 가속입니다. 면내 parallel imaging의 줄 생략과 달라서 Q04의 1/√R을 MB 값에 그대로 대입하지 않습니다. 여기서는 임상 SNR이나 SAR을 계산하지 않습니다.
