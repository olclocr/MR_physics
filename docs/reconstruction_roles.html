AI01 기본 · 실제 학습 모델이 없는 역할/평가 모형

매끈해진 결과와 덜 찍은 자료의 복원은 같은 문제일까요?

잡음 감소, 누락된 표본의 추정, 선명도 조작은 서로 다른 역할입니다. 알려진 원본에 명시한 수학적 처리를 적용해, 모양·측정 자료·정답 오차를 따로 비교하겠습니다.

목표: 처리 목적과 획득 표본을 구별하고, data consistency가 무엇을 확인하는지 설명합니다.

선행 · 구현한 처리 · 구현하지 않은 학습 모델

Q01의 복소 잡음과 Q06의 Fourier/Haar를 재사용합니다. N64/FOV64mm의1D합성 신호입니다. 원본은 두 단계 영역과 j32의 작은 성분0.15를 포함합니다. 실제 임상 영상/질병 예시가 아닙니다.

비교 처리는 identity,3tap 평활,3tap 선명도,한 번의 Haar shrink(λ0.08)입니다. 이 페이지에는 학습 데이터/신경망/벤더 알고리즘이 없습니다. 정해진 처리를 AI 결과라고 부르지 않고, AI 재구성의 역할과 평가 방법을 이해하는 기초 모형으로 사용합니다.

Unitary Fourier k-space의 Re/Im에 각각 표준편차σ의 고정seed Gaussian 잡음을 더한 뒤 마스크를 적용합니다. Singlecoil·균일gain·동일 위상의 원본이며 실제 다중coil/수신 잡음 공분산은 제외합니다. 한 seed의 예시로 평균 임상 성능을 추정하지 않습니다.

세 가지 관찰

  1. 전체 표본의 잡음에 평활을 적용하면 정답 오차와 경계는 어떻게 달라지나요?
  2. 잡음이 없어도 짝수 표본만 얻은 입력은 정답과 다를 수 있나요?
  3. 획득 자료를 정확히 다시 넣으면 정답도 완전히 회복되나요?

같은 원본 · 다른 자료와 처리

기본: 전체64개,σ0.05,평활,자료 치환 끄기. 동일seed를 사용해 조작 전후 잡음 입력을 맞춥니다. 획득 시간/SNR 개선 배수를 계산하지 않습니다.

원본 · Zero-filled 입력 · 최종 출력

1D 실수값을 폭64cell의 띠로 표시한 교육 그림입니다. 고정 회색창0…1.4 상대단위이며 음수/창 밖 값은 이 띠에서만clip합니다. 각 행을 최대값으로 나누지 않습니다. Clip 개수는 경계의1e−10 이내 부동소수 차이를 제외합니다. 복소 계산과 원값은 아래 곡선/표에 유지합니다.

검정=정답Re,주황=입력Re,파랑=출력Re,보라 점선=출력Im. 상대신호−1…2 고정,x는0…63mm 표본 중심입니다. 표본 연결이며 실제 획득 해상도나 연속 조직을 뜻하지 않습니다.

출력 복소 NRMSE

획득자료에 대한 상대 잔차

누락k의 정답에 대한 상대 오차

획득한 것과 출력이 예측한 것

주황=획득|y|,파랑=출력의|F x|. 녹색점=획득한q. 누락위치의주황0은획득한0이아니라표시용채움입니다. q−32…31,크기0…3.5고정.

q획득|y||F x|복소차 크기

자료 일치와 정답 일치는 다릅니다

획득k를 원자료로 치환하면 그 위치의 잔차는0이 됩니다. 그러나 원자료의 잡음도 다시 넣으며 누락k의 정답을 확인한 것은 아닙니다. 전체 표본에서는 자료를 그대로 되돌리는 것이 잡음 제거와 충돌할 수 있습니다. 불완전 자료에서는 잔차0이어도 aliasing이나 추정 오차가 남습니다.

연산 · 단위 · 사전 가정과 실제 학습

y=M(Fx_true+σ ε), z=F⁻¹y
평활: [1/4,1/2,1/4] 순환convolution
선명도: [−1/4,3/2,−1/4] 순환convolution
Haar 1회: W⁻¹ soft(Wz,0.08)
자료치환: k_out=M y+(1−M)F(processed)

F는unitary변환입니다. 원본의위상은0이지만잡음/출력은복소수그대로유지합니다. 신호와σ는공통상대단위이며별도수신단위보정은없습니다. 복소NRMSE는원본L2 norm,자료잔차는획득y의L2 norm,누락오차는누락된정답k의L2 norm으로나눕니다. 전체표본의누락오차는해당없음으로표시합니다.

평활/선명도는선형위치불변필터이므로없는Fourier모드를스스로만들지않습니다. 이두처리뒤모든획득값을치환하면입력zero filling으로돌아옵니다. Haar shrink는Q06의알려진희소성가정한번이며최적화수렴치나학습된prior가아닙니다. 실제학습재구성은데이터에서prior/가중등을학습할수있고이페이지의정해진필터와다릅니다.
