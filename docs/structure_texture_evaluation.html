전체 오차가 줄면 작은 구조와 질감도 보존될까요?

같은 원본을 평활하거나 선명하게 만들면서 전체 오차, 작은 점의 대비, 알려진 질감 성분을 따로 비교합니다. 이 페이지의 처리는 학습된 AI가 없는 수학적 대리처리입니다.

목표: 보기 좋은 정도와 정보 보존을 구별하고, 무엇을 측정했는지 설명합니다.

선행 개념 · 합성 원본과 잡음

AI01의 네 가지 처리를 그대로 사용합니다. N=64, FOV=64 mm인 1D 합성 원본은 단계 신호에 j=32의 작은 점 0.15와 질감 0.06 cos(2π·12j/64)를 더한 것입니다. 임상 영상이나 병변 모형이 아닙니다.

여기서는 전표본 복소 영상 영역의 Re/Im에 각각 표준편차 σ의 Gaussian 잡음을 더합니다. AI01의 k-space 잡음과 입력 영역을 구별하세요. Seed A/B의 두 고정 예시이며 모집단 평균이나 임상 성능 추정은 아닙니다.

세 가지 관찰

  1. 평활 뒤 전체 오차가 줄어도 작은 점의 대비가 줄어드나요?
  2. 100%를 넘는 구조 반응이 곧 정확한 복원인가요?
  3. 비선형 Haar 처리의 구조 반응은 잡음 예시에 따라 같나요?

같은 구조 · 다른 처리

기본: σ=0.15, 평활, Seed A. 모든 신호는 공통 상대단위입니다. 행별 최대값 정규화나 자동 표시 창을 사용하지 않습니다.

알려진 쌍의 차이는 단일 영상의 검출력이 아닙니다

점이 있는 원본과 없는 원본에 동일한 잡음을 더하고 각각 처리한 뒤 빼면, 그 점이 처리 결과를 얼마나 바꾸었는지 관찰할 수 있습니다. 실제 환자 영상 한 장에서 이런 정답 쌍을 얻을 수 있다는 뜻은 아닙니다. 이 비율은 병변 검출률, 임상 SNR 또는 AI 성능 지표가 아닙니다.

선형 필터에서는 같은 잡음이 차이에서 상쇄되어 구조 반응이 seed에 무관합니다. 비선형 Haar shrink에서는 배경과 잡음이 계수의 문턱 통과를 바꿀 수 있습니다. 한 seed의 결과를 보편적인 구조 보존율로 해석하지 마세요.

지표의 수식 · 정규화 · 처리의 가정

Δp = T(x + p + t + n) − T(x + t + n)
Δt = T(x + p + t + n) − T(x + p + n)
점 정점비 = Re Δp[32] / 0.15
점 국소 대비비 = {Re Δp[32] − (Re Δp[31] + Re Δp[33])/2} / 0.15
질감 진폭비 = {(2/64) Σ Re Δt[j] cos(2π·12j/64)} / 0.06
NRMSE = ‖출력 − 전체 정답‖₂ / ‖전체 정답‖₂

x는 점과 질감이 없는 단계 신호이고 p, t는 각각 점과 질감입니다. NRMSE는 복소 전체 신호, 세 반응비는 실수 성분을 사용합니다. 비율에 별도 0…100% 제한을 두지 않습니다. 순환 3tap 평활 [1/4, 1/2, 1/4], 선명도 [−1/4, 3/2, −1/4], 명시적 직교 Haar의 복소 soft shrink 0.08을 사용합니다. 끝과 처음이 연결되는 1D 모형입니다.

평활의 점 정점비는 50%, 국소 대비비는 25%입니다. 선명도는 150%, 175%이지만 음수 주변 반응을 만듭니다. 질감 진폭비는 지정한 12 cycles/FOV 성분에 대한 투영이며 모든 공간 주파수의 보존이나 실제 해상도 측정이 아닙니다.
