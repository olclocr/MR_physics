X09 후속 · 알려진 두 입력과 선형 합

입력이 두 번이면 반응도 두 봉우리로 보일까요?

하나의 입력에 대한 반응이 늦게 퍼지면 다음 입력의 반응과 겹칠 수 있습니다. 각 입력의 기여를 따로 보고 합을 비교하여, 원인 입력의 횟수와 관찰 곡선의 모양을 구별합니다.

목표: 입력 간격·둘째 입력 크기·지연 폭의 영향을 비교하고, 선형 합의 적용 범위를 설명합니다.

선행 · 알려진 입력과 인과적 합성곱

입력과 지연 반응의 같은 커널을 사용합니다. 첫 입력은 [2,4)초에 1, 둘째는 [2+Δ,4+Δ)초에 크기 a입니다. Δ는 시작 사이 간격 2/6/10초, a는 0/0.5/1이며 0은 둘째 입력이 꺼진 경우입니다. 두 구간은 겹치지 않으며 Δ=2초이면 이어집니다.

h(t)=t²exp(−t/τ)/(2τ³)는 t≥0, 그 전에는 0입니다. 커널 면적은 전체 시간에서 1, τ는 1/2초, h의 단위는 s⁻¹입니다. 입력 u와 반응 y는 직접 정의한 무차원 양입니다. 첫 반응 y₁과 이동·가중한 둘째 반응 y₂를 더해 y=y₁+y₂로 정의합니다.

입력 시각과 크기는 알고 있습니다. 실제 신경 사건 수나 BOLD 신호의 백분율·표준 HRF를 추정하지 않습니다. 비선형 생리·적응·잡음·실제 fMRI 통계는 계산하지 않습니다. 예시값은 환자 프로토콜이 아닙니다.

예측하고 비교할 세 가지 관찰

  1. 두 입력이 바로 이어지면 두 반응은 어떻게 겹칠까요?
  2. 크기와 τ를 고정하고 입력을 멀리 떼면?
  3. 간격을 고정하고 둘째 입력 크기만 반으로 줄이면?

두 입력과 지연의 조건

기본값: 시작 간격 6초, 둘째 크기 1, τ 1초. 입력 길이는 모두 2초입니다. 지표와 작은 원은 공통 관찰 시각 10초를 가리킵니다. 입력 구간의 시작은 포함하고 종료는 제외합니다.

각 반응과 합을 같은 축에서 읽기

회색 점선: 첫 입력 u₁ · 주황 점선: 둘째 입력 u₂. 채운 점은 그 시각의 값, 빈 점은 직전 값입니다. a=0이면 둘째 입력은 꺼집니다.

회색 점선: 첫 기여 y₁ · 주황 점선: 둘째 기여 y₂ · 파랑 실선: 합 y. 세로 점선과 작은 원은 10초입니다. 두 그림 모두 시간 0–24초·무차원 값 0–1의 고정 축입니다. 표시창 뒤에도 반응의 꼬리가 남습니다.

10초의 둘째 기여 y₂

선형 합이어도 봉우리가 입력을 하나씩 표시하지는 않습니다

각 반응은 입력 이후에 퍼져 남으므로 서로 가까우면 합에서 구별하기 어려울 수 있습니다. 간격을 바꿀 때는 각 점선과 파란 합을 함께 보세요. 이 페이지는 알려진 입력으로 반응을 만드는 순방향 모형이며, 관찰한 봉우리 수로 실제 신경 사건 수를 추정하는 분석기가 아닙니다.

a를 반으로 하면 둘째 기여만 모든 시각에서 반으로 바뀝니다. 첫 기여는 같습니다. a=0은 첫 반응 하나로 돌아오는 경계 조건입니다. τ가 커지면 같은 입력도 더 넓게 퍼집니다. 반응이 남아 있다는 사실만으로 그 시각의 입력이 켜져 있다고 판단할 수 없습니다.

수식 · 이동, 가중합과 전체 면적

y₀(t)는 2초부터 2초간 크기 1인 입력에 대한 기존 반응입니다. 같은 τ에서 y₁(t)=y₀(t), y₂(t)=a·y₀(t−Δ), y(t)=y₁(t)+y₂(t)입니다. 인과적 합성곱 y=∫u(s)h(t−s)ds는 무차원×s⁻¹×초이므로 무차원입니다.

전체 시간에서 ∫y dt=2(1+a)초입니다. 간격은 이 전체 면적을 바꾸지 않습니다. 이것은 0–24초 표시창 안의 면적이나 실제 BOLD 신호의 보존 법칙을 뜻하지 않습니다. 입력 합이 0…1이고 비음수 커널 면적이 1인 이 모형에서는 반응 합도 0…1입니다.

가정과 출처

고정된 비음수 커널을 쓰는 선형·시간 불변·인과 모형입니다. 기존 W79의 계산을 그대로 이동/가중합합니다. 커널·계수·입력은 직접 정한 교육용 값이며 임상 영상은 없습니다. 실제 혈역학/산소화·신경 활동/사건 수 추정·적응/비선형성·잡음/통계·환자 진단은 제외했습니다.

Boynton 등(1996) 원논문 초록의 선형 변환 검사는 특정 V1 자료의 맥락입니다. 그 결과를 모든 실제 BOLD 반응의 선형성으로 확대하지 않습니다. 이 페이지의 gamma 커널은 그 논문의 측정 HRF를 재현하지 않습니다.
