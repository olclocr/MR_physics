X07 후속 · 같은 사각 입력의 두 농도 기여

입력과 함께 즉시 변하는 항도 같은 구획 washout일까요?

조직 농도에 혈관 직접 기여를 더하면 입력 종료에서 바로 변하는 부분과 연속적으로 남는 부분이 함께 보입니다. 전체와 두 성분을 나누어 비교합니다.

목표: 혈관 직접항/EES 기억·전체 농도/EES 기여·입력 경계의 점프/연속을 구별합니다.

선행 · 이전 Ct와 이번 전체 Ct의 차이

알려진 혈장 입력 Cp=1 mM를 [0,5)초에 직접 정의하고 이후 0입니다. ve=.2, 혈장 부피분율 vp=0/.05/.1, Ktrans=0/.01 s⁻¹를 선택합니다. 모든 값은 교육용이며 실제 AIF/주입량/환자 계수가 아닙니다.

이전 단일 EES 모형의 조직 부피 기준 EES 기여를 이번에는 T라고 부릅니다. dT/dt=Ktrans Cp−kepT, T(0)=0, kep=Ktrans/ve입니다. 혈관 기여 V=vpCp를 더해 전체 Ct=V+T로 정의합니다. 이전의 혈관항 없는 Ct와 이번 전체 Ct는 같은 양으로 자동 대입하지 않습니다.

Cp는 혈장 부피 기준, T/V/전체 Ct는 조직 부피 기준 농도이며 단위는 mM=mmol/L입니다. EES 자체 부피 기준 Ce=T/ve도 따로 표시합니다. 혈관 항이 있으면 입력 시작 0초의 전체 Ct(0)=vpCp(0)이지만 EES 기여 T(0)는 0입니다. 실제 MRI 신호/농도 변환·AIF 측정·환자 fitting/진단은 계산하지 않습니다.

예측하고 비교할 세 가지

  1. 입력이 끝나는 정확한 5초에 전체 Ct는 어떻게 바뀔까요?
  2. vp만 0으로 만들면 입력 종료의 점프는?
  3. Ktrans가 0이어도 전체 Ct가 남을 수 있을까요?

혈관 분율과 EES 전달

기본: vp .1 / Ktrans .01 s⁻¹ / t2초. ve .2·입력 Cp1 mM/[0,5)초는 고정입니다. 시간은 초이며 공통 구획 계산에만 분 단위로 변환합니다. vp와 ve는 서로 다른 부피분율입니다.

입력 종료에서 두 성분을 나누어 보세요

회색: 같은 Cp1 mM 입력.5초 직전은 빈 원, 정확히 5초 이후는 0의 채운 점입니다. 선택 시각은파랑 점/세로선입니다. 시간 0–20초·혈장 농도 0–1.1 mM의 고정 축입니다.

파랑 실선: 전체 Ct · 회색 점선: 혈관V=vpCp · 주황 실선: EES 기여 T.5초 직전 전체 Ct는 빈 파랑 원, 정확히 5초의 값은 채운 점입니다. 시간 0–20초·조직 부피 기준 0–.16 mM의 고정 축입니다. 표에는 5초의 우측 포함값을 적고 그림은좌극한도 따로 그립니다.

즉시 변하는 혈관 항과 연속적인 EES 항

V=vpCp는 주어진 혈장 입력을 직접 따라갑니다. 입력 종료 5초에서 Cp가 1에서 0으로 바뀌면 V도 vp mM만큼 즉시 줄어듭니다. 반면T는 이전 유입이 누적된 상태이므로 연속적으로 남아 washout합니다. 전체 Ct의 점프는 그때 사라진 혈관 직접항입니다.

Ktrans 0이면 EES로 들어가는 항이 0이라T/Ce는 0이지만, vp>0이고 Cp>0이면 전체 Ct=vpCp는 0이 아닙니다. 이는 이전 혈관항 없는 모형과 모순이 아닙니다. 전체와 EES 기여의 정의가 다릅니다. 실제 밝기/혈류/투과성이나 질병을 이 값으로 단정하지 않습니다.

vp 0에서는 전체 Ct와T가 겹치고 입력 종료에서 점프가 없습니다. 5초 직전/직후의 한계값 차이와 4.9초/5초 같은 서로 다른 표본의차이를 구별하세요. 후자에는 그동안의 EES 변화도 섞입니다.

수식 · 두 기여와 보존 범위

V(t)=vpCp(t), T(t)=Ktrans∫₀ᵗCp(s)exp[−kep(t−s)]ds, Ct=V+T, Ce=T/ve입니다. kep=Ktrans/ve이며 여기 시간은 초, Ktrans/kep는s⁻¹입니다. 공통 함수에는 Ktrans×60min⁻¹·t/60분·입력기간 5/60분을 넣습니다.

직사각 입력에서 T(5⁻)=T(5), V(5⁻)=vp·1 mM이며 V(5)=0이므로 Ct(5⁻)−Ct(5)=vp·1 mM입니다. 입력 Cp를 주어진 저장소로 두었으므로 EES 누적 유입/유출 보존을 전체 혈관 저장소의 질량 보존으로 확대하지 않습니다.
