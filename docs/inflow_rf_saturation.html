X02 기본 · 이상적 slab · RF 직후 신호

Slab에 새로 들어온 spin과 반복 RF를 겪은 spin은 같은 신호를 낼까요?

유입 spin은 slab 밖에서 평형을 유지하다 RF를 처음 만납니다. 같은 T1이어도 깊이에 따라 겪은 RF 횟수가 다르면 종자화가 달라집니다.

목표: 이동 거리·RF 노출 횟수·포화를 연결하고, 속도와 flip이 깊이별 신호에 주는 영향을 구별합니다.

선행 · 교육용 조건과 관찰 시점

X01의 등속 궤적과 C06의 반복 RF/회복을 연결합니다. Slab은 z0…30mm, 유입 방향은+z, T1=1200ms·M0/PD1로 고정합니다. Slab 밖에는 RF가 없고 들어오는 spin은 평형 Mz=1입니다. 유입은 공간적으로 같은 속도를 가진 plug flow이며 역방향/분포/재순환을 계산하지 않습니다.

정확한 순간 균일 RF, 완전한 횡 spoiling, RF 사이 T1 회복을 가정합니다. TE0/RF 직후의 횡진폭을 비교하며 T2* 감쇠·gradient 위상·잡음·수신 감도는 넣지 않습니다. 각 RF 시점에 충분히 반복된 공간 profile입니다. 시뮬레이션 시작 직후의 과도 유입 영상이 아닙니다.

깊이 중점120개(0.125…29.875mm)를 표시합니다. 120개 신호의 산술평균은 표시 요약이며 voxel/PSF 평균이나 실제 전체 영상 신호를 뜻하지 않습니다. T1과 속도는 교육용 값으로 특정 혈액/조직의 측정값이나 임상 권장값이 아닙니다.

유입과 반복 조건

기본 v10cm/s·TR20ms·flip30°. Slab30mm와T1은 고정입니다. v0은 무한 반복 정상상태이며 유입 횟수 식의 분모0에 넣지 않습니다.

관찰 깊이

깊이에 따라 쌓이는 RF 이력

파랑 계단: 선택 v. 보라 점선: 같은 T1/TR/flip의 정지 정상상태. 회색 점선: 이전 RF0회의 새 spin. 원: 관찰 깊이. 깊이0…30mm/신호0…1(M0=1) 고정 창입니다. 메뉴의 이동 거리는 표시 격자와 맞아 각 계단이 과거 RF 횟수 구간을 나타냅니다.

교육용1D 신호 띠·120표시점. 임상 혈관 사진이 아닙니다. 각 띠의 회색값은 신호0→검정,1→흰색으로 고정하며 자동 창 조절을 하지 않습니다. 노란 선은 관찰 깊이입니다.

밝기의 차이를 만드는 것은 유입 spin의 RF 이력입니다

각 TR 동안 이동하는 거리는 d=vTR입니다. 깊은 위치에서는 더 많은 과거 RF를 겪고 T1 회복도 반복합니다. 속도가 느리면 같은 깊이에 도달하기 전에 만나는 RF가 늘어나 정지 정상상태에 가까워집니다. 이동만으로 종자화가 새로 생기는 것은 아닙니다.

Flip을 크게 하면 첫 RF의 sinα 성분은 커지지만, 뒤의 RF를 위한 종자화는 더 줄어듭니다. 그래서 입구의 밝기 증가가 깊은 곳의 증가까지 보장하지 않습니다. TR을 바꾸면 회복량과 이동 거리/노출 횟수가 함께 바뀌므로 두 조건을 표에서 같이 확인하세요.

계산식 · 과거 횟수와 정지 정상상태

d(mm)=v(cm/s)×10×TR(ms)/1000
n(z)=floor[z/d] (v>0, 이번 RF 이전 횟수)
E1=exp(−TR/T1), q=E1 cosα
Mz_ss=(1−E1)/(1−q)
Mz_before(n)=Mz_ss+(1−Mz_ss)qⁿ
동일한 점화식: Mz_next=1+(Mz_before cosα−1)E1
S(z)=Mz_before(z) sinα (TE0)
v=0: Mz_before=Mz_ss, 횟수는 무한 정상상태로 별도 처리

첫 RF 직전 n0의 Mz는1입니다. n은 현재 RF를 제외하며 횟수를 총 RF로 쓰면1을 더해야 합니다. 표시 깊이는 경계가 아닌 중점입니다. v>0 메뉴의 d는0.5mm 이상의0.25mm 정수배여서 경계의 RF 포함 여부가 중점 횟수를 바꾸지 않습니다. TE0이므로 C06 모형의 고정 TE2ms/T2*40ms 감쇠는 사용하지 않습니다. Mz와 신호는 공통 M0=1 기준입니다.
