Q04 · 두 위치·두 coil·R2 분리

겹쳐 보이는 두 위치를 coil 감도로 구별할 수 있을까요?

Phase 줄을 하나씩 건너뛰면 FOV의 절반 간격인 두 위치가 겹칩니다. 두 coil이 그 위치들을 서로 다르게 본다면, 두 측정값으로 원래 신호를 풀 수 있습니다. 감도가 비슷해질수록 작은 잡음도 크게 증폭됩니다.

목표는 alias 합과 분리, 감도 차이의 역할, √R 손실과 g-factor의 추가 손실을 구별하는 것입니다.

선행 개념·모형·정규화

B05의 누락과 alias, Q01의 잡음 SD를 연결합니다. 같은FOV·voxel·신호·BW·coil·NEX 조건에서 R1 전체 측정과 R2 균일 누락을 비교합니다. 실제 감도 map 대신 두 위치의 알려진 실수 감도만 씁니다. 실제 해부학 영상이 아닌 두 voxel의 교육 모형입니다.

신호는 A=1, B=0.5이며 단위는 공통 기준 신호에 대한 비율입니다. 감도 행렬의 각 열 제곱합은1입니다. θ는 실제 coil의 회전각이 아닌 감도가 서로 비슷해지는 정도를 나타내는 교육 변수입니다. 복소 MRI의 한 실수 성분을 계산하며 magnitude/Rician 모형은 사용하지 않습니다.

R2 raw는 겹친 신호의 합으로 정규화합니다. 같은 크기 격자에 zero filling한 inverse에서는 합의1/2가 보이므로 이를2배 한 값입니다. 이 정규화에서 독립 coil raw 잡음 SD는σ√2이고, R1의 각 위치/coil SD는σ입니다. 각 반복의 잡음은 독립 Gaussian입니다.

세 관찰

  1. R1과 R2 비교. σ=0에서 raw 측정과 복원 A/B를 보세요. R2가 줄인 것은 무엇인가요?
  2. 감도 차이 줄이기. θ를20→40→45°로 늘리세요. 두 coil이 같은 비율로 보는 두 위치를 구별할 수 있을까요?
  3. 잡음만 늘리기. 기본값에서 σ를 바꾸세요. 한 번의 오차와 기대 SD를 구별하고, θ0°에서도 √2 손실이 남는지 보세요.

곡선은 σ>0에서 R2/R1의 기대 SNR 비율입니다. θ0°의 g=1에서도1/√2부터 시작합니다. 45°의0은 분리 불가로 향하는 극한이며 유효한 복원값을 뜻하지 않습니다. 실제 잡음이0이면 SNR은 유한 비율로 직접 측정할 수 없습니다.

수식·가정·한계

감도 행렬과 분리

C=[[cosθ,sinθ],[sinθ,cosθ]].
R2: y=Cm+ε, mhat=C⁻¹y.
R1: 각 위치를 따로 측정한 뒤 그 열 감도로 최적 결합.
g=1/|cos2θ|, κ=(cosθ+sinθ)/(cosθ−sinθ).

45°에서는 두 열이 같아 determinant가0이고 원래 값은 하나로 정해지지 않습니다. 예를 들어(1,0.5)와(0.75,0.75)는 같은 합을 만듭니다. 이 페이지는 역행렬이 없을 때 임의의 정답을 만들지 않고 분리 불가로 표시합니다. R1은 위치별 데이터가 있어 이 경우에도 작동합니다. 감도는 정확히 알려져 있으며 map 오차·motion·calibration은 모형 밖입니다.

잡음·g-factor·고정 표시 창

CovR2=2σ²(CᵀC)⁻¹.
SDR1=σ, SDR2=σ√2g.
SNRR2=SNRR1/(√2g).

독립 등분산 coil 잡음·정확한 감도·선형 비정규화 역문제와 열 norm1의 고정 조건입니다. g는 추가 잡음 증폭이고 R 자체의 √R 손실과 다릅니다. CNR·실제 coil 잡음 상관·정규화 재구성·GRAPPA·AI·실제2D 영상은 계산하지 않습니다. 복원값은 부호를 가진 실수입니다. 화면 창−0.5~1.5의 회색 표시만 잘라내며 표 수치는 잘라내기 전 값입니다. 분리 불가일 때 칸은 회색 줄무늬로 표시합니다.

근거·검증·검사 시간의 범위

Pruessmann 등 (1999), SENSE의 coil 감도에 의한 공간 부호화와 Larson · Accelerated Imaging의 undersampling·g√R 관계를 참고했습니다. 자체 두 위치 모형의 해·공분산은 독립 선형대수·Monte Carlo로 검산합니다. 수치·통계·화면·물리 검증 기록.

R2는 이 모형에서 phase 표본을 절반만 측정한다는 뜻입니다. 전체 검사 시간의 정확한 절반을 보장하지 않으며 준비·calibration·gating은 Q03의 이벤트 시간과 구별합니다. 실제 vendor SENSE/GRAPPA 또는 임상 SNR·안전·프로토콜을 예측하지 않습니다.
