X09 기본 · 직접 정의한 선형 지연 모형

입력이 끝난 뒤에도 반응이 남을 수 있을까요?

관찰한 곡선의 시각과 원인 입력의 시각은 같지 않을 수 있습니다. 짧은 입력에 지연과 퍼짐을 적용하여, 입력이 끝난 뒤에도 반응이 남는 이유를 살펴봅니다.

목표: 입력과 반응의 시계를 구별하고, 지연 폭과 입력 길이의 영향을 각각 비교하며, 이 교육용 곡선의 해석 범위를 설명합니다.

선행 · 시간축, 면적, 합성곱

시간창 평균에서 원래 곡선과 관측값을 구별했습니다. 여기서는 다른 연산인 인과적 합성곱을 사용합니다. 한 순간의 입력이 이후 여러 시각에 나누어 영향을 준다고 생각하면 됩니다. 미래 입력이 과거 반응에 영향을 주지는 않습니다.

입력 u는 2초부터 2초 또는 6초 동안 1, 그 외에는 0입니다. 반응 y도 직접 정의한 무차원 양입니다. 지연 커널 h의 단위는 s⁻¹이며, 전체 시간의 면적을 1로 정합니다. τ는 커널의 시간 척도로 1초 또는 2초입니다. 모든 값은 교육용 선택값입니다.

이 커널은 실제 신경 활동, BOLD 신호의 백분율이나 표준 혈역학 반응 함수(HRF)를 추정한 것이 아닙니다. 신호비와 ΔR2* 변환의 신호 모형도 여기에 적용하지 않습니다.

예측하고 비교할 세 가지 관찰

  1. 2초짜리 입력이 끝나는 4초에 반응도 0일까요?
  2. 같은 짧은 입력에서 커널의 τ만 두 배로 하면?
  3. τ를 고정하고 입력만 6초로 늘리면?

입력과 지연의 조건

기본값: 입력 길이 2초, τ 1초, 선택 시각 8초. 입력 시작은 항상 2초입니다. 입력 시작은 포함하고 종료는 제외합니다. 한 점의 포함 규칙은 연속 합성곱의 면적을 바꾸지 않습니다.

커널과 입력의 반응

보라 실선: 지연 커널 h · 원: 연속 최고점. 가로축은 입력 이후의 지연 시간 0–12초, 세로축은 0–0.3 s⁻¹로 고정합니다. 표시창 뒤의 꼬리도 남아 있어, 이 창 안의 면적만 1은 아닙니다.

회색 점선: 입력 u (채운 끝점 포함·빈 끝점 제외) · 파랑 실선: 반응 y · 작은 원: 선택 시각 · 빈 파랑 원: 반응의 연속 최고점. 가로축 0–24초, 세로축 0–1의 같은 고정 창입니다. 두 곡선은 직접 정의한 무차원 양이며 환자의 신호가 아닙니다.

입력이 끝나도 이전 입력의 영향은 남습니다

입력은 종료 시각에 0이 되지만, 그전에 들어온 입력의 영향은 커널의 꼬리를 따라 이어집니다. 따라서 이 모형에서는 반응 최고점도 입력 종료보다 뒤에 있습니다. τ가 커지면 커널이 더 넓고 낮아집니다. 전체 커널 면적은 두 경우 모두 1입니다.

입력을 길게 하면 반응의 높이와 전체 면적이 바뀝니다. 커널 면적 1 때문에 전체 반응 면적은 입력 면적 D와 같습니다. 이것은 0–24초 표시창의 면적이나 BOLD 신호의 보존 법칙을 뜻하지 않습니다.

수식 · 인과적 합성곱과 단위

h(t)=t²exp(−t/τ)/(2τ³) (t≥0), 이전에는 0입니다. ∫₀∞h(t)dt=1이며 커널 최고점은 지연 2τ입니다. y(t)=∫u(s)h(t−s)ds에서 무차원×s⁻¹×초이므로 y는 무차원입니다.

H(a)=∫₀ᵃh(s)ds (a≤0이면 0)로 두면 y(t)=H(t−2)−H(t−2−D)입니다. 연속 최고점 시각은 2+D/[1−exp(−D/(2τ))]초이며, 입력 종료 2+D초보다 큽니다. 이는 이 커널과 입력에만 해당합니다.

가정과 출처

고정된 비음수 커널을 사용하는 선형·시간 불변·인과 모형입니다. 입력 시작과 길이는 알려져 있고, 잡음·추정 오차·자극 적응·생리 변화·비선형성과 음의 undershoot는 포함하지 않습니다. 임상 영상은 없으며 실제 fMRI 분석·통계·활성화 추론·환자 진단은 구현하지 않았습니다.

Boynton 등(1996)의 원논문 초록은 일부 V1 자료에서 선형 변환 가설을 검사한 맥락을 제공합니다. Glover(1999)의 원논문 초록은 적용 범위와 비선형성의 문제를 다룹니다. 이 페이지의 gamma 커널·계수는 두 논문의 측정값이나 표준 HRF를 재현하지 않고 직접 정의했습니다. 선형 모형의 편의성을 실제 BOLD의 보편적 선형성으로 확대하지 않습니다.
