X07 후속 · 직접 정의한 사각 입력과 잡음 없는 전진 모형

같은 조직 농도 곡선이면 입력과 구획 계수도 같을까요?

입력 크기와 전달계수·분포부피를 함께 바꾸면 서로 다른 조건에서 같은 곡선을 만들 수 있습니다. 정해진 한 모형에서 무엇이 같은지, 무엇이 달라도 되는지 비교합니다.

목표: 입력 크기/조직 응답·같은 비율/다른 계수·Ct와Ce의 부피 기준을 구별합니다.

선행 · 알려진 입력과 두 농도 기준

단일 EES 구획의 dCt/dt=Ktrans Cp−kepCt, kep=Ktrans/ve, Ct0=0을 사용합니다. Cp=f mM를[0,5)초에 직접 정의하고 이후0입니다. f=.5/1/2이며 실제 AIF/주입량/환자 농도가 아닙니다. 혈관 직접 기여 항·MRI 신호 변환·잡음은 제외합니다.

Ct는 조직 단위부피당 EES 기여 농도, Ce=Ct/ve는 EES 자체 부피당 농도입니다. mM=mmol/L이지만 분모의 부피 기준이 다릅니다. ve는 EES만의 분율이며 혈관 직접항을 제외하므로 ECV 예시와 같은 양으로 대입하지 않습니다.

기준f1의 Ktrans=.01s⁻¹/ve=.2와 비교합니다. 고정형은 f를 바꾸어도 두 계수를 유지합니다. 보상형은 Ktrans=.01/f s⁻¹, ve=.2/f로 함께 바꿉니다. 두 유형의 kep는 항상.05s⁻¹입니다. 이 페이지의 시간은초이며 기존 챕터의분과 구별합니다. 공통 계산에는 시간/60분·Ktrans×60min⁻¹·입력기간5/60분으로 변환합니다.

다른 입력과 같은 조직 곡선

파랑: 선택 Cp=f mM · 회색 점선: 기준 Cp1mM. 시간0–20초·농도0–2.2mM의 고정 축입니다.5초 직전 값은 빈 원, 정확히5초의 값0은 채운 점입니다. 선택 시각은 파랑 점/세로선입니다.

파랑 실선: 선택 Ct · 회색 점선/빈 원: 기준f1의 Ct. 겹치면 같은 Ct 곡선이지만 계수까지 같은 것은 아닙니다. 시간0–20초·조직 부피 기준0–.1mM의 고정 축입니다. 입력종료5초에서Ct는 연속입니다.

같은 비율이나 같은 곡선이 모든 계수의 일치는 아닙니다

보상형에서는 f가 커질수록 Cp는 커지고 Ktrans와ve는 작아집니다. Ktrans Cp와kep가 모두 기준과 같으므로 Ct의 미분방정식/초기값이 같아 전체Ct도 같습니다. kep가 같다는 것만으로 Ktrans와ve를 각각 같은 값으로 정할 수는 없습니다.

고정형에서는 같은 계수로 Cp만 바꾸므로 Ct가 f에 비례합니다. 보상형과 고정형의 차이는 화면의 규칙으로 직접 정한 것입니다. 임의의 측정 곡선에 이 규칙이 항상 맞는다고 주장하지 않습니다.

같은 Ct여도 ve가 다르면Ce=Ct/ve는달라집니다. 또한 입력종료 뒤Cp가 0이어도 남아 있는Ct는 연속적으로 washout합니다. 한 시각의Cp와 과거 입력의 누적 응답을 혼동하지 마세요.

수식 · 제한된 스케일 불변과 단위

기준 Cp0(t)에 대해 보상형 Cp=fCp0, Ktrans=K0/f, ve=ve0/f이면 kep=(K0/f)/(ve0/f)=K0/ve0입니다. dCt/dt=(K0/f)fCp0−kepCt=K0Cp0−kepCt가 되어 기준과 같습니다. 이는 알려진 함수 형태/잡음 없는 단일 구획/입력 배율만의 불확실성이라는 제한에서 유도한 예입니다.

Ct(t)=Ktrans∫₀ᵗCp(s)exp[−kep(t−s)]ds입니다. Ktrans/kep는s⁻¹, t는초, 농도는mM이며 Ct는조직 부피 기준입니다. 공통 함수의min 단위로 바꿀 때 s⁻¹값에60을 곱하고 시간과입력기간은60으로 나눕니다. 실제 신호→농도/AIF 추정이나 fitting은 수행하지 않습니다.

가정과 근거

Tofts 등 표준화 논문의 저자 초록에서 Ktrans/ve/kep의 정의·비율을 확인했습니다. 이 페이지는 직접 선택한 사각 입력과 스케일 규칙에서 불변성을 유도한 교육 예입니다. 실제 환자 추정의 일반적인 비유일성이나 질병 차이를 원문이 증명했다고 표현하지 않습니다.
