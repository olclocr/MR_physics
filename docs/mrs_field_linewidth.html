N03 후속 · 알려진 주파수 분포의 교육 모형

voxel 안의 field가 고르지 않으면 peak는 어떻게 바뀔까요?

같은 평균 주파수라도 위치마다 주파수가 다르면 신호가 상쇄되고 spectrum이 넓어집니다. 균일한 이동과 공간적인 퍼짐을 구별해 shimming의 기본 목적을 관찰합니다.

목표: peak 위치·폭·높이와 복소 FID를 연결하고, 단일 지수 감쇠와 추가 위상 상쇄를 구별합니다.

선행 · 단일 가상 line과 정규화

중심0의 균일한 1D voxel 폭 L 안에서 잔여 주파수는 f(x)=μ+g x입니다. μ는 균일 B0 offset, g는 잔여 field의 선형 주파수 기울기입니다. Hz는 임의 기준 주파수에 대한 값이며 실제 대사물의 chemical shift를 나타내지 않습니다.

각 위치의 고유 횡이완 T2만 먼저 적용하고 공간 위상을 평균합니다. 이미 B0 퍼짐을 포함한 T2*를 또 곱하지 않습니다. 단위부피 평균으로 FID(0)=1, 연속 흡수선의 전체 면적=1을 고정합니다. 실제 voxel 부피가 커질 때의 신호량/SNR 변화는 이 비교에서 계산하지 않습니다.

이상적 box, 균일 밀도/위상, 선형 정적 field, 단일 종, 잡음0입니다. 실제 RF/localization·대사물/결합·field map·shim 최적화나 임상 품질 기준은 구현하지 않았습니다.

세 가지 관찰

  1. 전체 voxel을 같은 주파수만큼 옮기면 peak 폭도 변하나요?
  2. 같은 기울기에서 voxel 폭을 두 배로 하면 높이와 폭은 어떻게 되나요?
  3. 잔여 기울기를0으로 줄이면 어떤 감쇠와 linewidth가 남나요?

공간과 주파수 조건

기본: 폭20 mm, 기울기0.5 Hz/mm, offset0, T2 80 ms. 모든 조건은 단위부피 평균과 공통 표시 창을 사용합니다.

Voxel 안의 잔여 주파수

선은 관측한 voxel 안에서만 그립니다. x=−20…20 mm, 주파수=−30…30 Hz 고정. 실제 field map이나 조절 가능한 shim coil 모형은 아닙니다.

공간 평균한 복소 FID

파랑=Re, 보라 점선=Im, 검정=크기, 회색 점선=고유 이완 envelope exp(−t/T2). 시간0…300 ms, 신호−1…1 고정. 크기의 영점 뒤 재등장이 있어도 고유 T2가 되돌아간 것은 아닙니다.

같은 공간 분포의 연속 흡수선

파랑=정확한 연속 흡수선, 주황 선=반높이의 FWHM 구간. −50…50 Hz, 높이0…0.35 상대신호·s 고정. 유한 FID의 DFT 크기와 다른 정의이며 표시 표본을 늘려 획득 자료를 만든 것이 아닙니다.

평균을 맞추는 것과 퍼짐을 줄이는 것은 다릅니다

균일 offset은 전체 주파수를 함께 옮깁니다. 선폭을 줄이려면 voxel 안의 주파수 차이가 줄어야 합니다. 이 모형에서 g를 줄이는 것은 잔여 비균일성을 줄이는 개념이며 실제 장비의 최적 shim 계산을 뜻하지 않습니다.

공간 퍼짐은 같은 정규화 전체 면적에서도 peak를 낮고 넓게 만듭니다. 표시 범위 밖의 Lorentz tail 때문에 화면 안의 면적은1보다 작으며, peak가 이동하면 이 유한 범위의 면적도 달라질 수 있습니다. 높이만으로 농도 손실을 판단하지 마세요.

공간 적분 · 시간/주파수 정의 · 이중 계산 방지

a=gL/2, h=1/(2πT2초)
s(t)=exp(−t/T2) exp(−i2πμt) sin(2πat)/(2πat)
A(f)=2 Re ∫₀∞ s(t) exp(+i2πft) dt
a>0: A(f)={atan[(f−μ+a)/h]−atan[(f−μ−a)/h]}/(2aπ)
a=0: A(f)=h/{π[(f−μ)²+h²]}
FWHM=2√(a²+h²), ∫₋∞∞ A(f)df=1

수식의 t와 T2는 초 단위입니다.

t=0 또는 a=0에서 sinc의 극한은1입니다. 화면 계산의 시간은ms이며 Hz와 곱할 때1000으로 나누어 초로 변환합니다.

공간의 균일 주파수 분포와 Lorentz line의 convolution입니다. a>0에서는 FID envelope가 단일 지수가 아니므로 linewidth에서 단순히 T2*=1/(π FWHM)을 계산해 독립적인 조직값으로 다루지 않습니다. 여기의 T2는 각 위치의 고유 감쇠이며 추가 정적 field 분포는 따로 적분합니다.
