C08 후속 · On-resonance의 정확값과 짧은 TR 근사

신호를 T2/T1 비율만으로 정할 수 있을까요?

짧은 TR의 bSSFP 신호에는 T2/T1 비율이 중요한 역할을 합니다. 하지만 근사가 성립하는 조건까지 지워 버리면 다른 절대 이완시간의 차이를 놓칠 수 있습니다.

같은 T1, 같은 T2, 같은 T2/T1인 두 spin을 비교하고 TR을 바꿔 보세요. 물리 모형의 정상상태 정확값과 근사를 함께 표시합니다.

기초 개념·고정 조건·값의 성격

C08의 순간 RF/Bloch 고정점을 재사용하며 T1/T2만 선택한 두 spin으로 바꿉니다. M0=1·flip30°·offset0Hz·RF위상0/π 교대·balanced moment0·TE=TR/2입니다. 완전한 정상상태이며 초기 반복은 앞 페이지에서 다룹니다.

TR=5/20/50/100/200ms, TE=2.5/10/25/50/100ms입니다. TR과 함께 TE도 변합니다. TR200ms는 빠른 임상 bSSFP를 재현하기 위한 값이 아니라 짧은 TR 근사의 범위를 벗어나는 반례 조건입니다. 이완시간도 조직에 붙인 임상 표준값이 아닌 교육용 예시입니다.

모든 신호는 동일 M0 기준입니다. PD·RF 세기 오차·noise·coil·최소TR/장비·SNR·실제 조직/진단/프로토콜은 비교하지 않습니다. 원래 bSSFP의 off-resonance/flip 의존성을 비율 하나로 일반화하지 마세요.

  2. 같은 T2에서 T1만 다르게. “순수 T2 신호”라는 말로 설명할 수 있나요?
  3. 같은 비율에서 TR 늘리기. 근사는 같아도 정확값이 계속 같은가요?

수식·근거·한계

On-resonance 정확값과 TR→0 근사

E1=exp(−TR/T1), E2=exp(−TR/T2).
S정확=√E2·(1−E1)sinα / [1+(E2−E1)cosα−E1E2].
S짧은TR≈sinα / [1+cosα+(T1/T2)(1−cosα)].

위 정확식은 순간RF·위상0/π·on-resonance·TE=TR/2·M01이라는 현재 조건에서의 식입니다. 제품은 앞 페이지와 같은 3차원 Bloch 고정점을 풀며, 이 식과 독립 lab-frame 두TR 행렬로 확인했습니다. 근사는 E1/E2의 짧은TR 전개로 얻습니다. TR이 T1·T2보다 충분히 짧아야 하며 다른 offset·위상주기·TE에는 그대로 쓰지 않습니다.

근거와 독립 검증

Bieri (2011)의 원논문에서 순간RF/finiteRF의 이완 의존성을 확인했습니다. 현재 Bloch 고정점·on-res 정확식·TR→0 전개는 자체 유도하고 별도의 행렬지수/시간적분과 대조했습니다. 독립 검산·근사 범위·실제 화면 검증.

여기서 T2/T1의 영향은 특정 조건의 정상상태 신호 비교입니다. 실제 조직 대비·noise/SNR·B1/finite RF/MT·흐름·공간분포·임상 최적TR/안전·vendor 성능은 모형 밖입니다. 주파수 응답 페이지에서 offset·flip 의존성도 확인하세요.
