X16 후속 · 새로 정한 균일 열용량과 선형 손실

같은 에너지를 일찍 또는 늦게 흡수하면 마지막 온도 변화도 같을까요?

흡수 에너지가 같아도 일부가 주위로 빠져나가면 남은 에너지는 입력 시점에 따라 달라질 수 있습니다. 흡수한 양, 현재 저장된 양과 주위로 전달한 양을 함께 비교합니다.

목표: 같은 총 에너지/다른 시점·온도 변화/저장 에너지·열손실/에너지 보존을 구별합니다.

선행 · 열용량과 주위 기준 온도

이미 주어진 흡수 파워를20초 중 앞[0,10)초 또는 뒤[10,20)초에 연속1/2W 적용합니다. 총 흡수 에너지는10/20J, 전체20초 평균은.5/1W로 시점과 무관합니다. 실제 RF/B1에서 흡수 파워를 구하는 계산은 없습니다.

이번 페이지는 새 교육용 열용량 C=10J/K를 직접 정합니다. 이전 페이지의4000J/K와 다른 값이며 실제 물체/인체의 열용량이 아닙니다. 고정된 주위 온도에 대한 ΔT의 초기값은0입니다. 절대 체온은 정하지 않습니다.

주위로 전달되는 파워를 Ploss=HΔT, H=0/.5/1W/K로 정의합니다. 균일한 단일 온도·일정C/H·고정 주위를 가정하며 공간별 온도/전도·관류·체온조절을 계산하지 않습니다. H0은 열손실이 없는 극한입니다. 관찰 시각은 항상20초이고 곡선은40초까지 보여줍니다.

예측하고 비교할 세 가지

  2. 열손실만0으로 만들면 입력 시점에 따라 달라질까요?
  3. 같은 앞10초 입력에서 H를1W/K로 늘리면?

입력 시점과 선형 손실

기본: 앞10초 / P2W / H.5W/K. C10J/K·관찰20초·주위 고정입니다. 모든 값은 직접 정한 교육용 모형이며 환자 온도/화상이나 안전성을 추정하지 않습니다.

언제 흡수하고 얼마가 남았는가

파랑 실선: 주위 대비 ΔT · 옅은 영역: 흡수 입력 구간 · 세로선/파랑 점:20초 관찰 · 빈 주황 원: 입력 종료/처음 최고점. 시간0–40초·온도 변화0–2.2K의 고정 축입니다. H0에서는 최고점 뒤 평탄한 값이 유지됩니다.

낮은 마지막 온도와 적은 총 흡수를 혼동하지 마세요

앞10초의 입력은 관찰20초까지 더 오래 열을 잃습니다. H>0에서 뒤10초 입력보다 마지막 ΔT가 낮아도 총 흡수 에너지가 더 작아서가 아닙니다. 주위로 전달한 양이 더 큽니다. 입력 구간이 같고 모형 계수가 같다면 두 시점의 처음 최고 ΔT는 같습니다.

H0에서는 주위로 전달하는 파워가0이므로 같은E에 같은ΔT=E/C가 남습니다. H>0에서 입력이 꺼져도 ΔT는 즉시0이 되지 않고 연속적으로 줄어듭니다. 꺼지는 순간 바뀌는 것은 온도 자체가 아니라 그 시간 변화율입니다.

이 결과는 직접 정한 단일 열용량과 선형 손실 법칙의 결과입니다. 같은 에너지/다른 마지막 온도를 실제 환자 위험의 우열이나 허용 프로토콜로 바꾸어 해석하지 않습니다.

수식 · 에너지 보존과 지수 응답

C dΔT/dt=Pabs−HΔT, dE/dt=Pabs, dL/dt=HΔT입니다. ΔT0/E0/L0=0이므로 E=CΔT+L입니다. C의 단위J/K, H의 단위W/K이며 시간상수C/H는초입니다. H0에서는 유한 냉각 시간상수를 정의하지 않습니다.

입력 시작s0, 길이10초에 대해 u=clamp(t−s0,0,10), v=max(0,t−s0−10)이라 두면 H>0에서 ΔT=(P/H)[1−exp(−Hu/C)]exp(−Hv/C)입니다. H0에서는ΔT=Pu/C입니다. 온도는K, 에너지는J로 표시하며 이전 페이지의 mK와 구별하세요.
