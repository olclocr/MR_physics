AI03 정량 · 공간 처리의 한계 모형

각 echo를 같은 방법으로 처리해도 T2는 유지될까요?

서로 다른 감쇠가 공간적으로 섞이면 한 위치의 신호가 단일 지수에서 벗어납니다. 잡음이 없는 합성 신호에서 공간 처리와 T2 추정을 연결해 보겠습니다. 실제 학습 모델이나 임상 mapping 성능을 구현한 것은 아닙니다.

목표: 공간 혼합의 정량 bias, 사용 echo의 영향, 피팅 불가 상태를 구별합니다.

선행 · 신호와 공간 모형

N=64, FOV=64 mm, 시작 신호 A=1입니다. 배경 T2=80 ms, j32를 중심으로 폭 1/3/7표본의 영역에 T2=20/40/120 ms를 지정합니다. 실제 조직값이나 병변을 뜻하지 않는 1D 교육 모형입니다.

완전 회복, 이상적 SE, 동일 위상, 잡음 0으로 각 echo의 신호는 exp(−TE/T2)입니다. RF 불완전성, stimulated echo, 수신 코일, 실제 2D 획득은 제외합니다. AI01의 identity/순환 3tap 평활/선명도/한 번의 Haar shrink를 echo마다 같은 설정으로 적용합니다.

세 가지 관찰

  1. 평활 뒤 중심의 T2는 원래 값과 같나요? 폭을 3표본으로 바꾸면 어떤가요?
  2. 같은 평활 출력에서 후기 echo만 쓰면 추정값이 같나요?
  3. 선명도 처리로 음수가 생긴 신호에도 log fitting을 할 수 있나요?

영상을 섞은 뒤 피팅하는 것과 T2를 섞는 것은 다릅니다

폭 1표본의 평활 중심 신호는 0.5 exp(−TE/T2중심) + 0.5 exp(−TE/80)입니다. T2가 다르면 일반적으로 하나의 지수가 아닙니다. 후기에는 긴 T2 성분의 상대 기여가 커져, echo 선택에 따라 유효한 추정값이 달라집니다. 원래 T2의 산술평균을 먼저 계산한 것과도 다릅니다.

폭 3표본의 평활 중심은 이웃도 같은 T2라서 중심의 감쇠가 유지됩니다. 경계의 추정값까지 정확해지는 것은 아닙니다. 전체 map RMSE가 작아도 작은 중심 영역의 bias가 클 수 있으며, 제외된 위치가 있으면 그 개수를 반드시 함께 읽어야 합니다.

연산 · 추정 기준 · 선형과 비선형 처리

Sᵢ[j] = exp(−TEᵢ / T2[j])
zᵢ = T(Sᵢ), ln zᵢ[j] = a[j] + b[j] TEᵢ
T2추정 = −1/b, A추정 = exp(a)

절편을 자유롭게 두는 log OLS이며 사용점 모두의 실수 신호가 1e−12를 초과할 때만 계산합니다. 하나라도 이하이면 해당 위치를 추정 불가로 표시하고 점을 조용히 빼거나 절댓값으로 바꾸지 않습니다. 기울기가 −1e−12/ms 이상이면 감쇠 T2 추정 불가입니다. 이 문턱은 이 모형의 수치 기준이며 임상 신호 문턱이 아닙니다.

평활 [1/4, 1/2, 1/4]과 선명도 [−1/4, 3/2, −1/4]는 선형 순환 필터입니다. Haar는 복소 계수에 고정 문턱 0.08을 적용하는 한 번의 비선형 처리입니다. 같은 설정도 echo별 신호 크기에 따라 다른 계수를 제거할 수 있습니다. 실제 학습형 처리의 동작을 이 결과로 예측하지 않습니다.

중심 신호 RMSE는 사용 echo의 원래 상대신호 단위입니다. 공간 T2 RMSE는 유효 위치에서만 계산한 ms 단위이며 임상 정확도가 아닙니다. 창 밖 값은 표시 위치만 제한하고 오차 계산과 표의 원값을 유지합니다.
