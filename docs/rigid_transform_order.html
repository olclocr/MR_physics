X17 후속 · 알려진 2D 좌표와 변환 순서

회전과 평행이동의 순서를 바꾸어도 같은 점에 도착할까요?

둘 다 강체 변환이지만 순서를 바꾸면 점의 최종 위치가 달라질 수 있습니다. 같은 원점에서 두 순서의 점 위치와 선분 길이를 나란히 비교합니다.

목표: 변환 순서/원점·현재 위치/보존된 길이·물리 좌표/pixel 간격의 차이를 설명합니다.

선행 · 원점과 두 연산의 정의

강체 변환의 알려진 5×5 격자(20mm 간격)를 그대로 사용합니다. 물리 x는 오른쪽, y는 위쪽이고 (0,0) 원점을 고정합니다. R은 원점 중심 반시계 θ=0/30/90도 회전, T는 +x로 d=0/5mm 평행이동입니다.

순서 A는 회전→이동: pA=R(p)+b입니다. 순서 B는 이동→회전: pB=R(p+b)이며, 이동한 뒤에도 고정된 원점 주위로 회전합니다. b=(d,0)입니다. 이동한 물체의 새 중심을 회전 중심으로 삼는 연산과 구별하세요.

128×128mm FOV·Δx=1mm/Δy=1또는2mm에서 물리 좌표를 먼저 변환한 뒤 u=(X+64)/Δx−.5, v=(64−Y)/Δy−.5로 환산합니다. Pixel Spacing은 (Δy,Δx) 순서입니다. u/v는 분수 pixel 중심 좌표이며 반올림하지 않습니다. 점 ID r/c는 원래 점의 이름으로 현재 pixel 행/열과 다릅니다.

공통 변환과 표시 간격

기본: θ30도 / d5mm / 간격(2,1) / 중심 가로. 두 그림의 물리 축척과 FOV는 같습니다. 비등방 pixel 좌표 자체를 같은 각도로 회전하지 않습니다.

같은 점과 원점, 다른 순서

A · 회전→이동: R(p)+b

B · 이동→회전: R(p+b)

회색 빈 원: 원래 위치 · 옅은 선: 각 점의 이동 · 파랑 원(A)/주황 네모(B): 최종 위치. 굵은 선과 P/Q는 선택한 원래 두 점입니다. 모든 축은 mm이며 x/y가 같은 축척입니다. 같은 점 집합이 겹쳐도 ID/대응/선분은 달라질 수 있습니다. 교육용 기하 도식이며 임상 영상이 아닙니다.

위치가 달라도 두 변환 모두 길이를 보존합니다

두 순서의 차이는 모든 점에서 pB−pA=Rb−b로 같습니다. 따라서 이 예시의 두 결과는 서로 일정한 평행이동만큼 떨어져 있습니다. 어느 쪽도 늘이거나 비트는 변형은 없습니다. 각 결과 안의 모든 점쌍 길이는 원래와 같습니다.

d0 또는 θ0이면 차이가0입니다. 기본30도/5mm에서는 두 순서가 다르고90도/5mm의 차이는5√2mm입니다. 길이가 같다는 것만으로 최종 위치나 변환 순서가 같은지 판정할 수 없습니다.

물리 길이는 √[(ΔuΔx)²+(ΔvΔy)²]로 환산합니다. 간격(2,1)에서 u/v 차이만 같은 길이 단위로 더하지 않습니다. 이 알려진 변환의 수학적 보존을 실제 영상 registration 정확도나 장비 QA 합격으로 확대하지 않습니다.

수식 · 열벡터, 행렬 곱과 원점

동차 열벡터 p=(x,y,1)ᵀ에 회전 R=[[cosθ,−sinθ,0],[sinθ,cosθ,0],[0,0,1]], 이동 T=[[1,0,d],[0,1,0],[0,0,1]]를 정의합니다. A=T R p, B=R T p입니다. 오른쪽 연산이 먼저 적용됩니다. 표준 파일의 저장 순서/환자좌표를 추정한 것이 아니라 여기 직접 정의한 규약입니다.

pB−pA=Rb−b이고 크기는2d sin(θ/2)입니다(여기0≤θ≤90도). 두 순서에서 점쌍 차이는 R(p₂−p₁)이고 RᵀR=I이므로 길이가 보존됩니다. 회전은 항상 고정 원점 주위로 적용합니다.

가정과 근거

DICOM의 공간 등록/행렬 순서와 RIGID 설명, pixel 간격 정의를 배경으로 사용합니다. 여기25점/2D 원점/행렬은 직접 정한 교육 예시입니다. 실제 DICOM 등록 파일/4×4 환자 좌표를 계산한 결과가 아닙니다.
